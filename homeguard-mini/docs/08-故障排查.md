# 08 常见问题和故障定位

## PlatformIO 找不到工程

打开的是 `homeguard-mini/firmware`，不是最外层目录，也不是单独的 `main.cpp`。左侧应能看到 `platformio.ini`。

## 没有串口

- 换一根确定支持数据的 USB 线；
- 换电脑 USB 口；
- 在设备管理器查看是否出现新的 COM 口；
- 关闭占用串口的其他工具；
- 部分开发板需要安装 USB-UART 驱动。

## 烧录卡在 Connecting

按住 BOOT，短按 RESET，开始写入后松开 BOOT。烧录完成再按一次 RESET。

## 设备不断重启

- USB 电源可能不足，使用 5V 2A 合格适配器；
- 3V3 与 GND 可能存在间歇短路；
- 屏幕背光或模块接错电源；
- 查看串口是否有 `Brownout detector`；
- 拔掉所有外设，只留开发板，逐个接回。

## SCD4x=0、SHT4x=0 或 BH1750=0

- SDA/SCL 是否接反；
- 是否确实接 GPIO8/9；
- 模块是否 3.3V 供电且共地；
- 杜邦线是否内部断路；
- 三个模块全部断开，只接失败的一个测试。

## LD2410=0

- LD2410C 供电应接 5V；
- 模块 TX 接 GPIO17，RX 接 GPIO18；
- 波特率默认 256000，如果曾用工具修改过，需要恢复默认；
- 确认购买的是 LD2410C，而非接口不同的其他型号。

## 网页打不开

- 查看屏幕底部或串口打印的实际 IP；
- 手机与设备是否在同一 Wi-Fi；
- 路由器可能开启客户端隔离；
- 尝试设备热点模式和 `192.168.4.1`；
- 手机连设备热点后关闭移动数据，避免系统自动走蜂窝网络。

## 网页正常但屏幕白屏

主控和程序通常是正常的，集中检查屏幕供电和 SPI 接线。确认驱动芯片是否真的是 ILI9341。

## CO₂一直很高

- 房间确实可能通风不足，先开窗验证是否下降；
- 不要放在人的呼吸正前方；
- 不要放在燃烧设备、厨房或密闭柜内；
- 新传感器可在通风良好的环境运行数小时后再观察；
- 本设备不能检测天然气或一氧化碳。

## 温度偏高

SHT40 离 ESP32、屏幕背光或稳压器太近。用 5～10 cm 导线把 SHT40 移到外壳通风边缘，再重新比较。

## AI 一直报警

1. 查看原因是否为固定 CO₂或湿度阈值；
2. 确认设备没有移动；
3. 确认学习时环境是正常的；
4. 按学习按钮重新采集；
5. 如果只是正常开关灯导致短时高分，记录现象，后续加入多工况模型；
6. 不要优先通过提高危险阈值掩盖问题。

## 蜂鸣器不响或一直响

代码按“高电平触发”编写。部分模块是低电平触发，请更换对应模块或修改 `updateAlarm()` 中 HIGH/LOW 逻辑。先用万用表确认 I/O 和 GND 接线。
