# EasyEDA 渐进电路学习路线

本路线对应 EasyEDA 项目“嵌入式AI电路学习实验室”中的四个原理图页。四级电路都围绕同一块 `ESP32-S3-DevKitC-1 N8R8` 展开，前一级学会的内容会在后一级继续使用。

## 安全边界

- 全部实验只使用 USB 5V 和 3.3V 低压；
- 不接市电，不制作 220V 继电器或插座控制器；
- 接线、改线前拔掉 USB；
- 上电前用万用表确认 3V3 与 GND 没有短路；
- INMP441 只能接 3.3V，LD2410C 供电接 5V；
- 所有模块必须共地。

## 四级路线总览

| 等级 | EasyEDA 图页 | 核心知识 | 典型应用 |
|---|---|---|---|
| L1 入门 | `L1_入门_LED与按键` | 限流、上拉、低有效、共地 | 状态灯、模式按键、故障指示 |
| L2 基础 | `L2_基础_蜂鸣器驱动` | GPIO 电流边界、三极管开关、默认关断 | 门铃、定时提醒、阈值报警 |
| L3 进阶 | `L3_进阶_I2C环境节点` | I2C 总线、地址、并联、上拉 | 空气质量站、温室监测、通风提醒 |
| L4 大师 | `L4_大师_HomeGuard完整系统` | 多总线协同、供电域、模块化接口、系统调试 | HomeGuard Mini、本地 AI 环境异常检测 |

“大师”表示完成本学习路线的系统集成级别，不代表电路可以直接用于生命安全产品。HomeGuard Mini 是学习和辅助提醒设备，不能替代认证烟雾、燃气或一氧化碳报警器。

## L1：LED 与按键

### 电路

```text
GPIO2 ── 330Ω ── LED ── GND

3V3 ── 10kΩ ──┬── GPIO38
               └── 按键 ── GND
```

- `330Ω` 限制 LED 电流，不能省略；
- `10kΩ` 把未按下时的 GPIO38 稳定为高电平；
- 按下后 GPIO38 接地，因此程序读取到低电平；
- 固件实际使用内部上拉时，外部 10kΩ 可以省略，但保留它更适合学习上拉原理。

### 验收

1. GPIO2 输出高低电平时，LED 能可靠亮灭；
2. 未按按键时 GPIO38 稳定为高，按下时稳定为低；
3. LED 不应直接连接 GPIO 与 GND。

## L2：蜂鸣器三极管驱动

### 电路

```text
GPIO21 ── 1kΩ ── S8050 基极
                    发射极 ── GND
3V3 ── 有源蜂鸣器 ── 集电极
             10kΩ：基极下拉到 GND
```

- `1kΩ` 限制基极电流；
- S8050 作为低边开关，让 GPIO 不直接承担蜂鸣器电流；
- `10kΩ` 下拉保证 ESP32-S3 复位或启动时蜂鸣器默认关闭；
- 若使用采购清单中的三针有源蜂鸣器模块，模块已经带驱动，直接将 `I/O` 接 GPIO21，不要重复串联该驱动级；
- 若改用电磁式两针蜂鸣器，应根据器件说明增加反向续流二极管。

### 验收

1. 上电和复位时不应持续误鸣；
2. GPIO21 输出高电平时蜂鸣器响，低电平时停止；
3. 三极管与 ESP32-S3 必须共地。

## L3：I2C 环境节点

三个模块共用两根总线：

| 模块 | 地址 | 供电 | SDA | SCL |
|---|---:|---|---|---|
| SCD40/SCD41 | `0x62` | 3.3V | GPIO8 | GPIO9 |
| SHT40 | `0x44` | 3.3V | GPIO8 | GPIO9 |
| BH1750 | `0x23` | 3.3V | GPIO8 | GPIO9 |

EasyEDA 中 J1、J2、J3 的教学接口统一定义为：

```text
1=3V3，2=GND，3=SDA/GPIO8，4=SCL/GPIO9
```

实际模块的物理针脚顺序可能不同，接线时必须看模块丝印，不能只按连接器序号照搬。

R1、R2 是 4.7kΩ 可选上拉，标记为 DNP。多数成品模块已经带上拉；只有确认整条总线没有上拉时才安装，避免并联过多上拉导致等效阻值过低。

### 验收

1. 先只接一个模块运行 I2C 扫描；
2. 依次加入另外两个模块；
3. 应同时发现 `0x62`、`0x44`、`0x23`；
4. 任一模块加入后总线失效，优先检查 VCC/GND、SDA/SCL 反接和上拉阻值。

## L4：HomeGuard Mini 完整系统

### 总线和引脚

| 功能 | 模块信号 | ESP32-S3 |
|---|---|---|
| I2C | SDA / SCL | GPIO8 / GPIO9 |
| 雷达 UART | LD2410C TX / RX | GPIO17 / GPIO18 |
| 麦克风 I2S | WS / BCLK(SCK) / SD | GPIO4 / GPIO5 / GPIO6 |
| 屏幕 SPI | SCK / MOSI / MISO / CS / DC | GPIO10 / GPIO11 / GPIO12 / GPIO14 / GPIO15 |
| 蜂鸣器 | I/O | GPIO21 |
| 学习按键 | 按下接地 | GPIO38 |
| 静音按键 | 按下接地 | GPIO39 |

### 本页实际接口定义

- `J4`，I2C 扩展：`1=3V3, 2=GND, 3=SDA, 4=SCL`；SCD41、SHT40、BH1750 可通过转接线并到同一总线；
- `J5`，雷达 UART：`1=外部5V, 2=GND, 3=UART_TX, 4=UART_RX`；模块 TX 应接主控 RX，模块 RX 应接主控 TX；
- `J6`，INMP441/I2S：`1=3V3, 2=GND, 3=WS, 4=BCLK/SCK, 5=SD, 6=GND`；第 6 脚把 L/R 选择固定为低；
- `CN1`，SPI 屏幕：`1=3V3, 2=GND, 3=SCK, 4=MOSI, 5=MISO, 6=CS, 7=DC, 8=3V3`；第 8 脚用于背光或固定高电平控制；
- `R5、R6、Q2、BZ2` 是板上的蜂鸣器驱动级，不是额外的四针蜂鸣器模块；
- `R7+SW2` 是学习键，`R8+SW3` 是静音键，均为 10kΩ 上拉、按下接地。

特别注意：`J5.1` 的 5V 是外部 5V 电源轨。原理图中 U4 的 5V 引脚（U4.21）明确标为 NC，不能把 J5.1 理解成由 U4.21 输出。制作 PCB 前必须先确定 5V 从 USB、独立接口还是稳压电源进入。

### 推荐调试顺序

1. ESP32-S3 单板上电；
2. LED 与按钮；
3. ILI9341；
4. SCD41、SHT40、BH1750；
5. LD2410C；
6. INMP441；
7. 蜂鸣器和两个按钮；
8. 最后启用 Wi-Fi、网页和本地异常检测。

每加入一个模块就单独验收，不要一次接完再排查。

## 应用场景

### 家庭与租房环境管家

监测 CO₂、温湿度、光照、声音趋势和区域内是否有人，在彩屏和本地网页显示状态。适合书房、卧室、出租房客厅的通风与环境提醒。

### 本地异常检测学习机

ESP32-S3 在本地学习正常环境的均值与波动，发现多个指标的异常组合。数据默认不上传云端，适合学习边缘 AI、特征工程和在线统计。

### 教室、会议室或工作室通风提醒

根据真实 CO₂浓度提示开窗通风，并结合人员存在状态减少无人时的无效报警。

### 多传感器嵌入式开发模板

该系统同时覆盖 GPIO、I2C、UART、I2S、SPI、Wi-Fi、显示与人机交互，可以作为后续数据记录器、智能仪表和 TinyML 项目的硬件模板。

## 从原理图走向 PCB 前

当前 L4 是开发板和成品模块组成的模块级原理图。制作自定义 PCB 前还需要：

1. 确认每个实物模块的连接器方向和针脚顺序；
2. 为每个模块接口补充就近 100nF 去耦，并评估 3.3V 总电流；
3. 给 5V 和 3.3V 电源增加测试点；
4. 明确连接器防反插方式；
5. 完成 ERC/DRC、封装核对和 1:1 打印检查；
6. 先做面包板或洞洞板原型，全部稳定后再下单 PCB。
