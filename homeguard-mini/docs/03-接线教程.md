# 03 逐根接线教程

## 安全规则

1. 接线时拔掉 USB；
2. 只连接本教程中的 3.3V/5V 低压模块；
3. 不拆插座、不接市电、不制作 220V 继电器；
4. 每接完一个模块先检查 VCC 和 GND，再上电；
5. 不同模块必须共地。

ESP32-S3 不同厂家的物理排针位置可能不同，必须看开发板丝印找 `GPIO8` 等编号，不能照照片猜第几个孔。

## 推荐接线顺序

不要一次把所有模块堆上去。依次完成：

1. ESP32-S3 单板上电；
2. ILI9341 屏幕；
3. SCD41；
4. SHT40；
5. BH1750；
6. LD2410C；
7. INMP441；
8. 蜂鸣器和两个按钮。

每一步重新检查，再继续下一步。出现故障时就能知道是刚加入的模块或线路导致。

## I2C 为什么可以并联

SCD41、SHT40 和 BH1750 都使用 SDA/SCL，但地址不同：

- SCD4x 通常为 `0x62`；
- SHT40 通常为 `0x44`；
- BH1750 通常为 `0x23`。

因此它们可以共用 GPIO8 和 GPIO9。模块通常已经带上拉电阻，原型阶段不额外添加。

## 上电前最终检查

- 3V3 与 GND 之间没有明显短路；
- INMP441 没接 5V；
- LD2410C 的 TX 接 GPIO17，而不是 TX 接 TX；
- 按钮按下时只是 GPIO 与 GND 相连；
- 屏幕的 MOSI 没误接到 MISO；
- 所有模块 GND 都与 ESP32 GND 相连；
- 没有裸露线头碰到相邻排针。
