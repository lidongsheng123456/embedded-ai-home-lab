# 07 从面包板到一体化设备

## 为什么不能直接把面包板塞进盒子

面包板适合验证，但长期使用可能接触不良。正确顺序是：

```text
面包板逐模块验证 → 连续运行 48 小时 → 洞洞板焊接 → 外壳 → 自制 PCB
```

## 洞洞板版本

第一次做硬件，建议把 ESP32-S3 和各模块做成可插拔结构：

- ESP32-S3 使用两排母座，不直接焊死；
- SCD41、SHT40、BH1750 使用 4Pin 插座；
- LD2410C 和 INMP441 使用排母；
- 电源主线用稍粗导线；
- 每个接口丝印或手写 VCC、GND 和信号名称；
- 焊好后用万用表通断档确认 3V3 与 GND 没短路；
- 第一次上电不要装外壳，观察是否异常发热。

## 外壳布局

建议外壳约 160 mm × 100 mm × 55 mm，具体按实物调整。

```text
正面
┌──────────────────────────────┐
│ SCD进气孔            麦克风孔 │
│                              │
│        ILI9341 彩屏           │
│                              │
│ [重新学习]        [静音]      │
│                              │
│ SHT通风孔  雷达塑料窗口 光照孔│
└──────────────────────────────┘
侧面：USB-C、电源开口
背面：大面积通风孔和壁挂/桌面支撑结构
```

关键规则：

- SCD41 与 SHT40 不要紧贴 ESP32、电源稳压器和屏幕背光，它们会发热；
- SCD41 周围必须有空气交换，但不能让风扇直接吹；
- LD2410C 前方使用普通塑料薄壁，不放金属网和覆铜板；
- 麦克风开孔不要被胶水堵住；
- BH1750 前方使用透明或开孔结构；
- 蜂鸣器独立开孔；
- USB 插口不能承受外壳挤压；
- 不要做完全密封外壳。

## 自制 PCB 建议

新手第一块 PCB 建议做“开发板载板”，仍然插 ESP32-S3 DevKitC-1 和传感器模块，不直接使用裸 ESP32-S3-WROOM 和裸 SCD41。

原理图至少包含：

- ESP32-S3 两排母座；
- 5V、3V3 和 GND 电源网络；
- 每个模块的带方向插座；
- I2C SDA/SCL 测试点；
- UART RX/TX 测试点；
- 两个按钮；
- 蜂鸣器模块接口；
- 3V3 总线 10 µF 电容；
- 每个传感器电源附近 100 nF 去耦电容；
- 安装孔和明确丝印。

布局注意：

- ESP32 天线伸出 PCB 边缘，天线下方及前方禁止铺铜、走线和放金属；
- SCD41/SHT40 放在远离发热器件的板边；
- INMP441 远离蜂鸣器，避免啸叫和机械耦合；
- LD2410C 天线正前方不放屏幕、覆铜或连接器；
- 底层尽量保持完整 GND；
- I2C 线尽量短；
- GPIO4/5/6 的 I2S 线远离蜂鸣器输出；
- 下单前运行 ERC 和 DRC；
- 打印 1:1 纸张，把所有模块放上去核对排针间距、方向和外壳孔位。

不要在第一块 PCB 上加入锂电池充电、电池保护或 220V 电路。首版用合格的 USB 适配器供电。
