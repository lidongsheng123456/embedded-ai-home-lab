# 05 首次启动与分阶段验收

## 阶段一：只验证开发板和屏幕

接好屏幕，其他模块可以先不接。烧录后应看到 `HomeGuard Mini` 启动画面，随后进入状态页。

如果白屏：

- 检查背光 LED/BL 是否供电；
- 检查 CS、MOSI、SCLK、DC、RST；
- 确认购买的是 ILI9341 SPI 屏；
- 屏幕排线很长时把 `platformio.ini` 中 `SPI_FREQUENCY` 从 27000000 改为 20000000。

## 阶段二：验证三个 I2C 传感器

依次加入 SCD41、SHT40 和 BH1750。串口应显示：

```text
SCD4x=1 SHT4x=1 BH1750=1
```

SCD41 启动后约 5 秒才产生第一组 CO₂数据。刚上电时显示 0 不代表损坏。

简单测试：

- 在传感器附近呼气，CO₂应明显上升；
- 用手握住 SHT40 附近，温湿度应变化；
- 用手遮住 BH1750，lux 应下降。

不要直接向 SCD41 吹气或用水汽测试，避免冷凝。

## 阶段三：验证毫米波

串口启动信息应有 `LD2410=1`。站到模块正前方 1～3 m，网页的“人体存在”应显示“有人”；离开检测范围一段时间后变为“无人”。

如果一直有人：

- 模块是否朝向风扇、窗帘或空调摆风；
- 背后是否有走动的人；
- 模块灵敏度可能过高，后续可用 HLKRadarTool 手机应用调节；
- 不要让雷达正对薄墙、窗户或走廊。

## 阶段四：验证麦克风

安静房间中声音指数应较低，拍手时明显升高。它不是分贝值，不同 INMP441 模块的绝对数字可能不同。

如果始终为 0：

- 检查 L/R 是否接 GND；
- 检查 SCK、WS、SD 是否接反；
- 检查 VDD 是否为 3.3V。

如果始终接近 100，可能是麦克风焊接不良、数据脚悬空或公式需要根据模块增益校准。先检查接线，不要立刻修改报警阈值。

## 阶段五：验证蜂鸣器和按钮

- 湿度或 CO₂达到警告条件时蜂鸣器间歇响；
- 按“静音”按钮后停止 10 分钟；
- 按“学习”按钮后网页样本数从 0 重新开始；
- 如果蜂鸣器上电一直响，购买的模块可能是低电平触发版。换高电平触发模块，或在代码中反转输出逻辑。

## 阶段六：验证网页

屏幕底部会显示地址，例如：

```text
http://192.168.1.35
```

手机必须和 ESP32 处于同一局域网。打不开时先在电脑浏览器尝试，再检查路由器是否开启“AP隔离/客户端隔离”。公司和校园网络通常会隔离设备，首次测试推荐手机热点。

所有阶段都通过以后，才进入洞洞板和外壳制作。
