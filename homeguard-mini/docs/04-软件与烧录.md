# 04 软件安装、编译和烧录

## 1. 安装开发环境

安装 Visual Studio Code，然后在扩展商店安装 `PlatformIO IDE`。安装完成后重启 VS Code。

不要同时用 Arduino IDE 打开同一个串口，否则 PlatformIO 串口监视器可能无法连接。

## 2. 打开正确的文件夹

在 VS Code 中选择 `文件 → 打开文件夹`，打开：

```text
D:\idea_project\embedded_project\homeguard-mini\firmware
```

必须打开 `firmware`，因为 `platformio.ini` 在这里。

## 3. 设置 Wi-Fi

在项目根目录执行：

```powershell
Copy-Item firmware\include\app_config.example.h firmware\include\app_config.h
```

编辑 `firmware/include/app_config.h`：

```cpp
#define HOME_WIFI_SSID "你的2.4GHz WiFi名称"
#define HOME_WIFI_PASSWORD "你的WiFi密码"
#define DEVICE_HOSTNAME "homeguard-mini"
#define FALLBACK_AP_NAME "HomeGuard-Mini"
#define FALLBACK_AP_PASSWORD "请换成至少8位的新密码"
```

注意：

- ESP32-S3 只连接 2.4 GHz Wi-Fi；
- 配置文件已加入 `.gitignore`，不会提交到 Git；
- 不想配置家庭 Wi-Fi也能使用，设备会开启自己的热点；
- 手机连设备热点时可能提示“无法访问互联网”，选择保持连接。

## 4. 首次编译

点击 VS Code 底部的对勾图标，或在 PlatformIO 面板执行：

```text
PROJECT TASKS
└─ esp32-s3-devkitc-1
   └─ General
      └─ Build
```

第一次会下载 ESP32 工具链和库，可能需要数分钟。成功结尾为：

```text
========================= [SUCCESS] =========================
```

如果某个依赖下载失败，先检查网络，然后再次 Build；PlatformIO 会复用已经下载的文件。

## 5. 烧录

1. 使用支持数据传输的 Type-C 线连接开发板；
2. 在 PlatformIO 执行 Upload；
3. 如果一直停在 `Connecting...`：按住 BOOT，短按一次 RESET，看到开始写入后松开 BOOT；
4. 烧录完成后开发板自动重启。

## 6. 查看串口

执行 Monitor，波特率已配置为 115200。正常启动信息类似：

```text
Connecting to Wi-Fi ...
Wi-Fi connected: http://192.168.1.35
Sensors: SCD4x=1 SHT4x=1 BH1750=1 LD2410=1
CO2=612 temp=24.7 hum=51.3 lux=86 sound=18 presence=1 AI=0.00 samples=1 level=0
```

数字 `1` 表示识别成功，`0` 表示对应模块没有识别到。不要在模块识别失败时继续装外壳。

## 7. 不配置 Wi-Fi 的启动方式

设备无法连接家庭 Wi-Fi 时会创建热点。手机连接后访问：

```text
http://192.168.4.1
```

网页由 ESP32-S3 自己提供，不需要 Python、Docker、Java 或云服务器。
