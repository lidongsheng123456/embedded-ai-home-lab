# 学习区规约

本目录继承仓库根目录的 `AGENTS.md`，并补充以下规则。

- `docs/` 只放教程；`examples/` 只放可构建工程。
- STM32F103 示例统一位于 `examples/stm32f103-hal/`，每个 PlatformIO 环境对应一个明确案例。
- ESP32-S3 示例统一位于 `examples/esp32-s3/`，使用 Arduino Core；每个 PlatformIO 环境对应一个明确案例。
- 新案例文件名采用 `章节号 + a/b + 主题`，例如 `04a_uart_print.c`。
- 示例必须有中文文件头，写明板卡、接线、预期现象和电平限制。
- 面向新手时先给点击路径和观察结果，再解释 HAL 结构体、寄存器或协议名词。
- 不在教程中写死个人电脑绝对路径；使用仓库相对路径和“选择文件夹”的描述。
- 后续章节不得破坏前面章节的独立编译。
- Wi-Fi、令牌等私密配置只提交 `.example` 模板，案例在缺少私密配置时仍必须能够编译。
