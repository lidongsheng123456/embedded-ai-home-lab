## 装配物料还未齐全

用户本次说明载板焊接元件尚未购买，当前32种料号、每板78个器件统一记为待补齐；已购买的外接模块不能当作这些元件的库存。完整清单只维护在[材料文档](02-材料清单.md#载板待补齐完整32种料号)，含型号、位号、用量和商城料号，不另建重复采购表。

开始装配前还需确认厂家包料或来料代焊、67个纯贴片元件与10个通孔插座及1个混合USB-C的焊接范围、配对线束和模块实物。只制PCB空板不能进入整机上电验收，设计检查通过也不代表物料已买齐。

## 上电前已确定的条件

- 用户已有专用 5V/3A 电源和对应线；这是电源能力，不是整机可用 3A 的保证，载板典型限流约 2.04A。
- 开发板按厂家图短接 IN/OUT 两焊盘，**不是短接 5V/GND**。位置已给出，实物尚未焊接。
- 烧录：断载板电源 → 取下开发板 → 接电脑 USB → 拔 USB → 装回 → 上电。不同时接排母供电和开发板 USB。
- 外围独立 3.3V 不与开发板 3.3V 并联。机械按厂家双排 22 针、25.40 mm 排距、53.34 mm 首尾针距设计，未实物套合。

操作见[供电说明](../eda/hardware/docs/header-power-review.md)和[首板验收](../eda/hardware/docs/first-board-validation.md)。

## 仍然存在的使用限制

| 限制 | 意味着什么 |
| --- | --- |
| 慢网页/拍照仍占用主循环 | 可能推迟下一声提醒、静音和学习操作；恢复后不补响 |
| 按键事件会合并 | 不保证保留连点次数/顺序；任务迟到仍可能漏采 |
| 雷达只解析当前已支持格式 | 不能检出所有数据位错误，真实协议和串口噪声待测 |
| 音频全零有歧义 | 可能安静，也可能数据线固定为0，必须拍手验证 |
| 网页没有账号认证 | 同网用户可能读取/控制，不开放公网 |
| 独立任务也有调度延迟 | 雷达接收、按键记录、蜂鸣器关闭均没有实测响应保证 |

HomeGuard Mini 是学习和辅助提醒设备，不能替代经过认证的烟雾、燃气或一氧化碳报警器。上述检查不等于首板实测通过。
