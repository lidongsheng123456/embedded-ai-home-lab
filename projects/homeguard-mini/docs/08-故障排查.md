# 08 出问题，先查这一张表

**先断电，撤掉刚加入的模块，回到最后一次成功状态。一次只改一处，再观察。** 不同时换电源、改代码、换引脚。

## 编译、烧录、串口

| 现象 | 先做什么 |
| --- | --- |
| 很多红线 / 没有PlatformIO任务 | 打开整个 `homeguard-mini/firmware`，顶层应直接有 `platformio.ini` |
| Build失败 | 看第一条实际错误；先排下载依赖、Node/npm和选错环境，按[04](04-软件与烧录.md)核对 |
| 卡在Connecting | 用数据线接原生USB；按住BOOT、短按RESET，开始写入再松BOOT |
| Upload成功却没日志 | 固件日志走原生USB；拔插观察对应COM，Monitor设115200，按RESET |
| COM被占用 | 关闭VOFA、串口助手和其他Monitor；同一时刻只留一个软件 |
| 一直重启 / Brownout | 先撤外设只留开发板，查电源压降、反接、短路；不要同时从多处给开发板供电 |

载板烧录先断电取下开发板，烧完拔USB再装回。它运行时不接开发板USB，用屏幕/网页观察；不要为看Monitor违反供电方案。

## 模块与网页

| 现象 | 按顺序核对 |
| --- | --- |
| 屏幕黑/白 | ST7789 VCC和BLO接3.3V；SCL12、SDA11、RES15、DC14、CS10；选ST7789环境 |
| 颜色/位置错 | 核对240×240屏型号和驱动；红蓝颠倒查RGB顺序，不盲目改线 |

| 雷达未知 | 5V；模块TX→17、RX→18、共地；默认256000，OUT不接；曾改参数要核对模块设置 |
| 雷达一直有人 | 查正面风扇/窗帘/走廊和薄墙影响，调整摆放再比较 |
| 麦克风始终0/接近100 | 3.3V、L/R接地、BCLK4/WS5/SD6；缩短线；拍手检查，别先提高阈值 |
| 相机初始化失败 | 只接相机，烧 `camera_ov2640_check`；先看PSRAM found=1，再逐根核对[相机表](03-接线教程.md#第七步ov2640独立验机接线) |
| 相机能初始化但取图失败 | 短线、稳定供电、N16R8配置；先保持640×480，不提高分辨率或连续刷新 |
| 网页打不开 | 用屏幕实际IP；同一局域网，路由器不隔离客户端；连热点后选择保持连接，必要时暂关移动数据 |
| 蜂鸣器一直响 | 模块应为3.3V高触发、自带驱动，I/O接21；断电拆I/O后再上电比较，核对模块类型 |
| AI一直提醒 | 先看触发原因，再查MQ-2预热、温度受热、传感器有效性；正常环境重新学习，别无限抬阈值 |
| 优惠券只支持OSP | 订单工艺与券不匹配，按[打样说明](07-一体化制作.md#弹窗说优惠券仅支持osp怎么办)选择；不是电路故障 |

## 三个最容易误判的情况

1. **有数字不等于传感器接好了。** MQ-2接ADC，悬空也可能有数。先测电压；GPIO3必须低于3.3V。载板AO接J1.3，已有10kΩ/10kΩ，不再叠面包板分压。
2. **雷达 `receiver=1` 不等于接收成功。** 只证明任务创建；收到有效报告才显示有人/无人，500ms没报告为未知。`receiver=0`或`RX buffer allocation failed`先查启动和内存。固件只读取，不自动恢复模块设置。
3. **读到全零音频不一定是安静。** 数据脚固定在0也可能读成功，必须用拍手验证。

## 相机接线特别提醒

- PCLK=16、VSYNC=47、HREF=48；**GPIO44有板载CH343输出，不能接PCLK**。
- RST接3.3V，PWDN接GND；SDA8/SCL9，D0～D7按表，不按相似照片猜。
- 模块必须是带板载晶振版本；GPIO43是驱动占位输出，保持不接。
- N16R8内存相关GPIO35～37不用于外设。

实物与图片不同先停下核对。闻到燃气、看见烟雾或正规报警器响时，按现实安全流程处理，不等待本项目结论，也不制造危险来测试。
