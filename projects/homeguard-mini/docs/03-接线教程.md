# 03 从一根线开始的接线教程

**这页的逐根线表用于面包板。载板使用直插排母或转换线，不照搬开发板电源脚。**

| 你用什么 | 先读哪里 |
| --- | --- |
| 面包板 | 本页，按屏幕→环境传感器→气体→雷达→麦克风→按钮→相机，每次只加一件 |
| R2载板 | [插座针序](../eda/hardware/README.md) + [首板上电](../eda/hardware/docs/first-board-validation.md)，使用 `carrier_r1_*` |

当前装配方案：开发板、麦克风直接插载板；MQ-2、LD2410C和ST7789通过各自2.54mm排母接公对母杜邦线，固定到外壳指定位置。麦克风仍为独立单孔座组成的2×3阵列，按图片2.6mm/7.3mm排布。其余XH口使用匹配插头的转换线，相机使用专用短转换线。位置、线长起点见[装配表](07-一体化制作.md#模块固定还是接线)，朝向、位号和NC见[接口表](../eda/hardware/README.md)。

载板外围用独立3.3V，开发板由J7.21供5V（按厂家图短接IN/OUT），两路3.3V不并联。板上MQ-2已有10kΩ/10kΩ分压，不外加第二套。

找某个模块：[屏幕](#第一步只接st7789屏幕) · [温湿度/光照](#第二步接sht40和bh1750) · [MQ-2](#第三步搭mq-2安全分压) · [雷达](#第四步接ld2410c) · [麦克风](#第五步接inmp441) · [按钮](#第六步蜂鸣器和按钮) · [相机](#第七步ov2640独立验机接线)。

## 底面接线表怎么看

底面白字是接线备忘，实际插线在顶面完成。先拔掉电源，在顶面找到接口编号，再找旁边的“1”或三角形1脚标记，按[接口表](../eda/hardware/README.md#接口表)的编号方向数脚。单排从1脚顺序数；摄像头双排座按专门转换表找脚，不能沿一排直接数完。

例如底面写“J1 气体MQ-2 / 5V”，表示编号为J1的插座用于MQ-2，电源是5V。“1脚接AO”中的1是**J1的插座脚号，不是GPIO1**：

| 载板J1 | 用杜邦线接到MQ-2哪里 |
| --- | --- |
| 第1脚 | AO：气体模拟输出，提供随气体变化的电压 |
| 第2脚 | 不接线，模块DO脚留空 |
| 第3脚 | GND：地，通常是电源负极 |
| 第4脚 | VCC：模块电源，此处为5V |

VCC/VDD表示模块电源名称，具体电压看该接口标题，不能看到VCC就一律接5V；3V3就是3.3V。GND是地；NC或“不接”表示该孔留空。GPIO是主控用来收发信号的脚。

SDA通常是数据线，SCL通常是节拍线；屏幕的同名脚用于SPI，不能因此插到I2C扩展口。TX是发送、RX是接收；雷达表中的TX/RX指**雷达模块上印的名字**，按表接到载板对应脚即可，板内已连到主控的接收/发送脚。

翻到底面看时左右会交换，**不要按底面文字所在的位置猜插孔，也不要把整排线按颜色直接照搬**。2.50mm的XH插头与2.54mm杜邦头不能硬插。摄像头必须按[逐根转换表](../eda/hardware/docs/camera-adapter.md)制作短线：J12.19接模块PWDN、J12.20接模块RST；这两根在载板侧分别接地、3.3V，用于让模块正常工作，不能误接模块的同名电源脚。

## 接线前的五条规则

1. 改线前拔掉两个Type-C接口和外部5V；
2. 模块VCC先查丝印，再决定接3.3V还是5V；
3. 所有模块GND必须与ESP32 GND相连，这叫共地；
4. GPIO只能接受0～3.3V；
5. 每增加一个模块就上电验收，不一次全部接完。

你的N16R8使用OPI PSRAM，GPIO35、36、37不要连接外设。完整摄像头环境在GPIO43输出占位时钟，
因此烧录和串口监视使用开发板上标为USB的原生USB口，不使用标为UART的Type-C口。

## 第一步：只接ST7789屏幕

| ST7789V | ESP32-S3 | 作用 |
|---|---|---|
| GND | GND | 电源负极 |
| VCC | 3V3 | 屏幕电源，不能接5V |
| SCL | GPIO12 | SPI时钟 |
| SDA | GPIO11 | SPI数据，也叫MOSI |
| RES | GPIO15 | 屏幕复位 |
| DC | GPIO14 | 数据/命令选择 |
| CS | GPIO10 | 片选 |
| BLO | 3V3 | 背光常亮 |

这里的SDA不是I2C SDA，只是商家对SPI数据脚的命名。上传core_st7789_154，屏幕出现
“居家环境助手”启动提示和中文数据栏目才继续。

## 第二步：接SHT40和BH1750

两个模块共享同一组I2C线：

| 模块 | 模块引脚 | ESP32-S3 |
|---|---|---|
| SHT40 | VCC | 3V3 |
| SHT40 | GND | GND |
| SHT40 | SDA | GPIO8 |
| SHT40 | SCL | GPIO9 |
| BH1750 | VCC | 3V3 |
| BH1750 | GND | GND |
| BH1750 | SDA | GPIO8 |
| BH1750 | SCL | GPIO9 |

它们能共用两根线，是因为地址不同：SHT40通常为0x44，BH1750通常为0x23。

## 第三步：搭MQ-2安全分压

### 为什么不能直接接

MQ-2模块使用5V供电，你此前订单标注AO可能约4V，其他版本也可能更高，超过ESP32允许的3.3V。DO则直接输出0V或5V，本项目
不使用DO。

### 分压电路

    MQ-2 VCC ───────── 5V
    MQ-2 GND ───────── GND

    MQ-2 AO ── 10kΩ ──┬── GPIO3
                       └── 20kΩ ── GND

20kΩ可以由两只10kΩ串联得到。中间连接点才接GPIO3，不要把AO直接接GPIO3。

上述面包板接法适用于已确认 AO 最高约 4 V 的模块。若 AO 可能接近 5 V，应把下方电阻改为 10 kΩ，并使用下面的载板编译环境以匹配分压系数。

R2 载板已在板上设计 10 kΩ / 10 kΩ 分压和 100 nF 滤波，使用 `carrier_r1_core_st7789` 或 `carrier_r1_full_st7789_camera`。MQ-2 原始 AO 直接接载板 J1 的 3 脚，不再外加面包板分压。J1 的 1、2 脚分别为 +5V、GND；转换线按模块丝印接，不能假定针序相同。整板设计状态见[载板说明](../eda/hardware/README.md)。

第一次上电先不要接GPIO3：

1. 给MQ-2的VCC和GND供电；
2. 万用表黑表笔接GND，红表笔测分压中点；
3. 确认中点始终低于3.3V；
4. 断电后再把中点连接GPIO3。

金属网在工作时温热属于正常现象。不要用打火机放气或明火测试。

## 第四步：接LD2410C

你购买的模块针脚从图片可读为TX、RX、OUT、GND、VCC：

| LD2410C | ESP32-S3 |
|---|---|
| VCC | 5V |
| GND | GND |
| TX | GPIO17，ESP接收 |
| RX | GPIO18，ESP发送 |
| OUT | 不接 |

TX必须接对方RX，RX必须接对方TX。雷达默认波特率为256000。

## 第五步：接INMP441

先拔掉开发板USB和外部5V电源，再连接麦克风。

你提供照片中的圆形模块，下排中间的字样看起来像“HS”，对应本教程的 **WS**。
WS是控制左右声道采样节奏的信号，也叫LRCLK（部分模块标LRCL），接 **GPIO5**。
这项对应仅针对你照片中的模块，不代表其他器件上标“HS”的脚也能这样接。

按照片方向，找到 **L/R在左、SCK在右** 的这一排：

```text
模块下排：  L/R       WS（看起来像HS）       SCK
接ESP32：   GND            GPIO5           GPIO4
```

| INMP441 | ESP32-S3 |
|---|---|
| VDD | 3V3 |
| GND | GND |
| SCK/BCLK | GPIO4 |
| WS/LRCLK/LRCL（你的模块照片下排中间，看起来像HS） | GPIO5 |
| SD | GPIO6 |
| L/R | GND |

**VDD只能接3.3V，不能接5V。GND和L/R都接ESP32的GND**，可以共用面包板接地轨。
L/R接GND表示使用左声道，悬空可能导致始终读不到声音；不要把L/R接到GPIO5。

接好后上电，在距离模块约1～2米处拍手，观察屏幕和网页的“声音指数”是否明显升高。
该数值是相对声音强度，不是分贝，也不表示已经识别出具体声音。
引脚对应已按照片与固件定义核对，实际采音效果仍需完成这一步实物确认。

## 第六步：蜂鸣器和按钮

| 器件 | 连接 |
|---|---|
| 蜂鸣器VCC | 3V3 |
| 蜂鸣器GND | GND |
| 蜂鸣器I/O | GPIO21 |
| 静音/多功能按钮一端 | GPIO39 |
| 按钮另一端 | GND |

蜂鸣器应是**3.3V供电、高电平触发、自带驱动的有源模块**，不能把裸蜂鸣器直接接GPIO。
按钮使用松手弹回的常开按钮。四脚或六脚按钮先断电用万用表确认：选“未按不通、按住接通、
松手断开”的两个脚分别接GPIO39和GND，其他脚留空，不接5V或3.3V。

**GPIO39是静音键，按下不会让蜂鸣器试响。** 按住约半秒再松开后，大屏应显示静音剩余分钟；
串口会输出`Alarm silenced for 10 minutes`。大屏已移除调试按钮，保留同源短响接口供接线验机：
在电脑打开设备网页，按F12进入Console（控制台），手动执行一次：

```javascript
fetch('/api/buzzer-test', { method: 'POST' }).then(response => console.log(response.status));
```

202表示请求已收到，是否发声仍要看实物。它只输出固定0.2秒、不调用云服务，静音时也能测试。
不需要制造烟雾。无声音时核对模块型号及VCC/GND/I/O接线，不反复连续执行。

在无摄像头的core_st7789_154环境中，还可以增加：

| 器件 | 连接 |
|---|---|
| 重新学习按钮一端 | GPIO38 |
| 重新学习按钮另一端 | GND |

full_st7789_camera环境把GPIO38用于图像数据，因此只保留GPIO39。R2载板的两个编译环境也统一使用GPIO39单按钮：

- 短按后松开：静音10分钟；
- 按住至少2秒再松开：重新学习。

## 第七步：OV2640独立验机接线

购买的模块带板载有源晶振，没有MCLK针。按照板上丝印连接：

| OV2640 | ESP32-S3 |
|---|---|
| 3.3 | 3V3 |
| GND | GND |
| SCL | GPIO9 |
| SDA | GPIO8 |
| D0 | GPIO1 |
| D1 | GPIO2 |
| D2 | GPIO7 |
| D3 | GPIO13 |
| D4 | GPIO38 |
| D5 | GPIO40 |
| D6 | GPIO41 |
| D7 | GPIO42 |
| PCLK | GPIO16 |
| VSYNC | GPIO47 |
| HREF | GPIO48 |
| RST | 3V3 |
| PWDN | GND |
| FLASH | 暂时不接 |

GPIO43保持悬空。固件会在GPIO43生成一个未连接的占位XCLK，只为满足ESP32 Camera驱动
的初始化要求；摄像头模块实际使用板载有源晶振。

GPIO44连接开发板CH343的发送输出，因此摄像头PCLK改用GPIO16。不要把旧版接线图中的
GPIO44继续接到PCLK；只拔掉UART口的USB线不能证明CH343输出已断开。

摄像头D0～D7、PCLK、VSYNC和HREF属于高速信号，母对母杜邦线尽量短于10cm。第一次只接
摄像头并上传camera_ov2640_check，不连接屏幕和其他传感器。

## 载板新增功放接口

这是 R2 精简载板 J13 的接法。使用已购 MAX98357A 模块与 4Ω/3W 喇叭，不把裸喇叭接 GPIO。本轮完成硬件接口，**现有程序尚不能通过它播放声音**；原蜂鸣器仍用于提醒。

| J13脚号 | 载板网络 / GPIO | MAX98357A模块 |
| --- | --- | --- |
| 1 | MIC_WS / GPIO5 | LRC / LRCLK |
| 2 | MIC_BCLK / GPIO4 | BCLK |
| 3 | AUDIO_DOUT / GPIO45 | DIN |
| 4 | NC，不接铜线 | GAIN，默认增益 |
| 5 | +5V | SD，常开使能 |
| 6 | GND | GND |
| 7 | +5V | VCC |

按用户确认的模块文字面左→右七针顺序制作短线：LRC、BCLK、DIN、GAIN、SD、GND、VCC。J13为2.54mm七孔排母，公对母杜邦线逐脚对应，无需交叉跳线；GAIN孔保留但不接铜，SD已在载板接5V（默认9dB，左声道）；喇叭接 OUTP/OUTN（或模块标出的 +/− 输出），**任一输出都不能接地**。GPIO45 是启动配置脚，板上 R22=10kΩ 下拉必须装，不得再接上拉或输出器。

GPIO4/5 与 INMP441 共用音频时钟，但数据线分开：麦克风 SD→GPIO6，功放 DIN←GPIO45。后续软件需实现同一 I2S 的全双工收发及静音时钟管理，不能同时启动两个相互争用时钟的驱动；本次没有修改固件。首次播放从小音量开始，验证全负载电流、5V压降与麦克风反馈，3W不是建议持续最大音量。

## 通用学习排针：J21 / J22

J7/J8是插开发板的排母；它们外侧新增J21/J22公排针，左右对称，2.54mm针距。公排针与对应排母电气并联，作用是把原有引脚再引出一份，不会增加可独立使用的引脚。原理图的“06 通用学习扩展”页有对应网络、GPIO编号和中文说明。

从PCB顶面看，开发板天线端朝上、USB端朝下，两边都从上往下读1～22脚。板上`IO`就是GPIO，即程序可以读取或控制的信号脚；`NC`表示留孔但不接铜。EN是复位控制，不能作为普通GPIO。

| --- | --- | --- |
| 1 | MCU_3V3 | GND |
| 2 | MCU_3V3 | GPIO43 / TX0 |
| 3 | EN / 复位 | GPIO44 / RX0，受CH343限制 |
| 4 | GPIO4 / 麦克风、功放位时钟 | GPIO1 / 相机D0 |
| 5 | GPIO5 / 麦克风、功放声道时钟 | GPIO2 / 相机D1 |
| 6 | GPIO6 / 麦克风数据 | GPIO42 / 相机D7 |
| 7 | GPIO7 / 相机D2 | GPIO41 / 相机D6 |
| 8 | GPIO15 / 屏幕复位 | GPIO40 / 相机D5 |
| 9 | GPIO16 / 相机像素时钟 | GPIO39 / 板载按钮 |
| 10 | GPIO17 / 雷达接收 | GPIO38 / 相机D4 |
| 11 | GPIO18 / 雷达发送 | GPIO37：NC，不接线 |
| 12 | GPIO8 / I2C数据 | GPIO36：NC，不接线 |
| 13 | GPIO3 / MQ-2分压采样 | GPIO35：NC，不接线 |
| 14 | GPIO46，仅输入 | GPIO0 / BOOT |
| 15 | GPIO9 / I2C时钟 | GPIO45 / 功放数据 |
| 16 | GPIO10 / 屏幕片选 | GPIO48 / 相机行同步 |
| 17 | GPIO11 / 屏幕数据，主控侧 | GPIO47 / 相机场同步 |
| 18 | GPIO12 / 屏幕时钟，主控侧 | GPIO21 / 蜂鸣器控制 |
| 19 | GPIO13 / 相机D3 | GPIO20 / 原生USB D+ |
| 20 | GPIO14 / 屏幕数据命令选择 | GPIO19 / 原生USB D− |
| 21 | +5V，保险丝之后 | GND |
| 22 | GND | GND |

切换为学习用途：**断电 → 拔下对应模块连接线 → 接实验电路 → 烧录该实验程序**。麦克风为板上直插，要释放GPIO4/5/6需拔下麦克风，GPIO4/5还要断开功放线。只拔线而继续运行HomeGuard程序，原程序仍可能控制这些脚。

为了省成本没有给每个信号增加隔离跳帽。拔模块线后，下面这些板载电阻、电容或按钮仍在，实验时必须考虑：

| GPIO | 仍连接的载板外围 | 对学习的影响 |
| --- | --- | --- |
| 3 | R2=10kΩ下拉、C1=100nF对地；经R1=10kΩ到MQ-2 AO接口 | 不是空闲的裸模拟输入；学习排针位于分压后的主控侧，外接信号也只能到3.3V |
| 39 | SW1按钮、R3=10kΩ上拉到MCU_3V3、C7=100nF对地 | 适合按键实验；不要输出高电平时按下按钮造成输出对地 |
| 45 | R22=10kΩ下拉 | 保持启动默认低；不能外接强上拉或与其他输出相连 |
| 21 | R4=100kΩ下拉 | 拔蜂鸣器线后，下拉仍保留 |
| 8 / 9 | R8/R9=4.7kΩ上拉到外围+3V3 | 适合3.3V I2C；全部模块同电源工作，不带电拔插 |
| 10 / 15 | 屏幕默认电平电阻R18/R19=10kΩ上拉到外围+3V3 | 拔屏幕线后仍有上拉 |
| 11 / 12 | 学习排针直接接主控；屏幕接口侧分别串R21/R20=22Ω | 学习排针与屏幕接口不是串联电阻的同一侧 |

GPIO0/3/45/46涉及上电时选择启动方式，避免随意改变上下拉；GPIO46只能输入。GPIO35/36/37被N16R8开发板的内存占用，两侧母座与学习排针都不接铜，不能使用。

GPIO44接开发板CH343芯片的发送输出，不能把外部推挽输出再接上去；拔UART USB线不能证明这个输出已隔离。GPIO43在完整相机程序中仍输出占位时钟，GPIO19/20用于原生USB，改用途需换实验程序并考虑烧录连接。

**全部GPIO只允许3.3V逻辑。** J21上的MCU_3V3来自开发板，与载板给外围用的+3V3是两路不同电源，禁止并联；MCU_3V3可用外带电流未知，不用于电机、舵机、灯带等负载。此类负载要外部供电、驱动电路并与本板共地，不能直接由GPIO驱动。烧录仍按“断载板电源、取下开发板、接电脑USB；拔USB后再装回”的顺序。

J19/J20是另外两个低功耗3.3V I2C扩展口，针序为3V3、GND、SDA(GPIO8)、SCL(GPIO9)。它们与温湿度、光照、相机控制总线并联，复用R8/R9上拉；同地址模块不能直接并联，新增传感器仍需对应软件驱动。
