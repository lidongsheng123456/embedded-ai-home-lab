# 02 还缺什么，要买什么

**你之前买的是开发板和传感器模块，不代表载板上的小芯片、电阻、电容也买齐了。**
截至2026-11-12：载板焊接元件统一记为**待补齐**。先确认厂家是否包料，再买缺项。

| 材料分组 | 当前情况 | 现在怎么做 |
| --- | --- | --- |
| ESP32-S3开发板 | 已明确持有泽杰N16R8 | 保留整块开发板，插在载板排母上，不另买裸ESP32芯片。 |
| 屏幕和传感器模块 | 之前按订单确认过选型；不等于逐件已到货验收 | 按[外接模块表](#外接模块)核对实物。 |
| 专用5V/3A电源和对应线 | 你已明确确认有 | 不重复买，首板仍需测实际压降和负载。 |
| 焊在载板上的元件 | **待补齐：32种料号、每块板78个器件** | 按下方完整表补齐，或由厂家按同一清单包料。 |
| 模块转换线、配对插头 | 未逐项确认 | 见[线束与装配](#线束与装配也要准备)，普通杜邦线不一定能插载板接口。 |

## 先分清空板与装好元件的板

- **PCB打样**：只制造带铜线、孔和文字的板子，通常不会帮你买元件、焊芯片。
- **物料清单（BOM）**：告诉装配厂家每个位置焊什么型号、焊多少个。下面的表供核对材料；正式装配文件仍从当前原工程生成。
- **贴片装配（SMT）**：把小元件焊到板面；是否包含采购，需要看厂家报价，不能只看“打样成功”。
- **插件焊接**：把插座等引脚穿过板孔再焊，常需单独安排。

当前每块载板共78个器件：**67个纯贴片元件、10个通孔插座、1个混合焊接的USB-C接口**。ESP32开发板、屏幕和传感器模块不计在这78个里。U7/U10底部有细小焊盘，建议交给具备相应工艺的装配厂家，避免只用普通烙铁尝试整板焊接。

## 载板待补齐：完整32种料号

以下均为**一块载板的实际用量**，不含焊接损耗和备用件。自己购买时，少量器件应留备用；厂家包料则先确认起订量、损耗和剩余物料归属，避免重复购买。

清单依据当前原生工程PCB2的器件和库属性核对，32种料号合计78件。`U7`、`R13`等叫“位号”，就是印在板上用来找位置的编号；`C2155674`等是立创商城料号，开头的C不代表电容。购买时核对**料号、型号和封装**，不要只看商品图片。封装就是元件外形与焊脚尺寸，例如0805，面包板用的长脚电阻不能直接替代同阻值贴片电阻。

### 线束与装配也要准备

这些**不计入板上78个器件**，持有情况尚未逐项确认：

- 适配上述板端XH插座的配对线束：3针2条、4针3条、6针1条、8针1条；购买成品线或对应外壳、端子后制作，先核对实际可插合。模块另一端按模块实物选接头。
- OV2640短转换线1套：载板端配J12双排20针插头，另一端按相机实际针序制作；不是把两个相似插头直接对插。接法见[相机转换表](../eda/hardware/docs/camera-adapter.md)。
- 载板与外壳安装用M3螺丝、隔离柱：四个安装位置，长度待外壳确定后再选，不盲买固定长度。

**XH的2.50mm与杜邦排针的2.54mm不是同一种接口。** 配对线束只是物理上能插入，还必须逐根核对电源、地、信号顺序；不能照线色推断。

## 下单时怎么避免漏买、重复买

1. **先选装配方式**：建议让厂家负责上面67个纯贴片元件；10个通孔插座和J10另确认焊接服务。若厂家能做整板装配，也可一起报价。
2. **确认谁买元件**：包料服务由厂家采购；只代焊服务需要你提供元件。让对方逐项确认32种料号的供货、起订量、替代料和费用，不假设商城显示有货就一定支持其贴片服务。
3. **用当前PCB2生成装配文件**：物料清单和元件位置文件必须对应同一版本。让厂家核对R13=24kΩ、J11已删除，以及U7/U10小封装和J10混合焊接能力；不要拿旧文件下单。入口见[嘉立创工程](../eda/README.md)。
4. **另外核对线束和已有模块**：装好78个元件的载板仍不包含开发板、屏幕、传感器、摄像头和电源。先核对到货实物，再补缺项，避免重复购买。
5. **拿到成品也先检查再上电**：按[首板验收](../eda/hardware/docs/first-board-validation.md)从空载开始测，不直接插满所有模块。

目前只是核对设计物料，不代表已经采购、厂家已接单或装配实测通过；硬件未实测，固件仅编译验证。

## 面包板的MQ-2分压电阻

订单图片明确写明MQ-2的AO在高浓度时可能达到约4V，DO则输出0V或5V。ESP32-S3的GPIO
最高只允许3.3V，因此本项目只使用AO，并增加：

- 10kΩ电阻一只；
- 20kΩ电阻一只。没有20kΩ时可用两只10kΩ串联。

分压关系是：

    MQ-2 AO ── 10kΩ ──┬── GPIO3
                       └── 20kΩ ── GND

GPIO3看到的是模块AO的三分之二。即使AO达到4V，GPIO约为2.67V，仍在安全范围内。

这一接法以 AO 不超过约 4 V 为前提，不能覆盖 AO 接近 5 V 的情况。若模块 AO 可能接近供电电压，改用上下各 10 kΩ，并选对应分压系数的固件。

R2 载板采用上下各 10 kΩ、1% 电阻和 100 nF 电容，GPIO3 看到 AO 的一半。载板应选择 `carrier_r1_core_st7789` 或 `carrier_r1_full_st7789_camera`；不要额外叠加上述面包板分压。首板试制资料与实物待确认项见[载板说明](../eda/hardware/README.md)。

## 不进入核心系统的现有器件

| 器件 | 放在哪里使用 | 原因 |
|---|---|---|
| HC-05 | STM32桌宠 | ESP32-S3已经内置BLE |
| 74HC595 | SPI学习课程 | HomeGuard没有缺少普通输出口到需要它扩展 |
| B10K电位器 | ADC学习课程 | 不属于成品功能 |
| YS-F04六路反相器 | 数字逻辑实验 | 输出会反相，不是74AHCT125 |
| WS2812 16灯板 | 后续灯光扩展 | 峰值电流较大，先完成核心系统 |
| MAX98357和4Ω3W喇叭 | 后续音频扩展 | 先验证麦克风与蜂鸣器，避免I2S同时收发增加难度 |

## YS-F04为什么不能直接代替74AHCT125

YS-F04是单向反相器。输入高电平时输出低，输入低时输出高。WS2812的数据协议不能直接
接受被反转的波形，而且若内部是74HC系列，5V供电时也未必能稳定识别3.3V高电平。

5V灯板的3.3V数据未必能被稳定识别；使用合适的74AHCT125或74HCT125电平转换。灯板外部供电、与ESP32共地，不由GPIO供电。

## 电源预算

已知负载的大致量级：

| 负载 | 典型或预留电流 |
|---|---:|
| ESP32-S3含Wi-Fi和摄像头 | 预留700mA |
| MQ-2加热器 | 约150mA |
| LD2410C | 约79mA |
| 屏幕、传感器、麦克风、蜂鸣器 | 预留300mA |
| 16灯WS2812全白 | 最坏接近960mA |

面包板核心系统使用正规5V 2A或3A电源；**当前R2载板按你已有的专用5V/3A电源和对应线设计**，板上典型限流约2.04A，不能将3A全额当成负载余量。加入WS2812属于另外的扩展，需要重新核算电源和保护，不属于上述32种料号。灯板单独布置5V和GND粗线，不让灯板电流经过ESP32的细排针或GPIO。

## 接线前要确认

1. ESP32-S3正反面和完整针脚图；
2. OV2640正反面、双排针定义和板载有源晶振说明；
3. SHT40正反面芯片丝印；
4. INMP441的L/R、WS、SCK、SD丝印；
5. MAX98357的VIN、BCLK、LRC、DIN、输出端；
6. MQ-2的VCC、GND、DO、AO方向。

模块外观相似不代表引脚顺序相同。教程中的GPIO编号固定，但模块端必须以收到的实物丝印
为准。
