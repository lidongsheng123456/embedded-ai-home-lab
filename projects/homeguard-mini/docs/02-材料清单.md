# 02 要买的元器件

**按当前PCB完整装配1块载板：需要32种，共78件板上元件。** 厂家包料贴片就让厂家采购；自己装配再按表购买。

搜索页打不开时，把该行型号复制到淘宝 App 搜索。优先选评分较高、有买家文字评价的店铺；这些链接未核验具体店铺和库存。

数量是板上所需件数，不是购买包数；一包多件时按包装换算。下单核对型号和封装，别只看图片相似。
