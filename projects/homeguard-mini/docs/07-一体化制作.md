# 07 从面包板到能装进盒子的成品

**顺序：面包板跑通 → 固定接线（可用洞洞板）→ 定制载板 → 首板验收 → 外壳。** 先做少量样板，不急着批量生产。

## 先分清你下单的是什么

| 订单写什么 | 通常收到什么 | 还缺什么 |
| --- | --- | --- |
| PCB打样 | 有铜线、孔、文字的空板 | 板上元件、焊接、模块和线束 |
| 只代焊 / 来料装配 | 厂家帮焊你提供的元件 | 你要采购并寄料，确认漏焊范围 |
| 包料装配 | 厂家按清单采购并焊接 | 确认28种料号全覆盖、插件/USB也焊、是否含测试 |

当前载板需**28种料号、60个器件，尚待补齐**。包括39个纯贴片、20个通孔插座/排针、1个混合USB-C。完整清单在[02](02-材料清单.md#载板待补齐完整28种料号)，不再另建采购表。

旧 U7/U10 等保护与开关器件已删除；U8 降压器外围及 R22 启动下拉按清单装齐。不要把“PCB下单成功”理解为元件已买齐、厂家会全焊好。

## 在嘉立创打开哪个工程

从[唯一原生工程入口](../eda/README.md)打开 `.eprj3`，进入 **Board2 / PCB2**。文件夹保留R1历史名称，实际是R2排母供电；Board1/PCB1现为四件四层学习参考，不是正式载板。想学会改图，先看[新手改板路线](../eda/tutorial/README.md)及工程内Schematic1/P2。

当前板为**4层、100×100mm、圆角R3、板厚1.6mm**，原建议绿油、双面白字、无铅沉金。具体订单仍以当前PCB2和板厂检查为准。加工文件按需从当前工程生成，不堆重复发布包。

### 弹窗说“优惠券仅支持OSP”怎么办

这是**优惠券与焊盘表面处理不匹配，不是电路报错**。焊盘就是焊元件的金属位置。

| 你想要什么 | 怎么选 |
| --- | --- |
| 使用这张券 | 表面处理改选OSP，再核对券的其余限制和装配厂是否接受 |
| 保留原来的沉金 | 换支持沉金的券，或不用这张券 |

OSP是在铜表面加保护膜，可以正常焊接；应按板厂要求保存，避免长时间放置和反复接触焊盘。沉金表面较耐存放，通常更方便手焊、检查和返修，但费用可能更高。两者都不能代替电路和装配检查；选哪种要结合费用、存放时间与厂家工艺。

## 下单前只查这几件事

- [ ] 模块、母座、USB和线束按实物核对；1:1打印图确认孔距和方向。
- [ ] 当前PCB2执行电气/间距/未布通检查（ERC/DRC），看板厂制造预览。
- [ ] 当前接口学习扩展版60件，旧U7/U10和J11已删除，J13与R22已加入；四组接口及七针功放已按实物修订，另有两个I2C扩展口和两侧22针学习排针；不要用旧导出下单。
- [ ] MQ-2分压是10kΩ/10kΩ，固件使用 `carrier_r1_*`。
- [ ] 天线有净空，插头插得进，USB-C在板边且不被外壳挡住。
- [ ] 确认板上60件的采购、焊接范围，另备模块配对线束。

DRC为0只代表设计规则检查未发现问题。当前仍有辅助制造提示与实物待验项，见[10 当前状态](10-遗留问题与验收清单.md)。

## 载板怎么给开发板供电

```text
已有的专用5V/3A电源 → 板边J10 → F1保险丝 / D1瞬态钳位
                         ├→ J7.21 → ESP32开发板5V
                         ├→ MQ-2、雷达、MAX98357A接口5V
                         └→ 降压到独立3.3V → 其余外围模块
```

- 按厂家标注短接开发板背面 **IN/OUT**，不是5V与GND；尚待实焊核对。
- 外围3.3V与开发板3.3V分开，GND相连；不要把两路稳压输出并在一起。
- 烧录：**断载板电 → 取下开发板 → 电脑USB烧录 → 拔USB → 装回 → 上电**。
- 3A是电源能力；精简版没有主动限流和反向阻断。加功放后须实测峰值负载、线材接头温升和5V压降，旧1.60A分配不能覆盖播放时负载。

**拿到板后先不插模块，做空载电压检查，再逐个加负载。** 电压、限流、启动和测量步骤按[首板验收](../eda/hardware/docs/first-board-validation.md)执行，需要相应仪器或厂家协助，不能直接插满上电。

## 外壳这样安排

### 模块固定还是接线

2026-11-19按屏幕位置可自定义的需求，采用下表装配。“外接”指用线移到同一外壳的合适位置，所有模块都需要支架、卡座或合适的螺丝固定，插头不承受模块重量。当前PCB已加入七针功放、两个I2C扩展口及两侧学习排针，并完成局部重布。

| 模块 | 决定的安装方式 | 原因及接线起点 |
| --- | --- | --- |
| ESP32-S3 | 板上直插J7/J8，保持居中 | 减少供电与信号飞线；取下烧录的空间需保留 |
| INMP441 | 板边六孔阵列直插，外壳声孔对准实际声孔面 | 减少数字音频线；保留已设计的2.6mm/7.3mm阵列，先实物套合，远离蜂鸣器和喇叭 |
| ST7789 | 公对母杜邦线接J6，固定前面板 | 显示窗口位置、角度可自定；先按不超过10cm做线，SCL/SDA是SPI信号，异常时先缩短线并检查时钟设置 |
| OV2640 | J12专用短转换线，固定镜头开孔后方 | 可调整视角，但主板相机接口应靠近镜头；总线束先不超过5cm，多根地按转换表接，不能用普通20针直通排线 |
| LD2410C | 公对母杜邦线接J4，固定正面塑料窗口后 | 雷达正面避开屏幕、金属件和主板铜层遮挡；先不超过15cm，OUT对应孔仍不接 |
| MQ-2 | 公对母杜邦线接J1，固定独立通风区 | 发热模块远离SHT40、镜头及塑料；先不超过10cm，VCC/GND避免过细线，DO对应孔仍不接，AO沿用载板分压 |
| SHT40 | J2匹配XH转换线，固定通风边缘 | 避免测到主控、稳压器和MQ-2自身热量；先不超过10cm |
| BH1750 | J3匹配XH转换线，固定采光孔处 | 避开屏幕背光与补光灯直射；先不超过10cm，按实物核对ADDR接地，不能按针数猜接法 |
| 有源蜂鸣器 | J9匹配XH转换线，固定出声孔附近 | 远离麦克风，先不超过15cm；载板1=3V3、2=GND、3=控制，分别接模块VCC、GND、I/O，不能按左右顺序直通 |
| MAX98357A | 用支架固定在壳内主板附近，J13七针公对母杜邦短线连接 | 数字音频线先不超过5cm；喇叭固定在出声孔，以一对绞合线接OUTP/OUTN，两端都不能接地；播放功能尚未实现 |
| 板上静音按钮、J10电源口 | 保持固定在PCB | 外壳给按钮留操作孔或导向按杆，给USB-C留插拔空间，不改接长线 |

上述长度是首板布置与调试的起点，不是已测得的最大允许线长；带载压降、SPI/I²C/数字音频和相机信号仍需实测。SHT40、BH1750与相机共享I²C，分支保持短，不拉成长树状线束。信号线尽量与地线贴近，远离喇叭输出线与电源开关节点。接插件预留弯线、拔插和拆壳余量，线束在壳内做应力固定，杜邦头不能因搬动松脱。

屏幕、雷达、MQ-2保留现有排母即可接公对母杜邦线，不为外接再增加一组插座。XH-2.50mm与杜邦2.54mm不混插，购买/制作匹配的转换线；相机线束按[逐根线表](../eda/hardware/docs/camera-adapter.md)制作。最终打印前先用实物摆放，测量模块、插头和线束整体空间，再确定外壳尺寸与孔位。

| 部件 | 放置要求 | 原因 |
| --- | --- | --- |
| MQ-2 | 通风、防触碰，远离塑料和SHT40 | 发热，会影响温度测量 |
| SHT40 | 通风边缘，远离主控/屏幕/稳压器 | 少测到机器自身热量 |
| LD2410C | 正面不放金属、屏幕或铜板遮挡 | 避免影响检测 |
| OV2640 / BH1750 | 镜头、采光处开孔 | 不能被面板挡住 |
| INMP441 | 开声孔，远离蜂鸣器 | 减少自发声音干扰 |
| ESP32天线 | 留出空间和净空，保留馈线弯曲空间 | 避免无线信号变差 |
| 按钮 / USB / 线束 | 可插拔、可维护，给锁扣留空间 | 不拆壳也能正常操作 |

外壳不密封。摄像头短转换线先尽量控制在50mm内，再按波形实测；载板J12是20针，不能直接插18针相机，见[转换线表](../eda/hardware/docs/camera-adapter.md)。

<summary>自己做洞洞板或下一版PCB时，再看这些</summary>

面包板电源轨分清5V/3.3V，改线断电；摄像头线尽量短于10cm。固定时贵重模块用插座，不直接焊死；电源主线比信号线粗，模块附近加合适的电源电容，先测无短路再上电。

下一版仍优先做模块载板，不急着焊裸ESP32和裸摄像头。先定板框、安装孔、母座、USB和插座，再分电源区、接口区、主控区。相机信号成组、短线、少过孔，有连续地作为返回路径，不贴着开关电源或天线走。详细理由见[从接线到PCB](../../../docs/嵌入式原理图与PCB设计实践.md)。

载板已增加 MAX98357A 模块接口，播放软件尚未实现，接法见[教程](03-接线教程.md#载板新增功放接口)。WS2812、连续视频、声音分类未加入；喇叭/舵机不能由GPIO供电。第一版不加锂电充电、市电或裸露220V。
