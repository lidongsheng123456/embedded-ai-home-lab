# 07 从面包板到能装进盒子的成品

**顺序：面包板跑通 → 固定接线（可用洞洞板）→ 定制载板 → 首板验收 → 外壳。** 先做少量样板，不急着批量生产。

## 先分清你下单的是什么

| 订单写什么 | 通常收到什么 | 还缺什么 |
| --- | --- | --- |
| PCB打样 | 有铜线、孔、文字的空板 | 板上元件、焊接、模块和线束 |
| 只代焊 / 来料装配 | 厂家帮焊你提供的元件 | 你要采购并寄料，确认漏焊范围 |
| 包料装配 | 厂家按清单采购并焊接 | 确认32种料号全覆盖、插件/USB也焊、是否含测试 |

当前载板需**32种料号、78个器件，尚待补齐**。包括67个纯贴片、10个通孔插座、1个混合USB-C。完整清单在[02](02-材料清单.md#载板待补齐完整32种料号)，不再另建采购表。

U7/U10底部焊脚很细，建议找具备对应工艺的装配厂家。不要把“PCB下单成功”理解为元件已买齐、厂家会全焊好。

## 在嘉立创打开哪个工程

从[唯一原生工程入口](../eda/README.md)打开 `.eprj3`，进入 **Board2 / PCB2**。文件夹保留R1历史名称，实际是R2排母供电；PCB1是早期空板，不用于打样。

当前板为**4层、100×100mm、圆角R3、板厚1.6mm**，原建议绿油、双面白字、无铅沉金。具体订单仍以当前PCB2和板厂检查为准。加工文件按需从当前工程生成，不堆重复发布包。

### 弹窗说“优惠券仅支持OSP”怎么办

这是**优惠券与焊盘表面处理不匹配，不是电路报错**。焊盘就是焊元件的金属位置。

| 你想要什么 | 怎么选 |
| --- | --- |
| 使用这张券 | 表面处理改选OSP，再核对券的其余限制和装配厂是否接受 |
| 保留原来的沉金 | 换支持沉金的券，或不用这张券 |

OSP是在铜表面加保护膜，可以正常焊接；应按板厂要求保存，避免长时间放置和反复接触焊盘。沉金表面较耐存放，通常更方便手焊、检查和返修，但费用可能更高。两者都不能代替电路和装配检查；选哪种要结合费用、存放时间与厂家工艺。

## 下单前只查这几件事

- [ ] 模块、母座、USB和线束按实物核对；1:1打印图确认孔距和方向。
- [ ] 当前PCB2执行电气/间距/未布通检查（ERC/DRC），看板厂制造预览。
- [ ] R13是24kΩ，旧J11已删除；不要用旧导出下单。
- [ ] MQ-2分压是10kΩ/10kΩ，固件使用 `carrier_r1_*`。
- [ ] 天线有净空，插头插得进，USB-C在板边且不被外壳挡住。
- [ ] 确认板上78件的采购、焊接范围，另备模块配对线束。

DRC为0只代表设计规则检查未发现问题。当前仍有辅助制造提示与实物待验项，见[10 当前状态](10-遗留问题与验收清单.md)。

## 载板怎么给开发板供电

```text
已有的专用5V/3A电源 → 板边J10 → 保护电路
                         ├→ J7.21 → ESP32开发板5V
                         ├→ MQ-2、雷达5V
                         └→ 降压到独立3.3V → 其余外围模块
```

- 按厂家标注短接开发板背面 **IN/OUT**，不是5V与GND；尚待实焊核对。
- 外围3.3V与开发板3.3V分开，GND相连；不要把两路稳压输出并在一起。
- 烧录：**断载板电 → 取下开发板 → 电脑USB烧录 → 拔USB → 装回 → 上电**。
- 3A是电源能力，载板典型限流约2.04A，整机设计分配1.60A，不能随意再接接近1A的灯板。

**拿到板后先不插模块，做空载电压检查，再逐个加负载。** 电压、限流、启动和测量步骤按[首板验收](../eda/hardware/docs/first-board-validation.md)执行，需要相应仪器或厂家协助，不能直接插满上电。

## 外壳这样安排

| 部件 | 放置要求 | 原因 |
| --- | --- | --- |
| MQ-2 | 通风、防触碰，远离塑料和SHT40 | 发热，会影响温度测量 |
| SHT40 | 通风边缘，远离主控/屏幕/稳压器 | 少测到机器自身热量 |
| LD2410C | 正面不放金属、屏幕或铜板遮挡 | 避免影响检测 |
| OV2640 / BH1750 | 镜头、采光处开孔 | 不能被面板挡住 |
| INMP441 | 开声孔，远离蜂鸣器 | 减少自发声音干扰 |
| ESP32天线 | 留出空间和净空，保留馈线弯曲空间 | 避免无线信号变差 |
| 按钮 / USB / 线束 | 可插拔、可维护，给锁扣留空间 | 不拆壳也能正常操作 |

外壳不密封。摄像头短转换线先尽量控制在50mm内，再按波形实测；载板J12是20针，不能直接插18针相机，见[转换线表](../eda/hardware/docs/camera-adapter.md)。

面包板电源轨分清5V/3.3V，改线断电；摄像头线尽量短于10cm。固定时贵重模块用插座，不直接焊死；电源主线比信号线粗，模块附近加合适的电源电容，先测无短路再上电。

下一版仍优先做模块载板，不急着焊裸ESP32和裸摄像头。先定板框、安装孔、母座、USB和插座，再分电源区、接口区、主控区。相机信号成组、短线、少过孔，有连续地作为返回路径，不贴着开关电源或天线走。详细理由见[从接线到PCB](../../../docs/嵌入式原理图与PCB设计实践.md)。

WS2812、MAX98357功放/喇叭、连续视频、声音分类都不是当前核心载板功能。要加时重新核算供电、引脚、驱动与测试；喇叭/舵机不能由GPIO供电。第一版不加锂电充电、市电或裸露220V。
