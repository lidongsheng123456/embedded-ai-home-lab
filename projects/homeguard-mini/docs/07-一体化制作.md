# 07 从面包板到完整嵌入式系统

本章区分学习用面包板和正式R2载板。R2的外围3.3V由载板独立降压产生，
开发板经母座J7.21接受保护后的5V，两路3.3V不并联。先按厂家图短接开发板IN/OUT；
烧录前断电取下开发板，拔掉电脑USB后再装回。完整电路见
[载板说明](../eda/hardware/README.md)，不要把面包板接法直接照搬到定制板。

## 三个版本，不跨级

    面包板原型 → 洞洞板/模块载板 → 定制PCB

面包板适合改线，洞洞板验证长期连接，定制PCB解决体积和可靠性。第一次就画PCB，任何
引脚或封装错误都会变成整块废板。

## 面包板版本

- 宽ESP32-S3放在面包板旁边，用公对母线连接；
- 3.3V和5V使用不同颜色电源轨；
- 摄像头线短于10cm；
- MQ-2分压电阻靠近ESP32 GPIO3；
- MQ-2金属网与塑料、杜邦线保持距离；
- 连续运行48小时后才固定。

## 洞洞板版本

所有贵重模块使用排母，不直接焊死：

- ESP32-S3使用两排母座；
- ST7789、SHT40、BH1750、INMP441使用带方向插座；
- LD2410C使用五针排母；
- OV2640使用两排排母并缩短并行线；
- 学习洞洞板的MQ-2可沿用面包板10kΩ/20kΩ分压，必须先实测AO不超过约4V；
- 正式R2载板使用10kΩ/10kΩ分压，烧录`carrier_r1_*`环境，不混用还原系数；
- 5V和GND主线比普通信号线粗；
- 3.3V总线入口增加10μF电容；
- 每个模块附近预留100nF去耦位置。

焊完先用万用表通断档检查3.3V、5V与GND之间没有短路。

## 外壳布局

    正面
    ┌────────────────────────────┐
    │ OV2640            光照开孔 │
    │                            │
    │       ST7789 1.54寸屏      │
    │                            │
    │ [多功能按钮]      蜂鸣孔   │
    │                            │
    │ 雷达窗口   温湿度通风孔    │
    └────────────────────────────┘
    侧面：原生USB、UART USB、5V电源
    背面或顶部：MQ-2大面积通风和防触碰罩

布局原则：

- MQ-2会发热，远离SHT40、ESP32和塑料外壳；
- SHT40放在通风板边，避免屏幕背光和MQ-2热量；
- LD2410C正前方不放金属、覆铜或屏幕；
- OV2640镜头不能被面板遮挡，并增加隐私指示标识；
- INMP441远离蜂鸣器和喇叭；
- BH1750前方开孔或使用透明窗口；
- ESP32天线伸到PCB边缘，天线下方不铺铜；
- 外壳不密封，MQ-2和温湿度都需要空气交换。

## 第一块定制PCB应该是什么

第一块板仍然使用ESP32-S3开发板和现成传感器模块，只做“模块载板”。不要第一版就把
ESP32-S3-WROOM、OV2640裸传感器或MQ-2敏感元件直接画到板上。

原理图至少包含：

- ESP32-S3两排母座；
- 独立的5V、3.3V和GND网络；
- USB 5V输入保护与测试点；
- MQ-2 10kΩ/10kΩ分压与滤波（R2正式载板）；
- I2C、UART、I2S、SPI和摄像头连接器；
- 摄像头D0～D7、PCLK、VSYNC、HREF的测试点；
- 多功能按钮和蜂鸣器接口；
- 安装孔、模块方向和电压丝印；
- 每个接口的第一脚标记和防反插设计。

## 摄像头PCB注意事项

面包板能运行不代表任意PCB布线都能运行。摄像头是并行高速信号：

- D0～D7、PCLK、VSYNC、HREF尽量短；
- PCLK优先最短，并避免紧贴蜂鸣器、开关电源和天线；
- 数据线尽量成组、少过孔；
- 摄像头附近保持完整GND参考；
- 不让高速线跨越地平面缺口；
- 先保留现成OV2640模块插座，不直接画裸FPC座。

## 电源和热设计

R2使用专用5V/3A正规适配器；USB-C不做PD协商，不用电脑USB口给整机供电。
MQ-2和LD2410C使用载板5V，其他外围模块使用载板独立3.3V。
ESP32板载稳压器只供开发板及指定MCU侧逻辑，不承担外围模块总电流；不要从GPIO供电。

加入16灯WS2812后，灯板使用单独5V粗线与电源连接，只与ESP32共地。不要让接近1A的灯板
电流经过ESP32开发板。

## 下单PCB前检查

1. 每个模块逐针对照收到的实物；
2. 打印1:1图纸，把模块放上去核对孔距；
3. 检查GPIO35～37没有连接；
4. 检查MQ-2 AO分压；
5. 检查摄像头D0～D7顺序；
6. 运行ERC和DRC；
7. 检查ESP32天线净空；
8. 检查摄像头、雷达、光照和通风开孔；
9. 保留烧录、复位和串口测试点；
10. 第一批只下单少量样板。

不要在第一版PCB加入锂电池充电、市电、继电器或裸露220V线路。

## 后续扩展放到核心稳定之后

当前载板不包含 WS2812 灯板、MAX98357 功放、喇叭和 TinyML 声音分类。先完成核心传感器、屏幕和相机的连续运行，再逐个扩展；不要将未来功能理解为当前固件已实现。

- WS2812：灯板用独立 5V 粗线、与开发板共地，16 灯最坏情况约需 1A 余量，入口电容 470～1000µF、数据信号串约 330Ω；正式设计使用合适的 74AHCT125/74HCT125 电平转换，重新核算整机电源。
- MAX98357 与喇叭：功放供电、I2S 资源和麦克风回声要分别验证，喇叭不能接 GPIO。
- 相机连续预览：先解决网页鉴权、带宽、内存和慢连接对普通告警的影响，不直接暴露公网。
- TinyML 声音分类：需要真实样本、独立测试集和误报评估，不能把相对声音强度当成声音识别。
- 自制 WROOM 主板：载板稳定后再重新设计稳压、启动、下载、ESD 和天线，不能直接复制模块接线。
