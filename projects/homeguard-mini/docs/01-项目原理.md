# 01 它是怎么工作的

**传感器负责感觉，ESP32负责判断，屏幕、网页和蜂鸣器负责告诉你结果。**

```text
传感器 → ESP32采集 → 固定规则 + 本地学习 → 屏幕 / 网页 / 蜂鸣器
                         ↑
                   按钮：静音、重新学习
相机 → 用户点击时拍一张照片 → 本地网页
```

烧录后电脑可以关机，ESP32自己运行；网页也存在ESP32里面。普通功能不需要额外运行Java、Python或云服务器。

## 每个零件干什么

| 零件 | 白话理解 | 实际得到什么 |
| --- | --- | --- |
| MQ-2 | 对多种气体敏感的鼻子 | 原始电压、0～100相对指数；**不是CO₂或气体ppm** |
| SHT40 | 温湿度计 | 摄氏温度、相对湿度 |
| BH1750 | 看亮不亮 | 光照值lux |
| LD2410C | 看正面是否有人 | 有人、移动；失联显示未知 |
| INMP441 | 听声音强弱 | 相对声音指数；不是校准分贝，也不是声音识别 |
| OV2640 | 拍照 | 手动请求的一张JPEG，不是录像 |
| ST7789 / 网页 | 仪表盘 | 读数、学习进度、提醒、IP地址 |

设备只测盒子所在区域，不能凭客厅一台设备知道卫生间是否漏水、窗户是否关好或具体是谁进门。

## 两种AI分别做什么

| 功能 | 怎么理解 | 需要联网吗 |
| --- | --- | --- |
| 本地学习 | 先记住“房间平时什么样”，再看现在偏离多少 | 不需要 |
| 可选DeepSeek | 看一份数据，给出中文解释；也可按明确指令执行少量操作 | 需要互联网、密钥和账户额度 |

本地每5秒记录一组：**气体相对指数、温度、湿度、光照变化、声音指数**。收满120组有效样本约需10分钟。模型记平均值和波动范围，不会自动辨认“做饭”或“失火”。雷达和照片不参与这个模型。

固定实验阈值和本地模型共同给出提醒，重新学习不会删除固定规则。用法和阈值看[06](06-AI与日常使用.md)。

DeepSeek仅在网页手动请求时调用。环境解读不操作硬件；一句话控制只允许**短响、静音、恢复提醒、拍照**，固件检查后才执行。当前没有舵机或220V家电控制，见[09](09-DeepSeek云解读.md)。

## 网页怎么拿到数据

手机/电脑与设备在同一局域网 → 浏览器访问屏幕显示的IP → 网页向ESP32请求数据。**这条链路走Wi-Fi，不走COM口。**

- 请求完成后约2秒再更新一次状态；点击时才发静音、学习或拍照命令。
- Three.js在浏览器里画房间。人物标记代表有人，光线代表明暗，不能代表人的真实位置或自动扫描的户型。
- 页面资源存在设备里，热点模式下也可用；[大屏操作](../firmware/web/README.md)。

## 代码为什么分文件夹

| 文件夹 | 只负责什么 | 类比 |
| --- | --- | --- |
| `drivers` | 读传感器、控制硬件 | 手和耳朵 |
| `domain` | 数据、学习模型、提醒规则 | 判断标准 |
| `app` | 安排采集、提醒和处理命令 | 调度员 |
| `ui` / `web` | 小屏/浏览器显示 | 仪表盘 |
| `services` | Wi-Fi、网页接口、云调用 | 通信员 |

`main.cpp`只组装并启动它们。按钮和网页用同一套应用命令，避免两处各写一套静音或告警逻辑。

<details>
<summary>进阶阅读：为什么慢网页还会影响响应</summary>

雷达接收、音频采集、按键记录和蜂鸣器关铃有独立任务；普通网页、相机等待、业务命令和下一声提醒启动仍使用主循环。慢请求可能推迟静音、学习及下一声，恢复后不会补响很多次。独立任务也有调度延迟，不能保证严格实时。

- 雷达完整报告校验后才更新状态；500ms没有有效报告就标未知。
- 按钮每5ms采样，两沿稳定20ms才确认；不足40ms忽略，至少2秒算长按，松开后记录。尚未处理的同类事件合并，不记录连点次数和顺序。
- 普通提醒100ms/每3秒，高级提醒250ms/每秒，手动测试200ms；独立定时任务负责关铃，定时器失败保持关闭。需实测脉宽和并发响应。
- 固件不会用无效温湿度/光照凑学习样本；数字音频全零仍须通过拍手测试区分安静与接线故障。

实现与验证依据见[10 当前状态](10-遗留问题与验收清单.md)。

</details>

## 使用边界

MQ-2不能替代SCD41测CO₂；相对声音不能识别玻璃破碎；本设备不能确认火灾、燃气泄漏或入侵，不能替代认证报警器。

照片和录音不发给DeepSeek，照片不保存历史。当前网页**没有账号登录**，同网能访问的人可能查看和控制；使用强Wi-Fi/热点密码，不映射公网，不对准他人隐私区域。
