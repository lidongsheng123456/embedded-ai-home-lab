# 04 软件安装、编译和烧录

## 1. 安装一次即可

1. 安装Visual Studio Code；
2. 打开扩展商店；
3. 搜索并安装PlatformIO IDE；
4. 等待底部状态栏不再显示安装；
5. 重启VS Code。

不要同时用Arduino IDE、串口助手和PlatformIO打开同一个COM口。

## 2. 打开正确文件夹

选择“文件 → 打开文件夹”，打开：

    embedded-ai-home-lab/projects/homeguard-mini/firmware

左侧文件树顶层必须直接看到platformio.ini。如果只打开某个cpp文件，PlatformIO不知道
芯片型号、库和编译参数，会出现大量红线。

## 3. 认识四个常用按钮

在左侧PlatformIO图标中展开某个环境：

| 菜单 | 意思 |
|---|---|
| Build | 只编译，检查代码能否变成固件 |
| Upload | 编译并烧录到ESP32-S3 |
| Monitor | 打开串口，查看程序打印 |
| Clean | 删除该环境的旧编译缓存 |

每次只操作教程指定的环境，不要看见四个环境就全部烧录。

## 4. 先配置Wi-Fi

在firmware目录的PowerShell终端执行：

    Copy-Item include\app_config.example.h include\app_config.h

编辑include/app_config.h，填写2.4GHz Wi-Fi名称和密码。该文件已经被Git忽略，不会提交。
不填写也能运行，设备会创建HomeGuard-Mini热点。

如果PlatformIO下载依赖时需要使用你本机代理，在当前PowerShell终端临时设置：

    $env:http_proxy="http://127.0.0.1:7892"
    $env:https_proxy="http://127.0.0.1:7892"

代理只影响当前终端，代理软件没有运行时不要设置。

## 5. 第一次选择core_st7789_154

在PROJECT TASKS中依次点击：

    core_st7789_154
      General
        Build

第一次构建需要下载工具链和库。成功结尾是SUCCESS。然后点击Upload。

你的板有两个Type-C接口：

- 核心环境可使用USB或UART接口；
- 完整摄像头环境占用GPIO43/44，必须使用标为USB的原生USB接口；
- 固件已启用USB CDC，Monitor波特率为115200。

如果Upload停在Connecting：

1. 按住BOOT；
2. 短按一次RESET；
3. 看到开始写入后松开BOOT；
4. 烧录完成后再短按RESET。

## 6. 按阶段选择环境

| 当前任务 | 选择的环境 |
|---|---|
| 屏幕和核心传感器 | core_st7789_154 |
| 只检查OV2640 | camera_ov2640_check |
| 核心与摄像头全部组合 | full_st7789_camera |
| 以后换用ILI9341 | core_ili9341_240x320 |

不要把camera_ov2640_check烧录后期待屏幕和网页工作；它只负责打印摄像头是否采集到JPEG。

## 7. 正常串口信息

核心系统启动后应看到类似：

    Sensors: SHT4x=1 BH1750=1 MQ2=GPIO3 (3 min warm-up)
    Sensor: LD2410=1
    MQ2 raw=420 voltage=0.51V index=13 temp=24.7 hum=51.3 ...

摄像头独立验机成功时应看到：

    PSRAM: found=1, size=8388608 bytes
    Camera: OV2640 ready, JPEG 640x480
    [Camera check] JPEG 640x480, 12345 bytes

字节数每次不同属于正常现象，因为不同画面的JPEG压缩大小不同。

## 8. 访问网页

连接家庭Wi-Fi成功时，串口会打印类似：

    Wi-Fi connected: http://192.168.1.35

若连接失败，ESP32创建HomeGuard-Mini热点。手机连接该热点后打开：

    http://192.168.4.1

手机可能提示“该网络无法访问互联网”，应选择继续连接。网页来自ESP32本身。

## 9. 修改代码后的固定动作

1. 先Build；
2. Build成功再Upload；
3. 打开Monitor观察启动日志；
4. 记录刚加入的模块和现象；
5. 失败时只撤掉刚加入的模块，不同时改代码、换线和换电源。
