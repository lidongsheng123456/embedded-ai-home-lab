# EasyEDA渐进电路学习路线

本路线用于把先在面包板完成验证的电路逐步搬进EasyEDA。仓库中旧的L4图纸基于SCD41和ILI9341，
与现在的MQ-2、ST7789V和OV2640方案不再一致，只能作为历史参考，不能直接下单PCB。

## L1：LED、按键和共地

学习限流、内部上拉和低电平按下：

    GPIO2 ── 330Ω ── LED ── GND
    GPIO39 ── 按钮 ── GND

验收：LED有电阻；按钮松开为高、按下为低；所有模块共地。

## L2：5V与3.3V电源域

在原理图中明确区分：

- 5V：MQ-2、LD2410C、开发板5V输入；
- 3.3V：SHT40、BH1750、INMP441、ST7789、OV2640；
- GND：所有电源和模块共同参考。

不要把5V网络误接到任何ESP32 GPIO。

## L3：MQ-2模拟分压

    MQ2_AO ── 10kΩ ──┬── GPIO3
                      └── 20kΩ ── GND

在原理图标注分压比例为2/3，并增加GPIO3测试点。AO和分压点各留一个测试点，便于万用表
同时验证。

## L4：低速总线与人机界面

| 功能 | GPIO |
|---|---|
| SHT40/BH1750 I2C | SDA=8，SCL=9 |
| LD2410C UART | RX=17，TX=18 |
| INMP441 I2S | BCLK=4，WS=5，SD=6 |
| ST7789 SPI | MOSI=11，SCLK=12，CS=10，DC=14，RST=15 |
| 蜂鸣器 | 21 |
| 按钮 | 39 |

每个模块使用带电压和方向丝印的连接器。I2C模块通常自带上拉，载板上的4.7kΩ上拉应
标为可选DNP，确认总线没有上拉时才安装。

## L5：OV2640并行摄像头

| 信号 | GPIO |
|---|---|
| D0～D7 | 1、2、7、13、38、40、41、42 |
| PCLK | 16（避开GPIO44上的板载CH343输出） |
| VSYNC | 47 |
| HREF | 48 |
| SCCB SDA/SCL | 8、9 |
| 驱动占位XCLK | 43，不连接摄像头模块 |

购买的摄像头模块使用板载有源晶振，RST固定到3.3V，PWDN固定到GND，FLASH暂不使用。
GPIO35～37属于N16R8的OPI PSRAM资源，不连接。

PCB布局时D0～D7和同步线成组、短走线、少过孔，PCLK最短。摄像头连接器旁增加GND针和
测试点，但不要擅自改变收到模块的两排针顺序。

## L6：模块载板

把前五级组合成第一块PCB：

- ESP32-S3开发板使用排母；
- 所有传感器继续使用成品模块；
- 5V入口有保险或限流保护、反接保护和电容；
- 3.3V模块附近预留100nF去耦；
- ESP32天线伸出板边并保持净空；
- MQ-2与SHT40物理隔离；
- LD2410C正前方不放铜和金属；
- 摄像头和屏幕按外壳开孔位置放置；
- 保留BOOT、RESET、USB和测试点。

## 下单前强制检查

1. 面包板完整系统连续运行48小时；
2. 每个连接器按实物逐针核对；
3. 打印1:1纸张核对尺寸和孔位；
4. ERC没有未解释的电气错误；
5. DRC没有短路、未布线和间距错误；
6. 5V不会进入3.3V GPIO；
7. GPIO35～37未使用；
8. 摄像头D0～D7顺序与固件一致；
9. 外壳给MQ-2、SHT40和BH1750留通风或光照窗口；
10. 第一版只少量打样。

HomeGuard Mini不是生命安全设备。PCB做得更整齐不会让MQ-2自动获得消防或燃气报警认证。
