# 14 把视频里的家放进网页

## 现在能看到什么

网页中的“温馨小家”已按家庭视频改为一室、一厅、一厨、一卫、一阳台。模型保留这些特征：

| 空间 | 视频中可辨认并用于建模的细节 |
| --- | --- |
| 客厅 | 狭长空间、米白大地砖、蓝色沙发、深木色桌子、笔记本、灰色冰箱、白色低柜 |
| 阳台 | 玻璃推拉门、窗框和防盗栏、晾衣、木椅、水桶与洗衣设备 |
| 卧室 | 木床、浅色花纹床品、米色花纹窗帘、空调、行李箱、环形灯与床边小架 |
| 厨房 | 浅色台面、木色下柜、黑色侧吸油烟机、灶台和炒锅 |
| 卫生间 | 浅色花纹地砖、浅金色门框、磨砂门、储水热水器、洗手盆、蹲便与淋浴器 |

厨房空间完整位于客厅范围内，不占用卧室、卫生间或它们旁边的过道。厨房的双轨玻璃
推拉门与入户大门朝向一致，两扇门平行，不在客厅左侧隔墙开厨房门；厨房右侧保留
入户通道。这些连接和朝向按用户说明调整，厨房与通道的具体宽度仍按比例估计。
整个模型没有屋顶，并提供降低墙体的
剖面模式，可以像看打开盖子的模型屋一样查看内部。画面仍用暖白光和柔和材质，保留
实际的家具颜色，不把蓝沙发替换成别的装修风格。

## 怎么打开和操作

在`firmware/web`打开终端：

```powershell
npm run build
npm run preview
```

浏览器打开 <http://127.0.0.1:4173/?demo=1>：

- 总览：从斜上方看整套房子。
- 俯视：看房间、隔墙和门口的关系。
- 客厅、卧室、厨房、卫生间、阳台：镜头移到对应空间。
- 降低墙体：让遮挡视线的墙变矮，再次点击恢复。
- 拖动和缩放：自己调整观察角度。
- 设备：查看客厅桌上预设的HomeGuard节点。

这些按钮只调整浏览器画面，不开关真实家电。元器件尚未到货，模型里的节点位置是
未来摆放示意，不表示已经安装。当前只有一个节点，传感器数据表示其附近的环境，
不能通过切换房间得到其他房间的温湿度或人员位置。

## 哪些还属于估计

视频能提供家具和空间关系参考，但没有标尺、房间实测尺寸或完整户型图。因此墙长、
层高、门宽、家具尺寸和部分连接比例按画面估计，坐标方向也不代表真实东南西北。
这版用于可视化和后续调整，不作为装修、施工或PCB安装尺寸依据。

原视频只在本机提取关键帧查看，没有上传给DeepSeek或其他云服务。原视频、关键帧和
临时预览截图保留在本机或已忽略的`.pio/`中，不打包进固件，不提交到Git。
模型中的布料、床品和磨砂门纹样是程序生成的，不使用家庭照片或私人屏幕内容作贴图。

## 代码分别放在哪里

| 文件（相对`firmware/web`） | 职责 |
| --- | --- |
| `src/home-layout.js` | 房间中心、大小、连接关系、节点位置、预设镜头 |
| `src/room-architecture.js` | 地砖、墙、门框、窗框、玻璃门和剖面切换 |
| `src/home-living.js` | 客厅、阳台家具 |
| `src/home-bedroom.js` | 卧室家具 |
| `src/home-wet-rooms.js` | 厨房、卫生间家具 |
| `src/room-materials.js` | 木纹、布料、床品和各种材质 |
| `src/home-labels.js` | 房间名称标签，不表示额外传感器 |
| `src/room-model.js` | 组装房子与设备标记 |
| `src/room-scene.js` | 镜头、光照、交互和释放资源 |

后续校正布局时，先改房间配置，再对照建筑门洞和家具位置调整；不要把HTTP通信、
告警规则或云模型调用放进家具文件。模型全部本地生成，运行时不下载在线家具资源。
厨房家具以厨房中心为原点整体摆放；厨房门和入户门的位置、门宽集中在
`HOME_LAYOUT.doors`，房间标签与厨房镜头读取同一份房间位置。

## 验证边界

电脑浏览器检查五个空间、俯视、剖面和手机宽度布局；网页构建后仍需要重新编译并
烧录固件，真实手机通过ESP32热点加载的速度仍需元器件到货后确认。
