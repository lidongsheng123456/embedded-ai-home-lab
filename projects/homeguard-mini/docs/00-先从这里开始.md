# 00 第一次做 HomeGuard，从这里开始

**先在面包板上一件件跑通，再焊载板，最后做外壳。现在不要一次把所有模块接上。**

完成后，它能显示温湿度、光照、相对气体/声音变化和有人状态，发出提醒，并让手机查看数据、手动拍照。它是学习和辅助提醒设备，不能替代正规烟雾、燃气或一氧化碳报警器。

## 面包板按这个顺序做

每次先断电接线，完成一行后再加下一件。程序烧进芯片的整套代码叫“固件”。

| 步骤 | 接什么、烧什么 | 看见什么才继续 |
| --- | --- | --- |
| 1 | 不接外设；USB数据线接开发板标着 **USB** 的接口，烧 `core_st7789_154` | Monitor能看到启动文字；缺模块提示此时正常 |
| 2 | 只加ST7789屏幕，仍用上面环境 | 屏幕出现HomeGuard Mini和数据栏目 |
| 3 | 加SHT40，再加BH1750 | `SHT4x=1 BH1750=1`，读数随环境变化 |
| 4 | 加MQ-2，**先分压、测电压，再接GPIO3** | 输入低于3.3V，数据有变化；首次老化24小时，每次启动预热3分钟 |
| 5 | 先加LD2410C雷达，再加INMP441麦克风 | 走动/离开、拍手时，对应状态变化 |
| 6 | 加带驱动蜂鸣器和按钮 | 能短响、静音、重新学习 |
| 7 | 暂时拔掉其他模块，只接OV2640，烧 `camera_ov2640_check` | 每3秒能报告JPEG图片尺寸和字节数 |
| 8 | 恢复核心模块、加入相机，烧 `full_st7789_camera` | 网页手动拍到新图片，真实数据持续更新 |

接线见[03](03-接线教程.md)，点击哪里见[04](04-软件与烧录.md)，各项判断见[05](05-首次启动.md)。想先看整个系统怎么分工，再读[01 项目原理](01-项目原理.md)。

### 怎样避免选错程序

- 你选的是1.54寸ST7789屏，不选给旧ILI9341屏准备的环境。
- `camera_ov2640_check`只是相机诊断，没有正常屏幕、网页或AI功能。
- **面包板与载板不能随意混烧。** 载板用 `carrier_r1_core_st7789` / `carrier_r1_full_st7789_camera`，名字中的r1为兼容保留，当前实际是R2排母供电。
- MQ-2面包板10kΩ/20kΩ仅适用于已确认AO不超过约4V的模块；可能接近5V时改成10kΩ/10kΩ，并选匹配系数的环境。载板已自带后一种分压。

## 什么才叫跑通

1. Build结尾是`SUCCESS`：只证明能编译。
2. Upload成功：只证明固件已写入。
3. 接入实物，现象和教程一致，运行至少10分钟无重启/失联：这一阶段才算通过。
4. 完整面包板连续运行48小时，才进入焊板和外壳。

当前固件**仅编译验证**；载板上电、模块插合和整机稳定性仍待实物确认。
