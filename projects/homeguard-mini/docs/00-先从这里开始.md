# 00 第一次制作从这里开始

这份教程面向第一次搭建完整嵌入式系统的人。不要先把所有模块插满面包板，也不要先做
外壳。每次只增加一个模块，看到规定现象后再继续。

## 最终会做出什么

完成后，ESP32-S3会同时负责：

- 读取MQ-2相对气体指数、SHT40温湿度和BH1750光照；
- 读取LD2410C的人体存在状态和INMP441相对声音指数；
- 在1.54寸ST7789彩屏显示当前状态；
- 超过实验阈值时控制有源蜂鸣器；
- 连接家庭Wi-Fi，或者自己创建热点；
- 手机浏览器查看数据、静音和重新学习；
- 使用OV2640在本地网页手动拍摄JPEG快照；
- 在本机学习正常环境变化，不依赖云服务器。

MQ-2不能测CO₂，也不能确认发生火灾、燃气泄漏或一氧化碳中毒。HomeGuard Mini是学习和
辅助提醒设备，不能替代经过认证的烟雾、天然气或一氧化碳报警器。

## 先认识四个容易混淆的词

- **GPIO**：开发板上可以输入或输出电信号的针脚；
- **驱动**：让程序知道怎样和某个模块说话的代码；
- **协议**：双方约定的数据传递规则，例如I2C、SPI、UART；
- **固件**：最后烧录到ESP32-S3中运行的整个程序。

不需要先背会这些词。接线时知道“哪根线接哪里”，看到现象后再回头理解即可。

## 四个PlatformIO环境

点击左侧PlatformIO图标，在PROJECT TASKS下会看到：

| 环境 | 什么时候使用 | 是否连接摄像头 |
|---|---|---|
| core_st7789_154 | 默认环境，先完成传感器、屏幕、雷达和网页 | 不连接 |
| camera_ov2640_check | 摄像头到货后的独立验机 | 只连接摄像头 |
| full_st7789_camera | 前两项都通过后的完整系统 | 连接 |
| core_ili9341_240x320 | 兼容旧的ILI9341屏幕 | 不连接 |

你买的是ST7789V屏幕，因此正常情况下不选择ILI9341环境。

## 从零到完整系统的正确顺序

### 阶段1：只验证开发板

1. 所有外部模块先不接；
2. 使用支持数据的Type-C线连接标为USB的原生USB接口；
3. 打开firmware文件夹；
4. 执行core_st7789_154中的Build；
5. 编译成功后执行Upload；
6. 打开Monitor，波特率为115200。

这一阶段只要求能烧录并看到启动文字。

### 阶段2：只接ST7789屏幕

严格按照[逐根接线教程](03-接线教程.md)连接8根线。成功现象是出现
HomeGuard Mini启动画面。白屏、全黑或颜色异常时不要继续接传感器。

### 阶段3：接SHT40和BH1750

这两个模块共用GPIO8和GPIO9。成功时串口出现：

    Sensors: SHT4x=1 BH1750=1

### 阶段4：接MQ-2

MQ-2使用5V加热，但它的AO可能超过ESP32允许的3.3V。必须先搭好10kΩ和20kΩ分压，
用万用表确认分压点不超过3.3V，再连接GPIO3。

首次使用建议在通风环境连续预热至少24小时。程序每次上电还会等待3分钟，预热期间
不会把MQ-2数据加入AI模型。

### 阶段5：接LD2410C和INMP441

先接雷达并确认有人/无人变化，再断电加入麦克风。不要两者同时第一次接入。

### 阶段6：接蜂鸣器和按钮

核心环境可以使用两个按钮。完整摄像头环境因为GPIO数量紧张，只使用GPIO39一个按钮：

- 短按：静音10分钟；
- 按住2秒再松开：清空旧模型并重新学习。

### 阶段7：独立验证OV2640

先拔掉其他外设，只连接摄像头，上传camera_ov2640_check。串口每3秒打印一次JPEG
尺寸和字节数才算通过。摄像头高速线尽量短于10cm。

### 阶段8：组合完整系统

恢复核心模块，按照完整接线表加入摄像头，上传full_st7789_camera。手机打开设备网页，
页面出现“本地摄像头快照”和“拍摄新画面”按钮即表示软件识别成功。

## 什么叫“通过”

每个阶段都要同时满足：

1. 编译结尾是SUCCESS；
2. 烧录后开发板不反复重启；
3. 串口没有持续报模块初始化失败；
4. 实际现象与教程一致；
5. 连续运行至少10分钟没有断线。

最终焊接前，完整面包板版本应连续运行48小时。
