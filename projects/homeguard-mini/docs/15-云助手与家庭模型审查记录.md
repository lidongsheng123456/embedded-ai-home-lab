# 云助手与家庭模型审查记录

审查日期：2026-11-12。范围为本次全部未提交变更：可选DeepSeek直连、受限硬件指令、
网页助手、家庭视频参考模型及相关教程。没有改动其他学习案例或项目。

## 模块怎样分工

| 层次 | 职责与约束 |
| --- | --- |
| `domain/ai_device_command` | 定义四种指令及协议名称，不依赖网络或GPIO |
| `services/deepseek_protocol`、`deepseek_tools` | 组织测量摘要，校验文本与单个工具，拒绝未知操作、额外参数和尾随内容 |
| `services/deepseek_client` | 校时、官方HTTPS、响应长度与超时预算，不直接访问硬件 |
| `services/ai_advisor` | 快照复制、后台任务、固定队列、冷却和一次性消费指令 |
| `app/ai_command_handler` | 在主循环执行指令并记录本机结果，不解析云JSON |
| `drivers/camera_snapshot` | 取帧、PSRAM缓存与归还缓冲；网页读取缓存不重复拍照 |
| `services/network_ai_routes` | 同源JSON入口、只读状态和缓存JPEG，不等待模型 |
| 网页`ai-controller`、`ai-view`、`ai-photo` | 分别管理提交/轮询、纯文字呈现和缓存照片读取 |
| 网页`home-layout`与家具模块 | 集中空间配置，按客厅/卧室/湿区组合几何体，不连接设备API |
| 网页`scene-controls`、`room-scene` | 分离按钮状态与Three.js镜头/绘制，不复制风险规则 |

入口继续负责组装。网络层借用只读状态，后台任务不共享可变`HomeState`或操作GPIO。
文件放在既有职责目录，不新增杂项工具目录；方法接口和硬件边界使用中文注释。
建筑模块虽包含多个造型函数，职责均为墙、门、窗和剖面，没有混入通信或业务规则。

## 审查中修复的问题

- 修正“云回复只能解释”的过时注释，明确展示文字和白名单指令是两个通道。
- 工具参数严格要求一个完整空对象，拒绝空对象后夹带其他内容，并加入回归用例。
- 三维按钮从网页入口拆出，修复房间按钮与总览按钮同时选中的状态；场景载入前禁用按钮。
- 厨房、厨具、地面、标签和镜头一起移入客厅范围；玻璃推拉门与入户门平行。
- 移除旧模型加载器及空的释放接口，运行时不再打包旧躺椅；历史参考文件保留来源说明。
- HTTPS读取预算集中配置；私密配置由Git忽略，只提交空密钥模板。

## 验证与实际边界

- 电脑协议测试：JSON转义、无效读数、文本限长、工具条件、未知指令、参数和多工具拒绝。
- 网页测试与构建：状态类型、按钮禁用、纯文本呈现、设备断线及旧固件兼容。
- 浏览器模拟检查：五个空间、视角切换、剖面、WebGL、390像素手机布局，以及助手的
  单次POST、旧请求隔离、照片缓存、失败处理；这些检查不连接硬件、不调用付费模型。
- PlatformIO验证核心ST7789、ILI9341、完整摄像头环境及独立摄像头诊断环境。
- 先前一次电脑实际调用官方API返回`beep`并通过同一协议校验；本次审查无需再次调用。
- 检查公开变更中的密钥模式、生成物、旧引用、文档链接和Git空白错误。

固件仅编译验证。开发板未连接且元器件未到货，不能据此声称蜂鸣器已响、照片已拍到、
传感器已采集或ESP32实际HTTPS连接已成功。真实设备的证书链、校时、堆内存、任务栈、
相机并发与热点加载速度，仍需按教程分阶段实测。

模型墙长、家具尺寸和通道比例仍按视频估计；房间切换只移动镜头。只有一个感知节点，
不提供各房间的独立测量或人员定位。家庭视频与抽帧不进入Git、固件或云模型。
