# 05 首次启动和逐项验收

每一级通过后再断电加入下一级。没有接实物时，编译成功只能叫“编译验证”，不能叫
“硬件实测通过”。

## 1. 开发板和PSRAM

不接外设，烧录camera_ov2640_check。串口必须显示：

    PSRAM: found=1, size=8388608 bytes

如果found=0，先检查上传的环境是否正确，不继续接摄像头。你的N16R8应有约8MB PSRAM。

## 2. ST7789屏幕

烧录core_st7789_154。正常现象：

- 背光点亮；
- 显示HomeGuard Mini；
- 随后出现MQ-2、温湿度、光照、声音等项目；
- 底部出现IP地址。

颜色红蓝颠倒时检查TFT_RGB_ORDER配置；画面偏移或缺边时记录屏幕背面完整型号，不盲目
更换引脚。

## 3. SHT40和BH1750

串口应显示：

    Sensors: SHT4x=1 BH1750=1

验收方法：

- 手靠近SHT40，温度可能缓慢上升；
- 对SHT40轻轻哈气，湿度会升高，但不要让水汽凝结；
- 遮住BH1750，lux明显下降；
- 用手机手电照射BH1750，lux明显上升。

## 4. MQ-2

### 第一次老化

新MQ-2漂移很大。首次在通风、安全、远离易燃物的位置连续通电至少24小时，只观察数据，
不要把这段数据当报警基准。

### 每次启动预热

程序每次上电等待3分钟。此时网页和屏幕可以显示数值，但状态会提示MQ-2 warming up，
AI不学习这段数据。

### 安全验收

1. 万用表测MQ-2 AO；
2. 再测GPIO3分压点；
3. 确认GPIO3分压点低于3.3V；
4. 串口gasRaw和gasVoltage随环境变化；
5. 不使用明火、打火机放气或故意制造大量烟雾。

MQ-2对酒精、清洁剂和做饭气味都可能响应。这说明它“有变化”，不表示它能辨认具体气体。

## 5. LD2410C

启动时应显示Sensor: LD2410=1。测试：

1. 站到正前方1～3米并走动，presence为1；
2. 静坐时仍应维持有人；
3. 离开检测区域一段时间后变为无人。

一直有人时，检查是否面对风扇、窗帘、薄墙或走廊。LD2410C可以穿透部分非金属材料，
摆放方向会影响结果。

## 6. INMP441

安静时声音指数较低，距离1～2米拍手时明显升高。它不是校准分贝。

始终为0时检查L/R是否接GND以及SCK、WS、SD；始终接近100时先检查数据线和焊点，不立即
提高报警阈值。

## 7. 蜂鸣器和按钮

- 网页点击静音，蜂鸣器立即停止；
- 核心环境按GPIO39按钮，静音10分钟；
- 核心环境按GPIO38按钮，学习样本清零；
- 摄像头完整环境短按GPIO39静音；
- 摄像头完整环境按住GPIO39两秒再松开，学习样本清零。

如果上电一直响，先确认买的是高电平触发模块。

## 8. OV2640独立验机

拔掉其他外设，只接OV2640并上传camera_ov2640_check。通过标准：

    [Camera check] PASS
    [Camera check] JPEG 640x480, 若干 bytes

如果PSRAM正常但Camera init failed：

- 检查D0～D7是否顺序接反；
- 检查PCLK、VSYNC、HREF；
- 检查RST接3.3V、PWDN接GND；
- 确认商品确实是带板载有源晶振的版本；
- 缩短杜邦线。

## 9. 完整网页快照

所有独立阶段通过后上传full_st7789_camera。网页应出现摄像头区域，点击“拍摄新画面”后
显示一张新JPEG。当前版本不是连续视频，不会自动保存历史图片。

## 10. 最终稳定性

完整面包板版本连续运行48小时，记录：

- 是否重启；
- I2C是否偶尔失联；
- 摄像头是否偶尔取帧失败；
- MQ-2在通风环境中的正常范围；
- Wi-Fi断开后是否切换热点；
- 屏幕和ESP32发热是否影响SHT40。

48小时通过后才进入洞洞板和定制PCB。
