# 06 日常怎么用，AI到底学了什么

**先让设备记住家里“平常的样子”，以后看变化。它不会自动知道是否失火或漏气。**

## 第一次学习这样做

1. 新MQ-2先通电老化至少24小时；每次开机等3分钟预热。
2. 把设备放在长期使用位置，保持正常通风、灯光和生活声音。
3. 网页点击“重新学习正常环境”；单键版也可按住至少2秒后松开。
4. 等样本从0到120，约10分钟；不要喷酒精、故意拍打或移动设备。

模型存入设备，断电保留。换房间、更换传感器或正常环境长期变化后再学一次；不要在刚做完饭、喷过酒精时学。

## 屏幕上的状态怎么看

| 状态 | 白话意思 | 你该做什么 |
| --- | --- | --- |
| Learning | 正在收集正常样本，AI分数暂为0 | 保持日常环境，等样本到120 |
| Normal | 接近平常，固定实验阈值也没超过 | 正常观察 |
| Attention | 某项读数或变化值得看看 | 找出是哪项，核对环境与接线 |
| High risk | 超过更高一级的实验阈值 | 认真核对真实情况；这不是事故鉴定 |
| 未知 / `--` | 没有有效数据 | 排查模块，不能理解成正常 |

## 你常用的操作

| 想做什么 | 怎么做 |
| --- | --- |
| 暂时不响 | 网页静音，或GPIO39按钮短按松开；10分钟后自动恢复 |
| 重新学习 | 网页重新学习；单键长按2秒松开，双键用GPIO38 |
| 看照片 | 网页手动拍一张；当前无录像和历史相册 |
| 请AI解释 | 可选配置[DeepSeek](09-DeepSeek云解读.md)，再手动点击环境解读 |

静音不停止采集。操作要由主循环执行，慢网页时可能延迟。

本地模型只学习五项：MQ-2相对指数、温度、湿度、`log(光照+1)`、相对声音指数。它比较“比平常偏了多少”，雷达状态和照片不在本地模型里。

当前实验阈值如下，不是国家安全标准：

| 指标 | Attention | High risk |
| --- | ---: | ---: |
| MQ-2相对指数 | 60 | 80 |
| 湿度 | 75% | 85% |
| 声音指数 | 82 | 92 |
| AI异常分数 | 3.5 | 5.5 |

MQ-2三个字段：`gasRaw`是原始ADC；`gasVoltage`是按分压还原的AO估算电压；`gasIndex`是把0～4V粗略换成0～100。它们都不能当准确气体ppm或CO₂。声音指数也不是分贝。

## 云AI与照片

DeepSeek是可选功能，需要联网和密钥，手动调用才可能计费。普通解读只发一次测量摘要（含有人/移动），不发照片或录音，不自动改变提醒等级；另有一句话控制入口，见[09](09-DeepSeek云解读.md)。不配置云AI，本地功能照常使用。

网页目前没有账号认证。同网用户可能看数据、看照片或触发操作；用强Wi-Fi/热点密码，不做公网映射，不把镜头对准他人隐私区域。

闻到燃气味、看到烟雾或听到正规报警器时，按现实安全流程撤离并在安全位置求助，不开关可能产生火花的电器，不等待本设备或AI下结论。本项目只用于学习和辅助提醒。
