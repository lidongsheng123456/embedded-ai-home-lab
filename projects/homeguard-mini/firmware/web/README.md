# HomeGuard Mini 家庭数据大屏

采用奶油白、浅木色和柔和绿，面向iPhone 17竖屏与电脑的一页总览：温度、湿度、气体、光照、声音、人体存在与移动，
同屏显示趋势、设备提醒、自动摄像头画面与24小时时间轴。无需拖动房间或滚动页面找数据。
已移除三维模型、学习进度、异常分数、原始ADC、重新学习与云聊天入口；固件本地学习仍自动运行。

## 打开和使用

- **真实数据**：从屏幕IP访问设备，或从家中电脑网关/公网HTTPS地址访问；默认不是演示。
- **iPhone**：Safari直接竖屏查看；分享菜单→添加到主屏幕可减少浏览器工具栏占用。
  页面使用动态视口与安全区留白，按钮至少44像素。极短横屏或放大字体时允许滚动，避免裁切数据。
- **实时**：状态请求完成后约2秒再次读取。电脑网关每5秒采样，多个页面读取同一缓存，减少ESP32负担。
- **回放**：选择近1/6/24小时，点选时间轴同时查看当时的录像和读数。绿色条标出已有录像；点击“回放”默认按1倍速度播放，可切换10/60倍，点击“实时”返回。
  回放中禁用静音；顶部仍独立显示设备当前连接状态。录像空档明确显示“该时段未录到画面”，不会用直播替代历史。旧版本没有录下的画面无法补回。
- **摄像头**：设备就绪后自动显示画面，不用点拍照。OV2640资料标称SVGA（800×600）最高约30fps、CIF（352×288）最高约60fps，这是传感器输出模式规格，不能当作网页JPEG直播的实测速度。本项目保留800×600清晰度，通过同一条MJPEG连接连续发送画面，避免公网每帧等待一次HTTP往返。网关去掉原200毫秒限速，串行取图上限20次/秒且每次完成至少让出10毫秒；此前公网连续30秒收到301帧，源端约10.16帧/秒、接收约9.99帧/秒。后续更快的设备端连续流试验仍出现看门狗复位，未通过稳定性检查，已恢复单张快照采集，当前不能宣称稳定提速。设备直连在上一帧解码后等待10毫秒再取图；关闭Wi‑Fi省电的完整相机固件已烧录，整机重启原因仍待排查，见[验收清单](../../docs/10-遗留问题与验收清单.md)。多个网页共用电脑采集结果，最多8路连续直播；慢客户端丢弃中间帧，避免积压。暂停/后台停止本页连接，电脑仍录像；失败等待3秒重连，演示模式不取图。
- **手机看完整画面**：点击“放大画面”进入页内全屏，按原始比例显示完整画面，支持iPhone与横屏；点击“关闭放大”回到总览。总览为所有读数保留空间，摄像头按比例留白，不放大裁切边缘。
- **静音**：只暂停声音10分钟；显示设备返回的剩余时间，不停止监测，不自动重试命令。

单个感知节点只代表设备附近，不显示虚构的各房间数据。MQ-2和声音是相对指数，不是浓度或分贝。

## 24小时记录在哪里

家中电脑运行`npm run remote`后，即使关闭手机网页也继续记录：传感器每5秒一次，录像约每秒一帧，无声音。
传感器位于已忽略的`firmware/.pio/remote/history.ndjson`，只保存传感器和状态字段，每5分钟清理过期记录。
录像位于同目录的`recordings/`，按分钟保存JPEG连续画面和时间索引（Motion JPEG，即把JPEG画面按时间连续回放），无需额外安装编码器。
录像图像容量上限4GiB，保留最近24小时，达到容量上限时先淘汰最旧分钟，因此可能不足24小时。
约30KiB一帧时一天约2.5GiB，实际随场景变化；不会把画面写进Git、发送给DeepSeek或永久保留。
录像每分钟及启动时清理过期分段；查询立即排除超过24小时的帧。网关重启可恢复索引，半写记录跳过；
电脑关机、休眠、相机掉线和磁盘失败期间不能补录。录像仅从本次更新后开始。

直接访问ESP32的IP时只有实时数据与本页临时曲线，提示“24小时回放需从家中电脑网关打开”。
电脑网关离线时，已经载入的历史仍可查看，并明确提示记录服务断开。磁盘写入失败会显示提示，
不能把直播缓存可查看当成录像已可靠保存。设备掉线后仍可回看电脑已有录像。
页面显示录像中断或磁盘失败时，应先检查对应原因；所有录像接口与网页一样要求登录，不能通过文件路径下载整个录像目录。

## 在外面访问家里的真实设备

公网入口通过家中电脑连接ESP32，不需要修改路由器端口转发。电脑侧更新大屏无需烧录；800×600相机画质需先烧录新固件。
浏览器访问HTTPS临时地址，先使用独立账号密码登录，再读取真实状态和发送控制命令。
电脑提供页面资源，只把白名单内的设备API和摄像头取帧请求转给ESP32；断线显示失败，
不会改用演示数据，也不会自动重试控制。默认地址仅绑定`127.0.0.1`，不可把设备裸接口直接开放公网。

先确认这台电脑可以打开`http://屏幕IP/api/status`。安装Node.js 20+和`cloudflared`
（Windows可以执行`winget install --id Cloudflare.cloudflared -e`）。在本目录打开两个终端。
第一个终端执行，示例IP须替换成屏幕当前地址：

```powershell
npm ci
npm test
npm run build
npm run remote -- --device http://192.168.31.96
```

首次启动会在`firmware/.pio/remote/config.json`生成独立随机密码，用户名为`homeguard`。
在本机编辑器打开该文件查看`password`，不要使用Wi-Fi密码，也不要提交或分享这个文件。
它与整个`.pio/`一样被Git忽略。更换密码或端口后需重启网关；再次指定`--device`只更新设备地址，保留登录信息。

第二个终端执行：

```powershell
cloudflared --no-autoupdate tunnel --protocol http2 --url http://127.0.0.1:4180
```

如果在Windows命令提示符（提示符类似`C:\Users\用户名>`）中找不到`cloudflared`，且由WinGet安装，可使用下面的完整路径命令：

```cmd
"%LOCALAPPDATA%\Microsoft\WinGet\Packages\Cloudflare.cloudflared_Microsoft.Winget.Source_8wekyb3d8bbwe\cloudflared.exe" --no-autoupdate tunnel --protocol http2 --url http://127.0.0.1:4180
```

命令提示符使用`%LOCALAPPDATA%`；PowerShell的`&`和`$env:LOCALAPPDATA`不能直接粘贴到命令提示符中。
日志出现`Registered tunnel connection`后，再访问输出地址验证页面和数据。

打开终端输出的`https://….trycloudflare.com`地址，浏览器会弹出账号密码框。
手机关闭Wi-Fi、改用移动数据后测试，确认能读到真实数据。控制请求仍由固件判断和执行，
摄像头取决于当前固件是否启用；登录成功不代表这些硬件功能已经验收。

两个终端必须持续运行，电脑不能关机或休眠，设备必须保持供电和联网；在终端按`Ctrl+C`停止对应进程。
这是无需账号的临时通道，没有固定地址或可用性保证，重启通道通常会换网址。
浏览器可能记住HTTP登录凭据，在共享设备上使用隐私窗口，用完关闭整个隐私窗口。
长期使用应注册平台账号，建立带身份验证的固定通道，再配置持续在线的小主机和固定域名。

## 摄像头与画面清晰度

新固件统一800×600 JPEG、质量参数10、PSRAM双缓冲；数值越小压缩越少。
两只10kΩ给MQ-2分压时使用`carrier_r1_full_st7789_camera`，Build→Upload后刷新页面。
原取图失败已由用户修正D4→GPIO38接错后恢复；临时降速、信号探针和诊断接口已删除。
本机已验证真实800×600 JPEG取图和自动更新；清晰度仍需目视确认，长时间稳定性需继续验收。

照片仍模糊时，检查保护膜、镜头污渍和光照，在明亮处拍静止文字并查看原图。
软件分辨率不能修复物理失焦；仅当镜头支持手动对焦时才小幅调整，不强拧固定镜头。
`camera=true`只代表初始化成功，503时查看`Camera:`串口日志，断电核对[相机接线](../../docs/03-接线教程.md#第七步ov2640独立验机接线)。

## 页面卡在等待设备连接

先访问`/api/status`，再检查浏览器Network中的`app.js`与状态请求是否成功。
已移除大型图形运行库，入口受24KiB gzip构建测试约束；旧缓存需强制刷新。
网关启动后首次采样前可能短暂离线；设备拍照仍可能阻塞主循环，不能据此声称严格实时。

## 模块分工

| 文件 | 职责 |
| --- | --- |
| `src/app.js` | 组装实时轮询、回放选择和用户操作 |
| `src/dashboard-view.js` | 中文状态和读数展示，不计算风险规则 |
| `src/history-model.js` | 记录合并、时间查找、保留尖峰与空档的趋势路径 |
| `src/history-controller.js` | 拉取历史、选时、播放和实时切换 |
| `src/camera-controller.js` | 自动串行取帧、暂停/恢复、后台释放与重连 |
| `src/camera-layout.js` | 手机页内全屏与完整比例展示 |
| `src/device-api.js` | HTTP超时和错误处理 |
| `src/demo-state.js` | 仅用于明确开启的模拟演示 |
| `src/styles/` | 基础、单屏布局、移动适配 |
| `server/history-store.mjs` | 白名单字段、24小时窗口、串行持久化 |
| `server/history-recorder.mjs` | 独立持续采样、失败空档、实时缓存 |
| `server/recording-store.mjs` | 分钟录像、帧索引、24小时与容量淘汰 |
| `server/camera-recorder.mjs` | 电脑持续采集、录像与多人共用直播缓存 |
| `server/camera-stream.mjs` | MJPEG连续直播、慢连接背压与断线退订 |
| `server/recording-routes.mjs` | 录像时段与按时间读取画面，不暴露文件路径 |
| `server/access.mjs` | 登录与来源校验 |
| `server/device-proxy.mjs` | 固定设备和控制路由的白名单转发 |
| `server/gateway.mjs` | 组装认证、历史、状态缓存和静态页面 |
| `scripts/remote.mjs` | 本机配置、采样服务启动和退出 |
| `asset-manifest.mjs` | 固件、预览、网关共享资源清单 |

原生SVG绘制曲线，没有浏览器运行时依赖或CDN。构建工具只有esbuild，生成物都在`.pio/web/`。
固件保留可选DeepSeek接口，但此大屏不调用、不显示云聊天；进阶用法见[09](../../docs/09-DeepSeek云解读.md)。
