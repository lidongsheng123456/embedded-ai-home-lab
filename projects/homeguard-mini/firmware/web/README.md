# 手机与电脑可视化大屏

这个目录是浏览器网页源码。ESP32把文件发给手机或电脑，浏览器负责绘制三维房间（Three.js）。
ESP32仍然负责真实采集、告警和本地学习，关掉网页不会停止监测。

## 先在电脑看效果

安装Node.js 20或更高版本，在这个目录打开终端：

```powershell
npm ci
npm run build
npm run preview
```

浏览器打开 <http://127.0.0.1:4173/?demo=1>。窗口保持运行时才能预览，按Ctrl+C停止。
这是明确标注的模拟演示，可以切换舒适日常、潮湿、气体变化和无人场景，不会控制实物。

## 烧录之后怎么用

1. 在上一级`firmware/`选择正确的PlatformIO环境，执行Build和Upload。
2. 让手机/电脑与设备在同一局域网内，输入屏幕或串口日志里的IP。
3. 家庭Wi-Fi连接失败时，连接设备热点，在浏览器访问 <http://192.168.4.1>。
4. 打开后默认读取真实API；页面会自动重试连接，连接失败会显示未知并禁用控制。
5. 在模型上拖动旋转，电脑滚轮或手机双指缩放；点击“复位视角”恢复初始角度。
6. 点击“全屏”进入浏览器支持的全屏模式；“暂停动效”可减少动态效果。

网页、字体替代方案、Three.js均来自本地，不依赖CDN。第一次构建需要互联网安装依赖，
依赖安装好后才可以离线构建。网页会自动压缩编入Flash，不用执行Upload Filesystem。

## 每一块画面是什么意思

| 页面区域 | 来自哪里 | 能说明什么 |
| --- | --- | --- |
| 房间人物 | LD2410C的“是否有人” | 只有有人/无人示意，不能确定人员位置、数量或实际户型 |
| 房间明暗 | BH1750照度 | 示意模型随当前照度变化，不代表真实天气、灯具状态或昼夜 |
| 扩散光环和状态圆环 | 固件返回的告警等级 | 正常、提醒、较大变化；浏览器不复制告警判断逻辑 |
| 数值和小趋势线 | `/api/status` | 当前数据，以及当前页面打开后最近40个采样点，无历史数据库 |
| 学习进度 | 模型已学习样本数 | 当前需120组有效数据，约10分钟；预热/传感器无效时不学习 |
| 摄像头快照 | 手动请求`/camera.jpg` | 点击才拍一张，不会自动拍照、上传云端或保存历史图片 |

静音只暂停蜂鸣器，监测继续；重新学习需要在弹窗里确认。演示模式下两项操作仅提示，
不会请求真实设备。MQ-2和声音数值都是相对指数，不能分别当成气体ppm或校准分贝。

## 文件职责

```text
index.html                 页面骨架、控件和语义标签
src/app.js                 组装模块、轮询、用户命令
src/device-api.js          HTTP状态与命令请求、超时处理
src/dashboard-view.js      状态翻译、DOM显示、小趋势线
src/camera-controller.js   手动拍摄、超时、快照按钮状态
src/room-model.js          基础几何体搭建家具与设备模型
src/room-scene.js          镜头、光照、动画、触控与资源释放
src/demo-state.js          只用于?demo=1的模拟状态
src/styles/                按导航、场景、面板、手机布局拆分样式
scripts/build.mjs          打包Three.js、gzip压缩、生成C++资源头
scripts/preview.mjs        本机静态预览服务，不连接硬件
tests/                     数据、API错误处理的自动检查
```

生成文件统一位于`firmware/.pio/web/`，不要手改或提交。前端依赖在`node_modules/`，
由锁文件安装，不进入Git。PlatformIO的`scripts/build_web.py`负责调用网页构建，
`src/ui/web_assets.cpp`查找资源，`NetworkService`按HTTP路径从Flash发送压缩文件。

为了减少手机发热，场景最多约30帧/秒，像素比例最高1.5；页面隐藏或场景滚出视野时
停止绘制。系统启用“减少动态效果”时默认暂停自动动画，数值和控制仍可使用。
不支持WebGL时显示降级提示，数据面板仍继续工作。

## 验证

```powershell
npm test
npm run build
```

前端测试与浏览器模拟检查不等于实物验证。还需用真实手机连接设备热点，确认gzip资源
传输、传感器联动、命令处理和摄像头快照；固件状态只能写“仅编译验证”。
