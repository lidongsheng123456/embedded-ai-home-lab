# 本地工程迁移与目录分层审查

审查日期：2026-11-12。范围为本次未提交的完整本地工程搬迁、硬件资料重排、辅助脚本和文档导航；不涉及固件功能或电路优化。

## 职责与依赖

- 项目级 `eda/` 保存嘉立创EDA完整工作工程；工程内部相对结构、原理图、PCB、规则和内嵌资源保持原样。
- `hardware/design/` 按接口、器件库、原理图组合、PCB 参数划分机器输入；`hardware/docs/` 保存人工说明。
- 工具按采集、原理图规划、PCB 规划、验证、装配、渲染划分；只有工程路径定位和同职责几何逻辑共享，没有新增通用杂项层。
- `hardware/releases/r1/` 保存冻结制造交付；`archive/` 保存历史检查点、工作归档和恢复核验工程。新设计不能覆盖旧发布证据。
- 本机过程文件、依赖及 MCP 客户端位于已忽略的 `.work/`，不纳入提交；未引入其他项目代码。

1. 修复脚本移动后的输入位置和 Python 本机依赖位置，显式文件参数按调用者当前目录解析。
2. 传感器规划改为输出新候选和连接目标，不再覆盖 `design/`；放置工具使用新输出并拒绝覆盖。
