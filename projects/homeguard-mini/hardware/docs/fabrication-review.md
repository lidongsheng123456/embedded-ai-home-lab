# R1 制造复核与告警处置

本记录对应 `releases/r1/verification/pcb-final.board.json` 及同目录原生 DRC，制造 ZIP 的身份与哈希记录在 [独立制造报告](../releases/r1/pcb/gerber-preview/manufacturing-inspection.json)。所有结果为设计/文件检查，尚无实物测试。

## 通过的检查

五页原理图逐页保存重开、原生 DRC 与逐项接线检查通过。全工程与设计源核对为 79 器件、346 物理引脚、30 明确 NC、75 网络；各 PCB 实例身份和每个焊盘网络均与原理图一致。原理图检查中的无接点交叉及图签缺项是 INFO，不是忽略了短路或悬空脚。

PCB 最后两轮检查均为原生 DRC 0 项错误。第二轮包含保存、关闭重开、重新铺铜、新鲜快照；两轮元件、焊盘、板框、丝印、规则、855 段线及 154 过孔内容一致。重新铺铜生成的填充对象 ID 会改变，其实际轮廓不变。

制造 ZIP 独立读取确认：外框约 100.00005 × 100.00005 mm（输出舍入误差）、四个约 Ø3.2017 mm 铣孔、256 个圆孔、4 条 USB-C 镀铜槽。全部圆孔中心与 PCB 通孔焊盘/过孔核对，未多出 U10 SDK 错误 hole 字段所暗示的孔。两个内层主地铜各约 8908.47 mm²，全部 60 个地过孔接入主地铜，信号过孔未接入主地铜；全部走线中心线在对应 Gerber 铜层中覆盖。

这项独立几何检查不是第二套完整电路 DRC：没有从 Gerber 反推所有器件电气网络，也不证明阻抗、EMI、时序或温升已实测。原生 DRC、逐脚身份、制造几何和图面是不同证据。

原生 EPRO2 已经官方导入为独立核验工程并打开：恢复后的原理图器件、网络、接线与源逐项一致；PCB 元件、板框、丝印、规则、铜线、过孔、覆铜边界、禁区和铣孔一致，恢复后的原生 DRC 为 0。没有覆盖正式工程，完成后已切回正式工程。

## 辅助 DFM 报告没有全通过

最终 `pcb-dfm.json` 原样保留：1 个 ERROR、66 个 WARN、23 个 INFO，共 90 项。其自身标记 `incomplete:true`，不支持 U10 的四个多边形焊盘；不能把它的包络猜测等同于原生规则，也不能删除报告来隐藏问题。

| 类别 | 结论与处置 |
|---|---|
| 1 个间距 ERROR | 报 I2C_SDA 过孔距 U3.19 为 6.7 mil。按实际 OVAL 焊盘轮廓及过孔圆盘测得 **9.3471 mil / 0.23742 mm**，高于 8 mil；是矩形包络误报。原生 DRC 通过。 |
| 45 个 3W 平行线 WARN | 含直流电源之间、使能与其电源、细间距逃线及麦克风等信号。3W 是经验建议，非短路规则。保留外层走线、相邻连续地和 8 mil 规则，不为了消警报破坏引出。最长麦克风 SD/WS 同向段约 34.2 mm；与实际线束的串扰、边沿质量须首板示波器验证，未声称完成 SI 仿真。 |
| 12 个电容距离 WARN | C2/3/4/5/6/8/28/29 是各模块接口去耦/储能，不能改移到中央监控 IC。C21/22 是电感后的降压输出电容，不是 FB 引脚去耦。U8 主要输入电容 C19 为 10µF，VIN 到最近电容焊盘中心约 2.36 mm；补充的 C20 100nF 较远。C26 为 U10 输入 100nF，中心距约 3.3 mm；U10 为限斜率电源开关。输入环路纹波与温升待首板验证。 |
| 2 个电源未铺铜 WARN | +5V、+3V3 使用明确线宽的外层树状配电，两内层保留连续 GND。+5V 主干 40 mil，外围 3.3V 主干 24 mil，负载分配见电气依据。没有为了满足检测器而把地平面切成电源岛。 |
| 2 个线宽 WARN | 电源细间距焊盘缩颈和地去耦短支线。高电流长主干已加宽；细脚缩颈的长度、并联引脚及真实铜在最终快照/Gerber 中保留，按当前负载分配验收，非任意 3A 满载保证。 |
| 4 个插头空间 WARN | 检测器用圆形包络和库 bbox 猜插头宽度，误把长排母当作圆形插头。已有二维实体/配对护套包络检查及固定采购尺寸约束；用户实物、USB 朝向和外壳仍按 1:1 模板复核，不能从假阳性推出实物已经插合。 |
| 23 个线宽不对称 INFO | 去耦电源/地或小封装引脚不同角色线宽，不要求两端机械等宽。 |
| 1 个定位点 INFO | 单板未放独立 Mark；裸板打样无影响。贴片采用加工方工艺边定位点，自拼板量产需重新确认定位工艺。 |

原先的悬空端、锐角、重复段、无换层过孔和排母焊盘旁过孔已修复。最终这些类别、丝印文字压盘、文字翻转、越界及浮空铜线岛均为 0。真实铜连通和原生 DRC 独立通过。

## 丝印与制造裁切

正面统一器件位号及接口标记，背面针序表通过实际 Gerber 目视与开窗几何复核。底面文字在原生镜像锚点处理上曾与辅助图不一致，最终以官方 Gerber 修正，不修改导出 SVG 来伪造结果。

底面丝印与阻焊开窗交叠面积为 0。顶面只有 **C25 库外形线四角、J11 库外壳线**共约 0.22103 mm² 交叠，不含文字、Pin 1、C25 正负号；按板厂常规丝印避开开窗处理，交付原始 Gerber 不做手工补丁。下单 CAM 应确认这些小段被裁切且功能文字保留。

官方画布截图因后台标签页不可重绘而未采集，原始失败回执保留；交付正反面图来自已核对的实际 Gerber 和钻孔。三维图来自官方 OBJ 的辅助投影，未增加虚构开发板和线束模型；不是机械碰撞求解结果。

## 仍需实物确认

开发板和配对插头插合、短 USB 线与天线馈线、外壳通风、供电倒灌、启动瞬态、3.3V 降压纹波与温升、相机并行总线、麦克风及屏幕信号、全部功能按[首板清单](first-board-validation.md)执行。现有六环境固件为**仅编译验证**。任何模块超出电流分配、采购尺寸或信号电平条件都需要重新设计审查。
