# 机器可读设计输入

这里保存设计意图和已核对的参数，嘉立创EDA可编辑工程位于项目级的 [eda/](../../eda/README.md)，设计解释位于 [docs/](../docs/README.md)。JSON 里的 `candidate` 表示设计候选，不能当作当前编辑器已实现状态。

| 目录 | 职责 |
|---|---|
| `interfaces/` | 开发板和各功能接口针序、供电与信号约定 |
| `library/` | 经真实器件查询得到的选型与器件绑定 |
| `schematic/` | 原理图模块组合、连接目标和呈现参数 |
| `pcb/` | 板框、布局、机械约束及布线规划输入 |

依赖顺序是接口与真实器件 → 原理图组合 → PCB 布局和连接规划。脚本读取这些输入和新鲜现场快照，先在 `.work/` 生成候选，再通过 typed CLI 执行。验证脚本独立比对目标与观察值，不以生成候选成功作为通过依据。

本次仅移动 JSON，保留原始字节及哈希；历史验证引用通过 [structure-migration.json](../archive/structure-migration.json)映射。将来修改设计输入后必须重新验证，不得沿用历史哈希。
