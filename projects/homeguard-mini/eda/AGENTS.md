# 可编辑硬件工程

本目录继承上级规约，适用于工作工程及 `hardware/`。

- 修改前阅读本目录 README、`hardware/README.md` 和目标工具入口。
- 当前主板为 Board2 / Schematic2 / PCB2；先通过健康检查和工程信息读回身份，不硬编码旧路径对应 UUID。
- 最新供电决定：删除 J11，保护后的 5V 直接接母座 J7.21，不增加额外跳帽；厂家要求短接开发板 IN/OUT。用户选择先断电、取下开发板再接电脑 USB，不同时接载板与开发板 USB。
- `hardware/design/interfaces/header-power-change.json` 记录新版变化。历史 composition/布局含旧身份与 J11，只作来源，不直接重放。
- 使用嘉立创 typed 接口编辑并保留完整工程结构，不手改 `.eprj3`、原理图、PCB 或原始观测。
- 修改后显式保存、重载、新回读；两轮检查及制造核对后才更新当前验收状态。历史通过不能替新版签字。
- 唯一打样源为本目录完整 `.eprj3` 工程中的 PCB2；不再建立 `releases/`、`archive/` 或历史恢复副本。需要加工文件时从当前工程生成，临时导出放忽略目录。
- 检查结论维护在现有验收清单；原始观测与衍生报告只保留本机临时文件，失败不得改写为成功。临时候选、重复导出和本机依赖放已忽略的 `hardware/.work/` 或工作区 `.easyeda/`。
- 以 Git 中的完整原生工程作为日常恢复来源，不为每轮修改另建恢复工程或复制备份目录。加工输出从当前工程按需生成，不取代 Git 提交记录；回退应保留后续用户改动，不直接重置整个工作区。
- 不新增重复的审查总结；当前问题统一维护 `../docs/10-遗留问题与验收清单.md`，具体电气依据与操作只在已有专门文档维护。
