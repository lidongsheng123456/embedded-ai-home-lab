# 可编辑硬件工程

- 本目录的 `.eprj3` 文件夹是后续优化的工作源；修改前阅读本目录 README 和 `../hardware/README.md`。
- 当前主板为 Board2 / Schematic2 / PCB2。先通过健康检查和工程信息读回当前身份；本地工程 UUID 可能随路径变化，不硬编码旧 UUID。
- `../hardware/design/` 是历史设计输入，候选计划可能含旧工程身份和旧图元 ID，不直接重放。读取当前对象后生成新的候选。
- 使用嘉立创EDA typed 接口编辑，保留完整原理图、内嵌库、板框、规则和工程相对结构；不要单独移动 `.eprj3` 或手改原始观测来消除检查错误。
- 当前已知有 1 项网表不一致待处理，先复核最新结果；历史 R1 发布通过记录不覆盖当前工作版。
- 优化后显式保存、重载、重新读取和检查，再生成新的制造交付。`../hardware/releases/r1/` 是冻结版本，不直接覆盖其制造文件或原始报告。
