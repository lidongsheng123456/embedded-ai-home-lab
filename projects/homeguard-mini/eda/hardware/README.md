# HomeGuard Mini 载板

当前工作版为 **R2 精简排母供电**，100 × 100 mm、R3 圆角、四层。打开[唯一嘉立创原生工程](../README.md)中的 **PCB2** 直接打样，参数与步骤也在该入口。原生工程由 Git 管理，不保留重复的发布包、历史导出和恢复副本。当前检查与实物待验统一见[验收清单](../../docs/10-遗留问题与验收清单.md)。

## 电源与烧录

载板 J10 接已有的专用稳压 **5V/3A 电源及对应线**，经 F1 保险丝后形成 `+5V`，直接供母座 **J7.21 → 开发板 5V**、MQ-2、雷达、功放接口和 U8。D1 保留输入瞬态钳位；已删除旧 U7/U10 的主动限流、软启动和反向阻断。旧 J11 USB-A 保持删除。

厂家要求先短接开发板上标出的 **IN/OUT 两块焊盘**。它们不是 5V/GND 排针；具体步骤见[供电与烧录操作](docs/header-power-review.md)。正常使用只接载板电源；烧录前断电、取下开发板，再接电脑 USB；烧录后拔 USB 再装回。不带电拔插。

外围模块由载板独立3.3V供电，`MCU_3V3`供按钮外围并引到学习排针，可用外带电流未知；两路3.3V不并联。厂家建议电源能力大于1.5A，不代表开发板恒定耗电1.5A；整机峰值、启动与温升仍待首板实测。

## 接口表

2026-11-19按外壳自定义位置的需求，采用“开发板、麦克风板上直插，其余模块按功能接线安装”的方案，具体位置与线长起点见[外壳装配表](../../docs/07-一体化制作.md#模块固定还是接线)。外接模块也要用支架固定，不能悬挂在线上。已增加两个I2C扩展口，并将J13改为匹配实物七针；GPIO分配沿用。

J1、J4、J6仍是按实物完整针序设计的2.54mm排母，现在分别给MQ-2、雷达、屏幕接公对母杜邦线：公头插载板排母，母头接模块排针。麦克风保留两排各三孔直接插接。下表从PCB顶面Pin 1标记沿编号方向读；右侧MQ-2接口从上向下为1～4，左侧雷达从下向上为1～5。模块可以随接口整体旋转，不能把底面镜像当成模块文字面。

其余XH接口为载板自定义针序，针距2.50mm，需要“匹配XH插头→模块侧杜邦母头”的转换线，不能硬插2.54mm杜邦头。J12使用匹配简牛插头的短转换线；不是20针对18针的直通排线。全部线束断电制作并按信号逐根测通断，不能只按线色接。

麦克风按用户图片文字面，从左到右：

| 排列 | 左 | 中 | 右 |
| --- | --- | --- | --- |
| 上排 | J5：GND | J14：VDD / +3V3 | J15：SD / GPIO6 |
| 下排 | J16：L/R / GND | J17：WS / GPIO5 | J18：SCK / GPIO4 |

L/R固定接地，使用左声道。六孔阵列中心位于板坐标(10,40)mm，按用户指定2.6mm/7.3mm设计，不按普通2.54mm双排座代换。首件先断电套合，核对文字面和声孔方向。屏幕SCL/SDA分别是SPI时钟/数据，不是I²C。

J13从PCB顶面左→右为1～7，按用户确认的实物针序用公对母杜邦线逐脚连接，GAIN线可以不装。GPIO45 是启动配置脚，R22=10kΩ 下拉必须装，只接功放高阻 DIN，不接上拉或外部输出。功放SD由J13.5接+5V，GAIN对应J13.4明确悬空；喇叭只接 OUTP/OUTN，两端均不能接 GND。现有固件只有麦克风接收，尚未实现播放；原蜂鸣器保留。

J19/J20复用R8/R9上拉和现有I2C总线，仅接3.3V低功耗模块；地址不能冲突，接新传感器仍需软件驱动。

J21/J22位于主控两侧、中心(32.22,50)/(67.78,50)mm，逐针与母座对齐。采用断电拔模块线、换学习程序的低成本复用方案；GPIO3分压滤波、39按钮、45下拉等板载外围仍连接。六页正式原理图已有中文功能标题、接线说明和供电限制，新增页为“06 通用学习扩展”。

25 路主控信号现为直连，已删除双电源稳定监控与总线开关，不支持热插拔或任一路单独供电。MQ-2 接 GPIO3（启动配置脚）的现有方案需首板反复冷启动确认。

MQ-2的J1.2（DO）、雷达J4.3（OUT）保留物理孔但明确不接铜线；AO改为J1.1。J1 AO 已有 10kΩ/10kΩ 分压与 100nF 滤波，不再串面包板分压。载板仍使用 `carrier_r1_core_st7789` 或 `carrier_r1_full_st7789_camera` 编译环境，名称保留以兼容既有配置；两环境分压还原系数均为 2。

J3 已由四针换为五针；第 1、2 脚在当前原理图中都接地。若第 1 脚用于模块的地址选择脚（ADDR），接地对应常用地址 `0x23`；转换线仍须按实物模块丝印核对，不能只按插座左右方向照接。

GPIO16 用于相机 PCLK；GPIO35/36/37 留给 OPI PSRAM，GPIO19/20 留给原生 USB。GPIO39 短按静音，按住至少 2 秒松开重新学习。开发板为泽杰 ESP32-S3 N16R8、双 Type-C、CH343、外接天线版本，机械按厂家尺寸设计，尚未完成实物套合。
