# HomeGuard Mini 载板

当前工作版为 **R2 排母供电**，100 × 100 mm、R3 圆角、四层。打开[唯一嘉立创原生工程](../README.md)中的 **PCB2** 直接打样，参数与步骤也在该入口。原生工程由 Git 管理，不保留重复的发布包、历史导出和恢复副本。当前检查与实物待验统一见[验收清单](../../docs/10-遗留问题与验收清单.md)。

## 电源与烧录

载板 J10 接已有的专用稳压 **5V/3A 电源及对应线**，经过输入保护、U10 反向阻断和缓升后接母座 **J7.21 → 开发板 5V**，地脚共地。旧 J11 USB-A 已删除。`USB_MCU_5V` 为保留的历史网名，现表示这条排母电源。

厂家要求先短接开发板上标出的 **IN/OUT 两块焊盘**。它们不是 5V/GND 排针；具体步骤见[供电与烧录操作](docs/header-power-review.md)。正常使用只接载板电源；烧录前断电、取下开发板，再接电脑 USB；烧录后拔 USB 再装回。不带电拔插。

外围模块由载板独立 3.3V 供电，`MCU_3V3` 只供逻辑开关、监控和按钮，两路 3.3V 不并联。厂家建议电源能力大于 1.5A，不代表开发板恒定耗电 1.5A；整机峰值、启动与温升仍待首板实测。

## 接口表

以下为载板自定义针序，**不是模块通用针序**。XH 为 2.50 mm，不能直接当作模块 2.54 mm 排针；转换线按实物丝印制作。

| 位号 | 模块 | 从第 1 脚开始 |
| --- | --- | --- |
| J1 | MQ-2 | +5V、GND、AO 原始信号 |
| J2 | SHT40 | +3V3、GND、SDA、SCL |
| J3 | BH1750 | +3V3、GND、SDA、SCL |
| J4 | LD2410C | +5V、GND、模块 TX→GPIO17、模块 RX←GPIO18 |
| J5 | INMP441 | +3V3、GND、BCLK、WS、SD、GND（L/R） |
| J6 | ST7789 | GND、+3V3、SCLK、MOSI、RST、DC、CS、+3V3（背光） |
| J7/J8 | 开发板母座 | 双排各 22 孔，2.54 mm 针距、25.40 mm 排距；J7.21 为 5V |
| J9 | 有源蜂鸣器模块 | +3V3、GND、IN；3.3V 高触发且自带驱动 |
| J10 | 电源输入 | 专用 5V/3A USB-C，不含 PD 协商 |
| J12 | OV2640 | 自定义 20 针，见[逐根转换表](docs/camera-adapter.md) |

MQ-2 DO、雷达 OUT 不接。J1 AO 已有 10kΩ/10kΩ 分压与 100nF 滤波，不再串面包板分压。载板仍使用 `carrier_r1_core_st7789` 或 `carrier_r1_full_st7789_camera` 编译环境，名称保留以兼容既有配置；两环境分压还原系数均为 2。

GPIO16 用于相机 PCLK；GPIO35/36/37 留给 OPI PSRAM，GPIO19/20 留给原生 USB。GPIO39 短按静音，按住至少 2 秒松开重新学习。开发板为泽杰 ESP32-S3 N16R8、双 Type-C、CH343、外接天线版本，机械按厂家尺寸设计，尚未完成实物套合。
