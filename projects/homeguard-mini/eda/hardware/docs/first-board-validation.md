# 载板首板验收与实物待确认

本清单尚未执行，全部项目均待实物确认。设计检查通过不代表已经实测。首板使用可限流的 5V 台式电源、万用表；纹波、启动和高速信号另需示波器。不要带电插拔模块或换线。

本页操作以[当前原生工程](../../README.md)中的 **R2 排母供电**为准。用户已有 5V/3A 电源及线，机械按厂家标称设计，尚未实物套合。

## 机械与线束

- 开发板双排各 22 针，2.54 mm 针距、25.40 mm 排距、53.34 mm 首尾针距；从当前 PCB2 按需输出 1:1 图套合，并用实物复核。厂家外形容差、天线馈线和按钮操作空间仍待确认。
- 外壳尚未定尺寸，不能声称适配现成盒子。四个 M3 孔、模块锁扣和线束弯曲都要留空间。
- 相机使用 3.3V、自带晶振的模块与短转换线，不推测可直插；信号质量需实测。
- 配对模块插头投影按插座每侧扩大 0.5 mm 预留，实际更大须调整。蜂鸣器为 3.3V 高触发、自带驱动的有源模块。
- R2 直接通过排母供电，无盒内 USB 短线；核对板边 J10 与外壳开口，插头应能完全插入并留出拔插空间。

## 1. 不上电检查

1. 从当前 PCB2 输出 1:1 图，按 100% 打印并用尺子确认没有缩放，再核对开发板双排 22 针、25.40 mm 排距；确认天线馈线、按钮和全部插头不碰撞。必须根据实物模块丝印制作转换线，不能认为 XH 与 2.54 mm 排针通用。
2. 放大检查 U7 WSON、U10 VQFN、U9 小封装、USB-C 电源脚是否桥连、虚焊；检查 C25 正负、D1 阴极、D2 极性。通孔插座与 USB 外壳脚焊牢，清理残留锡珠。
3. 开发板及模块全部不插。断电测 +5V、+3V3 与地之间阻值，电容充电后的阻值不应持续接近短路；若异常，先排查焊接，不能直接上电“试一下”。检查 GND 连通、J7.21 与 U10 保护输出/C25.1 导通，且与 GND 不短路；两路 3.3V 不并联。
4. 对照[相机逐根线表](camera-adapter.md)、[接口表](../README.md)逐根检查线束通断及反插方向。蜂鸣器必须是 3.3V、高电平触发、自带驱动的有源模块。

## 2. 仅载板上电

1. 不插开发板和模块，从 J10 接 5.0V，初始限流约 0.2A。若持续限流、反复启动、发热或异味，立即断电排查，不盲目调高限流。
2. 测 J1 的 1→2 脚为主 +5V，J2 的 1→2 脚为外围 +3V3。3.3V 目标约 3.3V；初步放行范围 3.20～3.40V，超出则查稳压器、测量和负载，不能据此取代器件全容差分析。
   冷启动还须测保险丝后的 `FUSED_5V`（U7.3/4）达到至少 4.50V；当前 R13 为 24kΩ，典型开启约 4.08V，计入所列误差的开启上限约 4.445V。若输入已足够而保护后仍无输出，检查 R13/R14、EN、电流限制及焊接，不能把 EN 直接短接到 5V 绕过问题。计算依据见[电气说明](electrical-review.md)。
3. 测 J7.21→GND 有约 5V；开发板未插时 `MCU_3V3` 应无正常供电，信号开关应保持断开。不要因悬空节点的万用表读数就判定隔离失效，需结合阻抗和泄漏规格。
4. 空载运行 10 分钟记录输入电流和 U7/U8/U10 温度。空载异常高温不通过。

## 3. 开发板与上下电

1. 断开所有电源，按厂家图短接开发板 IN/OUT 双焊盘（不是 5V/GND），核对后插母座。开发板两个 USB 口均不接线。逐步放宽限流以支持启动；厂家建议电源能力大于 1.5A，不代表实际耗电，不能据此把所有支路电流上限相加。
2. 测开发板自己的 3.3V 与载板外围 +3V3，确认两轨均稳定；检查 `ISO_OE_N`：任一轨未稳定时不得导通，两轨稳定并经过监控延时后应拉低。必要时用示波器确认，而非仅看直流值。
3. 验证载板供电、输入掉电和反复启动。烧录必须先断电取下开发板，电脑 USB 拔掉后才装回；不做开发板插在载板时同时接电脑 USB 的测试。
4. 开发板取下时用自己的 USB 数据口烧录 `carrier_r1_core_st7789`；全部单模块验证后再使用完整相机环境。插回运行时从 Wi-Fi 网页观察状态，带载串口调试需另用可靠的数据/地连接方案。

## 4. 单模块再到全负载

每次断电增加一个模块。建议 SHT40 → BH1750 → ST7789 → INMP441 → LD2410C → 有源蜂鸣器 → MQ-2 → OV2640。确认每次新增后的电流、电压和通信均正常，再继续下一项。

- SHT40/BH1750：I2C 上拉只能接 3.3V；载板与模块并联上拉后的总阻值、波形与读数应正常。温湿度模块远离 MQ-2 加热器和稳压器，外壳需通风。
- MQ-2：AO 接载板 J1.3，DO 不接；板上已有 1:1 分压，固件还原系数为 2。测 ADC 端不超过 ESP32-S3 允许输入，不能接原始 5V 信号。MQ-2 只能作相对指标，不用于可燃气体浓度认证。
- LD2410C：模块 TX→GPIO17、模块 RX←GPIO18，OUT 不接；检查模块的信号电平与供电满足要求。
- ST7789/INMP441：核对针序及屏幕背光电流；示波器检查时钟、数据、过冲和地参考。必要时依据波形调整已留的屏幕串阻，调整后重新做设计检查。
- OV2640：使用用户商品图所示 3.3V、自带陶振版本，短转换线建议先控制在 50 mm 内，地线按表连接；这不是已验证的最大允许线长。检查 PCLK、帧同步、图像稳定性和持续采集，结合实际线束测波形。不得接 5V 相机信号。
- 按钮/蜂鸣器：短按静音，按住至少 2 秒松开重新学习；蜂鸣器模块电流不由 GPIO 直接承担。

## 5. 记录与放行

全模块运行、Wi-Fi 发射、屏幕刷新、相机采集同时开启，记录输入峰值电流、J7.21/开发板 5V 电压、两路 3.3V 纹波、复位次数及最高温度。用短接地弹簧测纹波，避免长地线引入假振铃。高环境温度、冷启动与重复上下电另测。

电流不得超过现有分配：开发板 0.70A、MQ-2 0.20A、雷达 0.20A、外围 3.3V 合计 0.50A，整机设计分配 1.60A。超出需重新核算接头、保险丝、限流与铜宽，不能只换大保险丝。限流/短路恢复测试仅在熟悉仪器的条件下使用受控电子负载，不用导线直接短接 USB 口。

只有上述实物结果记录齐全后，才能称为“首板实测通过”。外设在程序启动后才上电需重启初始化；现有固件未宣称支持任意热插拔。外壳、防静电、EMC 和长期可靠性均不在本次设计检查的认证范围内。
