# 当前 R2 制造检查与告警说明

更新日期：2026-11-12。唯一打样源是[完整原生工程](../../README.md)里的 **PCB2**。原生工程和改动使用 Git 管理；旧发布包、历史导出及恢复副本已按用户要求移除。本页保留判断依据，临时检查输出不加入版本库。

## 已检查的范围

- 原理图与 PCB 逐脚对账：78 器件、340 焊盘、27 明确不连接脚、75 网络。取消 J11，J7.21 从不连接改为保护后 5V，其余逐脚网络不变。
- 先前已同步删除 J11 后七个器件的内部编号；本次丝印检查期间完整重开 EDA，又检出电源页19个内部 Channel ID 与新鲜官方网表不一致。已核实 Board2 绑定正确，具体差异仅为这些编号，再经官方导入变更同步。完整重开应用后仍通过 DRC，随后显式保存、关闭重开、新回读与两轮原生图面检查均通过，DRC为0项。同步前后器件快照、焊盘网络、板框、规则、既有文字和铜逐项相同（枚举顺序不计），未放宽检查规则；内部编号差异不能仅凭接线相等就忽略。
- 后续电源容差复核将 R13 从 27kΩ / C17593 换为 **24kΩ / C17575（0805W8F2402T5E）**，降低冷启动门限；通过真实库换件、导入变更同步两侧身份，并恢复导入时被重置的 R13 位号字体。再次保存、重开后连续两轮新回读与原生整板画面检查通过，PCB DRC 均为 0 项；电源页原生 DRC 为 0 项。全部实际铜、焊盘网络、器件位置、板框、规则和丝印几何与换件前相同，物料身份与隐藏阻值更新，不沿用旧物料表。原因及实测边界见[电气依据](electrical-review.md)。
- R2 布线和铺铜完成后已保存重载两轮检查；后续 R13 换件另完成两轮新回读，实际铜保持不变。原生 PCB DRC 为 0 项，未放宽规则来掩盖走线错误。C25.1 → J7.21 的供电铜路径接通，最窄 40 mil、两个过孔。
- 五页原理图原生 DRC 0 项、桥接和孤儿线检查通过；辅助版式检查仍有缺分区框 WARN、无接点交叉及图签 INFO，不声称严格检查全部通过。
- R13 更换后已从当前 PCB2 重新导出 Gerber，并独立核对板框、圆孔、槽、走线中心线及两内层主地铜过孔接触。251 圆孔包含 155 过孔，另有四个 USB-C 镀槽及四个约 Ø3.2 mm 安装铣孔；没有缺失或额外钻孔中心、遗漏的走线中心线、地过孔脱离主地铜或信号过孔误接主地铜。以后修改 PCB 必须重导出重查。
- 同次官方贴片坐标与当前 78 器件逐项匹配，参考点、板面、旋转及中心均一致；32 种料号的位号、数量、型号与 C 编号也同新鲜官方网表和 PCB 清单匹配，R13 确认为 24kΩ / C17575。物料清单来源是官方网表整理（`derived-netlist`），不是此前返回空文件的官方 BOM 导出；没有将失败接口改写为成功。纯贴片为 67 件，J10 仍须另做混合焊接。
- 已由用户手动导入当次原生导出做恢复核对：五页原理图器件/网络一致，PCB 器件、规则、板框、走线和过孔一致，铜填充仅有小于 1e-7 mil 的浮点舍入差异。恢复副本新增 72 条不可见 3D 库属性；未称字节完全相同。恢复后 PCB 和五页原理图原生 DRC 均通过，后续不再新建恢复副本。

用户将当前原工程置前台后，已取得并查看两轮有效的原生整板画面，第二轮包含保存、关闭重开及新回读；另查看顶面和底面图层，板边 USB、双排母座、接口与安装孔布局无新增待修问题。临时观察后已逐项恢复并核对原来的 262 项图层状态和画布过滤设置，没有修改元件属性可见性。既有 OBJ 投影另用于辅助查看板体与插座位置，不证明外接模块或外壳已完成机械套合。

原生文件含宿主保存时物化的默认图层记录，以及此前重新铺铜产生的填充 ID、轮廓集合排序变化。两内层 GND 的每条轮廓内部坐标与圆弧数据逐项相等；本次保存还由宿主规范化12条图层非活动颜色的十六进制写法，并更新库缓存的客户端与时间元数据。未手工删改原生文件，不以文件逐字相同代替几何核对。

制造文件几何检查不能证明阻抗、干扰、温升或真实线束时序；截图和相似外观也不能替代接线核对。原始画面和回读仅放本机已忽略目录，不增加发布文件。

## 辅助检查没有全部通过

辅助 DFM 是“按经验找潜在制造问题”的工具。本次为 **91 项：1 ERROR、67 WARN、23 INFO，且 incomplete:true**，不能说没有告警。

| 提示 | 判断与处置 |
| --- | --- |
| 1 项间距 ERROR | 检测器把 U3.19 椭圆焊盘按矩形估算，报 6.7 mil；真实轮廓净距为 9.3471 mil，大于 8 mil，原生 DRC 通过，判为包络误报。 |
| U10 四个多边形焊盘不支持 | 独立按实际轮廓补核 U10 全部焊盘对其他焊盘、顶层导线和过孔；焊盘之间按 7 mil、其他铜按 8 mil，0.01 mil 舍入容差，通过。不能据此说工具已支持多边形。 |
| 47 项平行线 3W | 3W 是经验间隔建议，不是短路规则；涉及电源、使能、细脚引出和麦克风等。保持连续内层地，首板测线束串扰和波形，未做信号完整性仿真。 |
| 12 项电容距离 | 包含接口电容和降压输出电容，不能一律搬到某颗芯片旁。U8 主输入 C19 距最近焊盘中心约 2.36 mm，U10 输入 C26 约 3.3 mm；纹波和启动需实测。 |
| 2 项电源未铺铜 | 5V 和 3.3V 用外层树状配电，两内层保持地；主干分别 40/24 mil，不为消警报切割地层。 |
| 2 项局部线宽 | 细间距电源脚及短去耦支线有缩颈；不能把主干线宽理解为任意 3A 满载保证。按负载预算验收。 |
| 3 项插头空间 | 圆包络不适合长母座；模块配对护套按插座每侧最多多 0.5 mm 预留，实物更大须调整。未完成实物插合。 |
| 23 项线宽不对称、1 项定位点 INFO | 电源/地角色不同，不要求两端机械等宽；裸板无独立 Mark，贴片需加工方工艺边定位点并确认首件。 |

## 丝印与首板

旧“DO NOT FEED 5V PINS”已在真实 PCB 改成“BRIDGE MCU IN/OUT”，顶面为“REMOVE MCU BEFORE USB”。改字后重新完成两轮检查，没有只改图片。

新增[两只狗的单色矢量头像](../design/pcb/dogs-silkscreen.svg)，依据用户照片保留左侧吐舌、右侧眨眼特征，简化背景、牵引绳和细毛。图案在**底层丝印（第4层）**，不是参考图片层；尺寸约35.56×19.72mm。实际底面观看时为吐舌狗在左、眨眼狗在右，朝向与照片一致；从顶面透视看底层时会左右镜像。调整方向后已保存、重开并检查原生图面和实际Gerber。

实际新增油墨约236.216mm²，板坐标范围X=45.72～81.28mm、Y=31.07776～50.8mm。距底面焊盘开窗最小约7.174mm、既有底面丝印约2.367mm，原文字无删减。重新导出的四层铜、顶面丝印、阻焊、锡膏解析几何与添加前一致，钻孔、板框、走线中心线及内层主地铜复核通过；不以导出文件的时间戳、未使用孔径定义或字节差异判断电气变化。

底面丝印与开窗交叠 0；顶面仅 C25 库外形四角约 0.017784 mm²，不涉及文字、Pin 1 或极性。让工厂按常规裁切外形小线段，并确认功能文字保留。

本版可进入首板试制；实际插合、IN/OUT 焊接、电源启动、压降、温升、相机与音频信号仍按[首板清单](first-board-validation.md)验收。固件六环境为**仅编译验证**，本设备用于学习和辅助提醒。
