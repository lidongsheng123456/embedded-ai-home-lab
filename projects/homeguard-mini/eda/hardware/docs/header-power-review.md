# 开发板通过母座供电

日期：2026-11-12。目标是开发板插到载板上就能工作，取消盒内 USB 短线。R2 已在真实原理图和 PCB 中完成，保存重载两轮原生 DRC 均为 0 项；直接从[完整原生工程](../../README.md)的 PCB2 打样。实物仍待验。

## 厂家答复和使用方式

用户提供的泽杰旗舰店客服聊天截图明确回复：

- “5v输入需要把板子上的inout短接”。
- 可以排针供电，也可以接 USB 调试。
- 问及防倒灌保护与推荐供电能力时，回复“没有，大于1.5A”。

因此不能把“可以调试”解释成已经有两路电源隔离。用户明确选择：**烧录时将开发板取下载板，不同时接排母和电脑 USB。** 本设计以此为装配和使用条件。

厂家“大于 1.5A”说的是电源可提供的能力，不代表开发板一直消耗 1.5A。整机继续使用专用稳压 5V/3A 电源；开发板与所有外设同时工作时的实际电流、压降及温升仍需首板测量，旧电流分配不能冒充厂家最大耗电数据。

## 电路变化

```text
载板 USB-C 输入 J10
  → 输入保险及电子保护
  → 受保护 +5V
  → U10 开发板支路（反向阻断、缓升）
  → C25 储能与去耦
  → 母座 J7 第21脚
  → 开发板 5V 排针
```

J7 第22脚及右侧母座的地脚仍与载板共地。删除原来 J11 USB-A 供电插座和它的专用铜线；保留电源保护和电容。

内部网络沿用历史名称 `USB_MCU_5V`，新用途是“受保护的开发板排针 5V”，并不表示 USB 数据线。引脚连接与原理图/PCB 验收以当前读回为准。

外围模块的 3.3V 仍由载板单独产生；开发板的 `MCU_3V3` 仅用于逻辑开关、监控和按键，两路 3.3V 不并联。开发板母座已核对的库器件额定电流为 4.7A；这不能替代开发板自身排针、稳压器和实际热设计的验证。

## 装配与烧录

1. 断开所有电源。按厂家清晰标注核对开发板 IN/OUT 焊盘，再按厂家要求短接。
2. 用户已提供带红框和箭头的焊接位置照片，位置证据已取得，实物尚未焊接。短接对象是该图标出的 IN/OUT 两焊盘，**不是 5V 与 GND 两根排针**；不短接可能导致排针供电无法工作。
3. 对准方向和每排 22 针，把开发板垂直插入母座，检查没有偏一排或反插。
4. 正常运行只给载板 J10 接专用 5V/3A 电源；开发板自身的两个 USB 口均不接线。
5. 烧录前先断开载板电源，取下开发板，再接电脑 USB 烧录或串口调试。
6. 烧录后拔掉电脑 USB，再装回开发板，最后给载板上电。**不带电拔插开发板。**

用户已确认有 5V/3A 电源和对应线，并决定按厂家标称的 25.40 mm 排距、53.34 mm 首尾针距设计。该决定不等于已完成实物测量或套合，装配时仍按实际插合情况验收。

这套使用方式下，在载板上运行时使用 Wi-Fi 网页查看状态。需要串口查看带载调试信息时，须另设计只接数据和地、不接 USB 电源的可靠方案；当前不宣称支持开发板插载板时直接插电脑 USB。
