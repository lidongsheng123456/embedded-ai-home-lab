# 嘉立创 EDA：从原生工程直接打样

唯一工程入口：[HomeGuard Mini 载板 R1 20261111.eprj3](<HomeGuard Mini 载板 R1 20261111/HomeGuard Mini 载板 R1 20261111.eprj3>)。

文件夹保留历史名称，里面的正式板是 **Board2 / Schematic2 / PCB2**，当前 PCB 丝印及供电方案为 **R2 排母供电**。PCB1 是早期空板，不用于打样。整个工程文件夹必须一起保留，不能只复制 `.eprj3` 一个文件。

## 怎么打样

先看[载板待补元件清单](../docs/02-材料清单.md#载板待补齐完整32种料号)：每板32种料号、78个器件目前待补齐。**只下单PCB打样通常是空板**；元件采购、贴片、插件及J10混合焊接须另外确认。已有的开发板和传感器不包含这些板上元件。

1. 在嘉立创 EDA 打开上面的 `.eprj3`，进入 **Board2 的 PCB2**。
2. 保存工程，重新铺铜，运行原生设计规则检查（DRC，检查短路、间距和未布通等问题）。本次验收结果为 0 项；以后改板后必须重新检查，不能只引用本页旧结论。
3. 在 EDA 中查看顶面、底面和 3D，核对 USB-C J10 沿板边、开发板母座方向、丝印、安装孔及配对插头空间。
4. 从当前 PCB2 直接发起 PCB 打样，核对下表参数。若委托贴片，同时由当前工程生成物料表与贴片坐标，确认 J10 的混合焊接工艺。
5. 厂家尺寸、实物套合与上电步骤按[首板验收](hardware/docs/first-board-validation.md)执行。这是首板试制，尚无实物测试结果。

若重新打开后出现“PCB 与原理图网表不一致”，先查看具体差异再处理，不要关闭规则。本次完整重开检出电源页19个内部编号未同步，已按新鲜官方网表通过官方导入变更修正，完整重开应用及后续保存重载检查后DRC均为0项；引脚接线相同也不能代替这项原生核对。

PCB2底面现有[两只狗的单色头像](hardware/design/pcb/dogs-silkscreen.svg)，已经进入实际制造丝印；尺寸、朝向与净距见[制造检查](hardware/docs/fabrication-review.md#丝印与首板)。

当前 R13 已由 27kΩ 改为 **24kΩ / C17575**，增加电源线有压降时的冷启动余量；PCB 位置和铜线不变。委托贴片应从当前工程生成物料表，不能复用修改前的清单，计算依据见[电气说明](hardware/docs/electrical-review.md)。

| 下单项目 | 参数 |
| --- | --- |
| 板材、尺寸 | FR-4，100 × 100 mm，R3 圆角，厚 1.6 mm |
| 层数与层序 | **四层**：顶层信号/电源、内层地、内层地、底层信号/电源；不改两层 |
| 铜厚 | 外层 1 oz，内层不低于常规 0.5 oz |
| 阻焊/丝印 | 推荐绿色阻焊、白色双面丝印 |
| 表面处理 | 推荐无铅沉金，无盘中孔或树脂塞孔要求 |
| 线宽、间距 | 常规 8 mil / 8 mil；U10 库内贴片焊盘之间为 7 mil |

如加工方要求 Gerber（制造图纸），从本次已检查的 PCB2 现导出，不使用旧文件。此前导出核对过 251 个圆孔（含 155 个过孔）和四条 USB-C 镀铜槽；过孔单独钻孔视图与完整钻孔表不要合并造成重复孔。

## 供电与装配

专用 **5V/3A 电源 → J10 → 输入保护/U10 → J7.21 → 开发板 5V**，共地。旧 J11 USB-A 已删除。厂家要求按标注短接开发板 **IN/OUT 两焊盘**，不是 5V/GND 排针；实物尚未焊接。

烧录：**断载板电源 → 取下开发板 → 接电脑 USB → 拔 USB → 装回 → 上电**。不同时接开发板 USB 和排母供电，不带电拔插；外围 3.3V 与开发板 3.3V 不并联。详见[供电操作](hardware/docs/header-power-review.md)。

板上 78 个器件、32 种料号，纯贴片清单 67 个；开发板及外接模块不算在内。J1～J10、J12 后装；**J10 为混合 USB-C，六个贴片脚和四个通孔外壳槽脚都要焊**，不能只焊外壳。委托贴片时核对 U7/U10/U9 角度、C25/D1/D2 极性；定位使用加工方工艺边，首件需确认。
