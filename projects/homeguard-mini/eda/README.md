# 嘉立创 EDA：从原生工程直接打样

唯一工程入口：[HomeGuard Mini 载板 R1 20261111.eprj3](<HomeGuard Mini 载板 R1 20261111/HomeGuard Mini 载板 R1 20261111.eprj3>)。

文件夹保留历史名称，里面的正式板是 **Board2 / Schematic2 / PCB2**，当前 PCB 丝印及供电方案为 **R2 精简排母供电**。**Board1是学习参考：P1四件真实电路、P2～P5中文图解、PCB1为35×25mm四层小板**，不能替代正式载板。整个工程文件夹必须一起保留，不能只复制 `.eprj3` 一个文件。

新手先打开 **Board1 → Schematic1 → P2**，按工程内路线学习；完整步骤见[四层载板改图教程](tutorial/README.md)，含器件、电源/信号规则、层管理、布局布线、铺地和分压扩展。自己重画时另建配对练习板，保留参考。

## 怎么打样

先看[载板待补元件清单](../docs/02-材料清单.md#载板待补齐完整28种料号)：每板28种料号、60个器件目前待补齐。**只下单PCB打样通常是空板**；元件采购、贴片、插件及J10混合焊接须另外确认。已有的开发板和传感器不包含这些板上元件。

1. 在嘉立创 EDA 打开上面的 `.eprj3`，进入 **Board2 的 PCB2**。
2. 保存工程，重新铺铜，运行原生设计规则检查（DRC，检查短路、间距和未布通等问题）。精简居中版本的当前检查状态见[验收清单](../docs/10-遗留问题与验收清单.md)，不能引用旧版零错误结论。
3. 在 EDA 中查看顶面、底面和 3D，核对 USB-C J10 沿板边、开发板母座方向、丝印、安装孔及配对插头空间。
4. 从当前 PCB2 直接发起 PCB 打样，核对下表参数。若委托贴片，同时由当前工程生成物料表与贴片坐标，确认 J10 的混合焊接工艺。
5. 厂家尺寸、实物套合与上电步骤按[首板验收](hardware/docs/first-board-validation.md)执行。这是首板试制，尚无实物测试结果。

若重新打开后出现“PCB 与原理图网表不一致”，先查看差异并核对身份与逐脚网络，再通过官方导入变更同步；不能关闭规则消警。

PCB2底面已补新手接线步骤、缩写解释和逐脚接法，共78条中文说明，含居中的“作者：李东升”；TX/RX等模块上的标准信号名保留。先看[底面接线表怎么看](../docs/03-接线教程.md#底面接线表怎么看)，数字是插座脚号，接线按顶面1脚标记数，不能照底面左右方向插。底面狗头像已按用户要求移除，保存重载及最新制造图均确认无残留；板名、供电说明和接口接线表保留。原[头像源稿](hardware/design/pcb/dogs-silkscreen.svg)仅作历史素材，不在当前制造丝印中。

常规铜间距8mil；J10库内0.20mm细间距焊盘使用7.8mil的SMD-SMD规则，其余铜间距保持8mil。2026-11-20先提交手动改图基线，再收紧U8降压区、整理局部走线与位号；保存重开后的两轮原生DRC均0项，六页原生ERC均0项，60件、252焊盘逐脚一致。自举路径约15.16→3.20mm，主输入电容路径18.16→2.15mm；焊盘内过孔、尖角、非规则斜线和悬空线尾提示均0。辅助DFM仍69项，原生画布因窗口隐藏未取得，已查看当前制造图；具体边界和实物待验见验收清单，不把DRC通过视为整机验收通过。

精简基线删除29件旧保护与信号开关外围，新增J13功放接口及R22启动下拉；本次又按实物更换四组接口，麦克风一个六针座改成六个单孔座，再增加两个I2C扩展口、两条22针学习排针、功放改为七孔后，当前60件。保留所有原传感器、屏幕和摄像头，排母整体居中；具体取舍见[电气说明](hardware/docs/electrical-review.md)。

正式Schematic2六页均已补中文功能标题、接线方向、外围用途与供电限制；“06 通用学习扩展”说明两侧排针，完整针序见[接线教程](../docs/03-接线教程.md#通用学习排针j21--j22)。

## 供电与装配

专用 **5V/3A 电源 → J10 → F1保险丝后的+5V → J7.21 → 开发板 5V**，共地。旧 J11 USB-A 已删除。厂家要求按标注短接开发板 **IN/OUT 两焊盘**，不是 5V/GND 排针；实物尚未焊接。

烧录：**断载板电源 → 取下开发板 → 接电脑 USB → 拔 USB → 装回 → 上电**。不同时接开发板 USB 和排母供电，不带电拔插；外围 3.3V 与开发板 3.3V 不并联。详见[供电操作](hardware/docs/header-power-review.md)。

板上 60 个器件、28 种料号，纯贴片清单 39 个；开发板及外接模块不算在内。20个通孔插座/排针（J1～J9、J12～J22）后装；J10单独核对混合焊接；J3为五针XH-5A；开发板、麦克风六孔板上直插，J1/J4/J6/J13接短杜邦线，见[接口表](hardware/README.md)。**J10 为混合 USB-C，六个贴片脚和四个通孔外壳槽脚都要焊**，不能只焊外壳。委托贴片时核对 U8 角度、C25/D1/D2 极性；定位使用加工方工艺边，首件需确认。
