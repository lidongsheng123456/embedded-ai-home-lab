# 外壳3D文件与下单说明

这里是按用户要求放在 `eda/` 内的外壳打印文件，2026-11-21整理，来源是2026-11-20生成的桌面外壳结构初版。它们独立于嘉立创EDA的PCB工程，不会自动显示在工程树中；下单时直接上传这里的STL，无需从PCB的3D视图再次导出。

**当前适合试装打样，整机装配尚未实物验证。** 主壳140×140×54mm，面框装上后最大厚度56.4mm，不含镜头和桌脚；PCB按100×100mm设计。屏幕玻璃偏移及厚度、镜头位置、MQ-2尺寸、喇叭深度和各插头高度仍需实测，建议先打下面两块小试装片，再决定整壳下单。

## 怎么上传嘉立创3D打印

1. 在文件管理器打开本目录的 `STL/`；不要上传 `.eprj3`、PCB的3D模型、预览图或HTML。
2. 进入嘉立创3D打印下单页面，上传所需零件的 `.stl` 文件。STL本身不记录单位，页面尺寸按 **毫米（mm）** 核对，保持100%比例，不缩放适配。
3. 按下表分别设置件数，尤其是屏幕压条要 **2件**。预览里的电子模块只是占位，不需要打印。
4. 若选FDM（挤出塑料丝逐层打印），可按现有设计建议选择浅色PETG、0.2mm层高、4圈外壁；以平台实际支持的材料和工艺为准。若选择树脂或其他工艺，需重新确认韧性、耐热、薄壁及螺丝孔能力，不能直接沿用PETG的装配预期。
5. 核对报价页的尺寸、支撑、薄壁及孔槽提示后自行下单。本目录没有自动提交订单。

打印STL已经平放到Z=0：主壳前面朝下、后盖外面朝下，桌脚也已转向；平台可能重新安排方向，仍需核对加工预览。主壳文件的外接尺寸应为140×140×54mm。
