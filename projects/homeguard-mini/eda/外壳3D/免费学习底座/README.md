# 免费券用：一体式学习保护底座

按用户2026-11-21的最终要求“以免费为主”设计。这里仅打印一个底座，原100×100mm PCB不改、不缩放；它通过四个安装孔固定载板，垫高焊脚，顶部完全开放，方便学习排针、主控母座和模块连接线插拔。

**这是保护板底的底座，不是包住四周的外壳。** 底板98×98mm，四个支柱稍向外伸出，打印模型实际最大尺寸 **99×99×8.2mm**；PCB四边各伸出底板约1mm，不提供侧边防撞、顶部防短路、防水或防尘保护。

## 怎么固定PCB

1. 断电，确认PCB四个安装孔孔距为90×90mm。四角柱只顶安装孔周围区域；板底其他地方保留5mm高度，焊脚按不超过3mm估算。
2. 将四颗普通M3六角螺母从底部放入六角凹槽。凹槽对边5.9mm、深约2.7mm，按普通M3螺母对边5.5mm、厚约2.4mm留余量；不要用加厚螺母或强行锤入。
3. 对准PCB四孔，从PCB上面穿入M3机牙螺丝，配薄平垫后拧入螺母。用户选型为M3×10mm大平头机牙螺丝（头径6mm）及M3×6×0.8mm平垫片，各4个；螺母为普通M3、对边5.5mm、厚2.4mm，共4个。安装顺序为螺丝头→垫片→PCB→底座→螺母。按标称尺寸计算，加0.8mm垫片后螺丝末端缩进底面约0.6mm；不加垫片则伸出约0.2mm。先核对实际咬合长度与底部是否突出，再轻拧到不晃动，不能把PCB压弯。
4. 不直接在树脂孔内自攻，不热熔装铜螺母，不用沉头螺丝楔压树脂。可在底部平面贴薄防滑垫，避开四个螺母口。
5. 检查底面焊脚和USB插头均不碰底座；更长的焊脚先按实际焊接情况修剪或修改支柱参数。插拔连接器时托住PCB，避免把插拔力全压在板中央。

主控和学习针从上方访问。底座没有挡住Type-C的侧壁，电源插头从板边插入；连接器外壳和线弯曲仍需实物确认。所有插拔均在断电后操作；取下开发板烧录的既有规则不变。MQ-2等发热外接模块保持独立固定，不放在底座与PCB之间。
