# 04 分别画电源、信号和地

[上一课](03-转PCB与四层布局.md) · [学习路线](README.md) · [下一课：分压扩展](05-增加分压测量.md)

这次先只连电源这一组。其余线、地孔和铺铜分别放在后续步骤里。

## 04-1：先只接电源这一组

1. 打开**自己的练习PCB**，选顶层为活动铜层，显示焊盘网络和飞线；可随时切到Board1/PCB1查看已完成参考。
2. 启动**交互布线/单线布线**工具，从J101.1焊盘起线。此时网络应自动继承为 `LEARN_3V3`；若显示GND，停下检查起点。
3. 线宽选0.50mm，向上离开焊盘，再沿元件上方走到R101.1。转角用45°，不要穿过C101的2脚地焊盘。
4. 从这条电源干线分支接到C101.1。完成后选线查看“层=顶层、网络=LEARN_3V3、宽度=0.50mm”。
5. 高亮电源网络：J101.1、C101.1、R101.1应相连，D101阳极不直接在这组内。

第一段可以这样做：点击图层列表里的“顶层”使它成为当前绘制层；选择布线工具，把鼠标移到J101的1脚焊盘，确认提示网络是LEARN_3V3，再单击起线。把线宽设为0.50mm，移动鼠标到转弯处单击，再移到R101的1脚焊盘单击结束，按Esc退出。最后点中刚画的铜线看网络和线宽；这与第02课画原理图导线是不同的工具和文档。

**先停一下：** 只核对这三个电源脚已连接，再去04-2。此时地和LED节点还未连通是正常的，不用为剩余飞线着急。

参考图里电源走在上方约y=19mm，电容1脚由上方短支线接入。**不能从电容左边直穿本体画到右侧电阻**，那会碰到电容接地的2脚。数值位置按实际封装吸附微调。

原理图“电源线”与“信号线”的差别在电气用途；PCB上都是指定网络的铜。电源要按电流、压降、温升和最窄位置设计。当前不到2mA的小板不构成正式载板1A支路的线宽依据。

## 04-2：接电阻到LED，中途换一次层

本电路的 `LEARN_LED_A` 是直流LED节点，不是高速通信信号；用它练习换层，不额外引入芯片协议。

1. 从R101.2在顶层以0.25mm线宽起线，向右到元件间空白处。
2. 在布线过程中使用工具的**添加过孔/换层**功能，选通孔过孔0.60/0.30mm，再选底层为目标。必须放下真正的过孔，不能只改变图层显示。
3. 在底层走约3mm，再放同尺寸过孔回到顶层，接D101.1。
4. 查看两只过孔的网络均为 `LEARN_LED_A`，起止层覆盖顶/底；两个孔之间确实是底层铜线。参考位置约(19,16)与(22,16)，以实际间距规则为准。

过孔的孔壁有镀铜，把不同层的同一网络接起来。这个信号孔穿过两内地层时，GND铺铜会按间距规则绕开它，**不应把信号接地**；属于同一个GND网的地孔才连接地面。

这两只孔是为了学习；如此简单的LED节点实际可以直接在顶层连接。正式高速网络通常应减少不必要的换层，不照抄这个绕法。

**完成标志：** R101.2到D101.1之间连通，两只信号过孔都是LEARN_LED_A，中间那一段在底层。选中线查看层属性核对，不靠线的颜色猜。

## 04-3：放四只地过孔

- J101.2本身是GND通孔焊盘，后面可连接两内层地面。
- 在C101.2附近放一个**网络为GND**的地过孔，用0.50mm顶层短线接C101.2；示意位置约(10.5,16)。
- 在D101.2附近同样放一个GND孔并短接，示意位置约(27.5,16)。
- 在前面两个信号换层孔旁各放一个GND孔，间距约1～2mm，先检查焊盘/孔/铜间距。它们与信号孔不直接用导线相连。

若独立放的孔没有网络，在属性中明确设GND，并检查修改结果；也可从已有GND焊盘起线并添加过孔。不要把“孔画成绿色”当作接地。

信号电流经负载回到地，快速变化的回流倾向沿邻近参考面流动。顶层信号参考L2，底层信号参考L3；在信号换层附近用GND孔接通两地面，可减少回流绕远。LED直流对这个不敏感，但摄像头/屏幕时钟会敏感，这就是本练习保留两内地层的理由。

**先数一遍：** 现在应有六只过孔：04-2的两只属于LED节点，04-3新放的四只属于GND。J101的两只排针焊盘不算在“六只过孔”里。还没铺地时，独立地孔之间可能仍有未连通提示，下一步再处理。

## 04-4：给内层1、内层2各铺一片地铜

“铺铜”就是把允许区域填成一片导电铜，不是给画布涂色。初学选**正片实心铺铜/铜皮区域**，不要同时混用负片电源层操作。

1. 选择内层1为活动层，使用**铺铜**工具画闭合区域，覆盖板内可用范围。
2. 在该区域属性里明确选：网络=`GND`，层=`内层1`，填充=`实心`，不同网间距≥0.20mm，铜到板边≥0.50mm。区域边界可以内缩0.50mm，重铺后还要检查实际铜边。
3. 关闭“保留孤立铜岛”或选择移除孤岛。对地焊盘使用热焊盘/辐条连接便于手焊，可先用四辐条、约0.25mm连接宽度，再按制造规则核对。不要用热连接削弱正式板的大电流支路。
4. 在内层2重复建立另一个同网络、同要求的区域。不要只复制了图形却忘了改层。
5. 执行**重建/重新铺铜**。画出区域外框不等于已经生成填充铜；看实际填充结果。
6. 只显示内层1，查看J101.2及各地孔周围确有连接铜；电源焊盘、LED节点信号孔周围留有绝缘间距。再只显示内层2重复检查。

**完成标志：** 有两块铺铜区域，一块属于内层1，一块属于内层2，两块网络都是GND。两块都重铺后，再去做04-5；不要把“隐藏某层”当成“切到这一层画图”。

本练习不强求顶底再铺满GND，先做到两内层连续且接通。初学留下来的大片空白不是错误；为了填满画面而生成浮铜，反而增加检查工作。

**不要手画一条GND“普通线”穿过电源焊盘来接地。** 铺铜工具依网络和规则避让；手工铜线也必须满足间距。若地面被密集过孔或开槽切成两片，要调整布局恢复连续路径，不靠“看起来连着”判断。

## 04-5：加文字，再检查和保存

给顶层丝印加 `LEARN 3V3 ONLY`、J101的 `3V3 / GND`、LED的 `A / K`。文字不压焊盘开窗和板边；3D只能辅助看外观，不证明电气连接正确。

| 顺序 | 检查什么 | 怎样才过关 |
| --- | --- | --- |
| 第一轮：网表 | PCB与原理图同步，四件的八个脚与第2课一致 | 无意外新增、删除、换网、悬空 |
| 第一轮：铜与规则 | 重铺后运行原生DRC，查看未布通、短路、线宽、铜间距、板边、孔等分类 | 无未解决错误；不能关掉类别或降低规则来清零 |
| 第一轮：逐层 | 分别查看四铜层，选中线路和过孔检查网络 | 电源只到该去的脚；信号孔不碰地；两个地面均连通 |
| 第一轮：装配 | 2D/3D看极性、插接方向、丝印、焊接空间 | 丝印能读、LED方向正确，封装与实物匹配 |
| 第二轮 | 保存所有修改文档，关闭并重新打开自己的P1及配对PCB，重新铺铜，再做上述检查 | 重开后结果保持；任何修改后重做两轮 |

刚布线前有飞线正常，完成后有飞线必须查。飞线显示可能被隐藏或未刷新，**看不到飞线不等于已连通**；以网络连接和检查结果为准。DRC也不能发现“原理图把LED极性设计反了”这样的全部功能错误。

需要看制造效果时，从自己的练习PCB导出一次Gerber（供板厂生产的分层图形文件）到本机忽略的 `eda/hardware/.work/`，在制造预览检查：四个铜层、板框、钻孔、阻焊开窗、丝印。文件名因版本而异，按导出清单映射，不凭扩展名猜层。确认没有把文档层当铜层，也没有遗漏内层。

参考PCB1已实际布线并运行原生DRC；当前复核结果见[学习工程验收记录](../../docs/10-遗留问题与验收清单.md#四层学习工程验收2026-11-18)。它尚无实体，检查结果也不能替自己改动后的练习签字。正式载板唯一打样源仍是PCB2；若单独打练习板，明确选择相应学习PCB，不能拿它替换载板订单。排针孔须在封装和制造钻孔中核实后再下单。

## 先打开哪里，先做什么

打开第03课配好的 **Learn_LED_PCB**（若软件自动命名，用你记录的实际名字）。它应有35×25mm板框、四件元件、四铜层和已设置的规则，但还没有完成连线。

现在按顺序只做一块：**04-1电源 → 04-2 LED节点 → 04-3地孔 → 04-4铺地 → 04-5检查**。不要看着飞线到处随便连，也不用先给所有层铺满铜。用到PCB示意时再打开工程内P4或[布局布线示意图](assets/mvp-routing.svg)。

这里“网络”就是应该接通的那一组脚；“焊盘”是元件脚落在板上的焊接铜块；“过孔”是把上下不同铜层接起来的镀铜小孔。没有实物也能先完成软件操作。

## 实物操作与预期现象（可选）

先完成焊接与断电检查，再上电。黑表笔接COM、红表笔接VΩ，选直流电压档；测电压时并接两点，不能用电流档跨电源。

1. 断电看焊接与极性，电阻档检查输入正负之间没有持续接近0Ω的短路；电容充电与LED导通会影响读数，不能要求任何方向都显示无限大。不带电用电阻/蜂鸣档。
2. 断电检查J101.2、C101.2、D101.2之间的连接；先短接表笔了解表笔本身电阻。不要用LED两端蜂鸣与否判断所有连接。
3. 确认稳压3.3V，限流20mA起步。黑笔固定J101.2，红笔分别测J101.1约3.3V、D101.1为LED正向压降量级。LED应低亮度常亮。
4. 若限流触发、反常发热或LED不亮，断电排查，不反复升压。核对输入、LED方向、电阻值和地连接。

</details>

## 常见错误

| 现象 | 先检查 |
| --- | --- |
| 看见一块铜，地还是未连 | 区域网络是否为GND、是否实际重铺、有无孤岛、地孔网络是否正确 |
| 换层位置仍有飞线 | 是否真正放过孔；线端是否吸附到焊盘；孔和两端线网名是否一致 |
| 铺铜后短路 | 是否错误给铜皮命了电源网；是否手工线穿异网焊盘；按DRC定位 |
| 全部隐藏后“没有飞线” | 恢复飞线显示，重新计算连接并检查未布通，不靠隐藏判断 |
| DRC零但LED不亮 | 实物电源、元件方向、焊接、阻值和封装映射仍需核对 |

</details>

## 过关标准与最终项目的关系

- [ ] 能从J101正端沿铜线说出完整电流回路，区分地孔与信号孔。
- [ ] 两内地层连续、同网接通；保存重开后网络和规则检查仍满足要求。
- [ ] 能说明DRC覆盖和不覆盖的事情，未实测时不写“实测稳定”。
