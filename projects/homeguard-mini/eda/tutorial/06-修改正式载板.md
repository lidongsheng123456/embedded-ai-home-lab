# 06 从小练习走到正式载板

[上一课](05-增加分压测量.md) · [学习路线](README.md)

本课先在自己的练习板换一个电阻，再练移动，最后才只读追踪正式Board2。不要同时做三件事。

## 操作一：先在学习板改一个电阻

目标：把R101由2.2kΩ改成1kΩ，理解“改参数文字”和“更换真实物料”不同。

1. 在自己的练习原理图里定位R101，记录两端网络和现有封装。
2. 用**替换器件/更换型号**选择1kΩ、0805、同样精度与合适功率的实际物料，例如C17513；核对新器件的1/2脚和R0805焊盘映射。只把文字写成1k，不保证BOM会购买1k。
3. 保存，检查网络仍是LEARN_3V3与LEARN_LED_A，没有悬空。
4. PCB导入变更时确认只影响目标电阻；同封装不一定移动铜，但仍核对身份、焊盘与网表。
5. 重新检查、保存重开。预计3.3V下LED电流约0.9～1.5mA，实际亮度仍取决于LED。

正式R15也是类似的小范围变更，但先用学习板熟悉；不要拿U8的反馈/自举外围或GPIO45的启动下拉随意试值。

## 板上元器件分别做什么

已有的传感器模块内部通常已经焊了芯片、稳压/滤波等元件。你在面包板上看到“一块模块＋几根线”，并不是电路里只有几根线。载板又承担统一供电、接口、分压及必要去耦，所以多出了下面这些器件。

这不表示全部器件都对所有版本必需；有些来自本版功能与可靠性取舍，精简时可以重新设计。但“暂时运行正常”只能证明当时条件可用，不能验证错接、插拔顺序或峰值电流等情况。

| 类别与正式位号 | 日常作用 | 能否凭数量直接删 |
| --- | --- | --- |
| 接头J1～J10、J12/J13 | 把模块固定接到确定针序；J7/J8插开发板，J10为电源入口 | 改接头要查孔距、针序、线束、额定与外壳；旧J11已取消 |
| R15＋D2 | 电源指示灯及限流 | 可以重新设计成可选指示功能；删灯与改主电源不同 |
| R1/R2＋C1 | MQ-2分压和滤波 | 不能省掉分压，把可能到5V的信号直接接ESP32 |
| R3＋SW1＋C7 | 按键默认高电平、按下接地、抑制抖动 | 改动要同时核对GPIO39、硬件和软件消抖 |
| R8/R9 | I2C上拉，让共用SDA/SCL在无人拉低时回高 | 模块自带上拉可能并联；需核对总阻值与电压，不能盲目叠加或全删 |
| R4；R22 | 蜂鸣器默认关闭；GPIO45启动下拉 | R22必须装，仅接功放高阻输入 |
| U8、L1、C18/C19、C21/C22、C23 | 5V降为外围3.3V；储能、滤波和开关驱动 | 成组按手册设计，不能用电阻代替，C23也不能随便改接地 |
| F1、D1、C15/C20/C24/C25 | 后备熔断、瞬态钳位、去耦储能 | 无主动限流、欠压放行、软启动或反向阻断 |
| R10/R11 | USB-C两路CC各5.1kΩ下拉 | 不支持PD协商，旧U9已删除 |
| C2～C6、C8、C28/C29 | 各模块接口附近的电源旁路和储能 | 先查归属与回路，不把远处一个大电容当作所有小电容的替代 |
| R18/R19、R20/R21 | TFT默认状态和时钟/数据串联阻尼 | 阻尼与源端位置有关，不能只看阻值小就短掉 |

完整采购型号与数量仍只维护在[材料清单](../../docs/02-材料清单.md#载板待补齐完整24种料号)，本表按用途解释，不建立第二份采购单。芯片细节、计算和手册来源见[电气设计依据](../hardware/docs/electrical-review.md)。

## 操作二：移动元件并保持回路

在自己的练习PCB把C101向下移约2mm。先记录原电源和接地路径，选整个元件移动，不拆焊盘。移动后查看哪些导线没有跟上，删除的只应是需要重画的那几段，重新接入电源与近旁地孔，然后重铺、检查、保存重开。

完成标准不是“元件动了”，而是其两脚仍分别连电源和地、走线没有碰异网、去耦回路没有被拉远。正式板移动去耦电容时更要靠近所属芯片电源脚；整齐不能优先于电气回路。

## 电源、地和信号如何在正式四层上安排

```text
专用5V/3A → J10 → F1 → +5V
                         ├→ J7.21 → 开发板5V
                         ├→ MQ-2 / LD2410 / J13功放
                         └→ U8降压 → +3V3 → 外围模块
开发板自身3.3V → MCU_3V3 → 按钮外围
各分支GND共地；+3V3与MCU_3V3不并联。
```

历史 `USB_MCU_5V` 已合并为 `+5V`，旧J11仍删除。开发板按厂家图短接IN/OUT两焊盘；不是短接5V/GND。烧录时**先断载板电、取下开发板，再接电脑USB；拔USB后才装回**，不同时接两路供电，见[具体供电操作](../hardware/docs/header-power-review.md)。

| 网络类别 | 正式板做法与改动检查 |
| --- | --- |
| 5V/3.3V电源支路 | 外层宽线或适当铜区；按实际电流、压降、铜厚、温升和最窄点计算，包含过孔和连接器。3A电源不代表载板可满3A，精简版无电子限流，功放播放须重新验负载 |
| GND | 两内层连续参考地，用GND通孔/过孔连接；不得为方便穿线随意分割 |
| MQ-2模拟信号 | 分压滤波后才到MCU侧；远离降压SW节点、时钟和蜂鸣器回路。GPIO3是启动配置脚，不随意改上电连接 |
| I2C SDA/SCL | 两根共享信号线；3.3V上拉，模块按地址应答，不是把任意GPIO输出直接并联。改接口电压/模块先查上拉、地址和总线电容 |
| 屏幕/摄像头/麦克风 | 连续参考地、短路径、合理源端阻尼和线束；降低跨层次数，换层附近给回流GND孔。不是所有信号都必须蛇形等长 |
| U8的SW、BST、反馈 | 按厂家典型布局处理开关电流回路；SW铜区不任意扩大，反馈远离噪声；不能照LED线宽和摆法重画 |

先根据电流方向、手册和机械约束分区，再在顶/底层完成信号与电源。层的选择不取代规则或电气设计；新手先保留本板两内地方案，不擅自改成“内层2全电源”。

## 操作三：对正式板做一次只读追踪

1. 在Schematic2找到D2和R15，高亮 `LED_ANODE`，只应把R15.2与D2.1接起来；D2.2在GND。
2. 打开PCB2，用查找/交叉定位找到R15/D2，分别查看焊盘网络、铜线层与宽度。
3. 在P1追踪 `MQ2_AO_RAW → R1 → MQ2_ADC` 与R2/C1的对地支路；继续追踪 `MQ2_ADC → J7.13`；本版U4已删除，分压滤波后直接接主控，GPIO3启动需首板验证。
4. 对照[摄像头转换表](../hardware/docs/camera-adapter.md)读J12；本板自定义20针，不能按相似外形接到任意摄像头。

若现场名字和教程不同，先看最近Git变更和当前电气说明，不改网名来迁就旧文档。

</details>

## 哪些可以先改，哪些需要继续学习

| 改动 | 所需能力 |
| --- | --- |
| 调整位号位置、说明文字 | 核对丝印开窗、阅读方向与制造输出；不改网络 |
| 同封装电阻换合适阻值 | 会算该支路、换真实料号、导入变更并查BOM |
| 小范围移动电阻或连接器 | 会重布相关线、重铺、查回流和机械空间；接口改向还需核对针序 |
| 新增低速传感器接口 | 继续查电压、地址、总线上拉、电流、驱动与固件引脚；不是多接同名线即可 |
| 删除保护/信号开关、换稳压器、改摄像头针序 | 重新建立供电与信号约束，读手册并计算，验证上掉电、温升、信号与启动；不属于入门随意修改 |

学完本教程能够开始做小范围修改，不表示已经具备任意电源或高速板的设计能力。若想减少正式板物料，先写出“保留哪些供电/保护/外设功能”，逐组分析并重新验证；不要通过少焊整组必需外围来简化现有PCB。

## 保存与版本管理

1. 修改前在仓库根目录执行 `git status --short`，确认哪些是已有改动；不要把别人的文件一起提交。
2. 在嘉立创保存所有改过的原理图和PCB，关闭重开，完成两轮检查。教程图源变更后还要重新嵌入对应讲解页；修改SVG文件不会自动更新原生工程。
3. 在Git里审查变更：原生工程目录必须整体保持可打开，不能只提交入口 `.eprj3` 而漏掉其sch/pcb等修改；同时更新受影响的电路参数、引脚表与教程。
4. 按职责提交，例如“硬件：增加四元件四层学习板”“文档：补充四层改板实操路线”。只选择相关源码与文档；自动备份、Gerber临时导出、日志和本机配置不提交。
5. 需要恢复先用 `git log` / `git diff` 找到具体改动，保留当前未提交内容，再恢复需要的文件或使用 `git revert` 生成反向提交。不要运行会清空全部用户改动的重置命令。

本目录已经属于现有仓库，不再 `git init`，不为每次练习复制“最终版2/备份版3”。软件内的独立练习板用于完成课程任务，Git负责版本历史，二者职责不同。

</details>

## 常见错误、现象与过关标准

“修改后还能打开”仅证明文件可读；“DRC零”也不证明供电、针序、固件和制造全对。正式板首板的电压、峰值电流、插合、温升和稳定性检查仍按[首板验收](../hardware/docs/first-board-validation.md)执行。

- [ ] 会追踪一个完整支路，能说明原理图到PCB的对应关系。
- [ ] 在自己的学习板完成一次真实换料和一次移动重布，变更范围符合预期。
- [ ] 能按功能解释元件，而不是以“面包板能亮”判断保护和滤波都可删除。
- [ ] 能识别需要新一轮设计/实物验证的改动，能保存并提交完整工程。

</details>
