# 05 在已有板上只增加一个功能

[上一课](04-布线铺铜与检查.md) · [学习路线](README.md) · [下一课：正式载板](06-修改正式载板.md)

先打开自己的 **Learn_LED_SCH**，核对基础的J101/R101/D101/C101四件仍在，并确认它的PCB已经完成第04课检查。先不加元件。

**过关：基础四件和旧连线都保留。** 做到再展开下面的接线计划，然后按顺序改原理图、更新PCB。这里不重新建一套板子。

<details>
<summary>需要时再看：目标</summary>

## 目标

只新增“修改原理图后同步PCB”这一知识点。增加一个把3.3V缩小到约1.65V的测量输出；电路仍不需MCU或固件。做完后就有修改已有载板的基本能力。

工程内P1/PCB1保留四件参考。继续使用你在第2～4课完成的独立练习板，先确认原理图与PCB配对正确；如果尚未完成前四课，先回去从空白重画并通过检查，再做扩展。不要在同一原理图里重复粘贴基础电路，造成位号重名。此课只改自己的练习板，保留参考随时对照。

</details>

<details>
<summary>核对完旧图，再看：这次准备增加什么</summary>

## 器件、接线与计算

增加 R102/R103 两只10kΩ、C102一只100nF、J102一只同款2针排针。用料同第1课，完成后总计八件，不是八种型号。

```text
LEARN_3V3 ── R102 10k ──┬── LEARN_HALF ── J102.1
                       ├── R103 10k ── GND
                       └── C102 100nF ─ GND
GND ─────────────────────────────────── J102.2
```

| 网络 | 新增的引脚；原有引脚不删除 |
| --- | --- |
| LEARN_3V3 | R102.1 |
| LEARN_HALF | R102.2、R103.1、C102.1、J102.1 |
| GND | R103.2、C102.2、J102.2 |

</details>

<details>
<summary>前一步完成后，再看：操作一：改原理图</summary>

## 操作一：改原理图

1. 在自己的练习原理图中放四个新元件，核对型号、封装与位号。
2. 按表接线；C102跨 `LEARN_HALF/GND`，不跨在R102两端。
3. 高亮并数网络成员：LEARN_3V3有4脚、LEARN_LED_A有2脚、LEARN_HALF有4脚、GND有6脚，共16脚、四网络。
4. 运行原理图检查，处理错误，保存。基础LED回路应该完全保留。

</details>

<details>
<summary>前一步完成后，再看：操作二：导入变更并调整PCB</summary>

## 操作二：导入变更并调整PCB

1. 打开与这份原理图配对的PCB，导入变更。
2. 预期只新增R102、R103、C102、J102和分压网络。若出现基础四件被删除/重加，或变更对象来自Board2，取消并查清板子配对或实例身份。
3. 新元件放到预留的下方区域：R102→分压中点→R103依次紧凑排列；C102靠近中点和J102，接地端就近接地孔；J102在右下并预留表笔/插头空间。
4. LEARN_3V3支线仍用0.50mm；LEARN_HALF可用0.25mm短线，远离LED电源干线，不跨地面裂缝。信号走外层，两内层仍保持GND用途。
5. R103.2/C102.2通过短线与地孔接到内层GND；J102.2若为通孔焊盘也应连接地面。检查信号孔与地孔分开。
6. 重铺两内层，查新增地连接、绝缘间距和孤岛；再按第4课做两轮检查、保存重开。

布局不合适就先调整布局，别靠穿过元件焊盘、挤细地面或关闭间距规则走通。元件一旦移动，原来接它的铜线端点都需要重新检查。

</details>

## 现象与实物操作（可选）

断电检查和供电方法与第4课相同。供电后LED仍亮；黑表笔接J102.2，红表笔接J102.1，读数约为输入电压的一半。即使只有万用表，你也能验证新增功能，不依赖尚未学过的固件。

输入不是恰好3.300V时，先测实际输入，再用“输出/输入≈0.5”比较，不死盯1.650V。分压器只适合小电流测量，不能当稳压电源给ESP32、摄像头或模块供电。

</details>

<details>
<summary>需要时再看：常见错误</summary>

## 常见错误

| 现象 | 原因与处理 |
| --- | --- |
| 输出接近0V | 中点误接地、上电阻悬空或没有输入；按脚号查 |
| 输出接近3.3V | 下电阻悬空、两个10k未串成分压；高亮网络排查 |
| 接上负载后不再是一半 | 输出被负载拉动；用高阻电压档验证，不能给模块供电 |
| 原理图多了件，PCB没有 | 保存后重新查看变更列表、核对所属板子与封装，不在PCB随便补无关器件 |
| 加件后原来地线断了 | 布局移动/铺铜避让改变了回流；重新铺铜和检查全板，不能只看新增部分 |

</details>

<summary>需要时再看：过关标准与最终项目的关系</summary>

## 过关标准与最终项目的关系

- [ ] 八件16脚四网，原LED回路保留。
- [ ] 新增四件通过正式导入变更进入对应PCB，元件属性和网络一致。
- [ ] 两轮检查后没有未解决错误；实物测量若未做，明确标为待做。

正式MQ-2接口的R1/R2正是两只10kΩ，C1是100nF。正式输入可能到5V，两电阻把它缩小至约2.5V后送入后级；本练习只用3.3V验证分压原理，不接MQ-2，也不表示简单分压能保护任意高压。正式GPIO3、信号开关和采样设置另有约束，见下一课。

</details>

<details>
<summary>选读：为什么约1.65V，以及误差和滤波计算</summary>

分压电压：`3.3×R103/(R102+R103)=1.65V`。两电阻各±1%、输入恰为3.300V时，理想输出约1.6335～1.6665V；真实测量还受电源、万用表和负载影响。先用高输入阻抗的万用表电压档测，不接LED、蜂鸣器或其他负载来取电。

R102/R103并联等效电阻是5kΩ，和100nF组成约0.5ms时间常数的低通滤波，转折频率约318Hz。含义是快速波动被削弱，**不是输出会永久延迟0.5ms，也不是能精确测量318Hz以内所有信号**。这里不讲采样程序。

</details>
