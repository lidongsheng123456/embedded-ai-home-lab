# 02 硬件和网络要求

## 最低真实配置

运行真实 CSI 实验需要下面这些现有硬件：

| 硬件 | 数量 | 规格或要求 |
|---|---:|---|
| ESP32-S3-DevKitC-1 开发板 | 1 | 全尺寸、N16R8、Type-C、已焊排针 |
| Windows 电脑 | 1 | 运行采集服务和浏览器界面 |
| 家庭路由器 | 1 | 支持2.4GHz，并允许局域网设备互相访问 |
| USB-C 数据线 | 1 | 必须支持数据传输 |
| USB 供电 | 1 | 能稳定给开发板供电 |

不要混用这些不符合当前固件目标的板型：

- 普通 ESP32；
- ESP32-C3；
- N8R2 版本；
- 未焊排针版本；
- 带 IPEX 外置天线座版本（新手没有必要）；
- 只有 4 MB 且散热很差的 S3 SuperMini；
- 所谓“USB 超声波接收器”；

官方固件会关闭 Wi‑Fi 省电并持续运行 DSP，小型廉价板可能明显发热。第一次运行时保持通风，每隔几分钟触摸检查；烫手就立即断电。

## 网络条件

- 路由器必须有 2.4 GHz SSID；
- ESP32 和电脑连接同一个局域网；
- 路由器不能开启 AP/客户端隔离；
- 电脑最好使用固定 DHCP 地址或路由器地址保留；
- Windows 防火墙允许 UDP 5005 入站；
- 公共、校园和公司 Wi‑Fi 通常不适合，因为客户端之间可能被隔离。

## 软件

- Git；
- Python 3.10+；
- Docker Desktop；
- Rust stable + MSVC Build Tools；
- Node.js 20+（用于 `npx` 数据检查，可选）；
- 官方 RuView 源码。

## 一块板能做到什么

把路由器和 ESP32 放在房间两侧，人体经过两者之间或附近时，CSI 会变化。单板适合验证：

- 无人/有人差异；
- 走动和静止的变化；
- 房间布局发生明显变化；
- 原始 CSI 包是否稳定到达。

它不适合承诺：

- 精确位置坐标；
- 多人可靠计数；
- 17 关键点人体姿态；
- 医疗级呼吸、心率或跌倒检测。
