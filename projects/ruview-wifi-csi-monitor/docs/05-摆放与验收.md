# 05 摆放、校准与验收

## 单节点摆放

```text
路由器  ───── 2～5米、主要活动区域 ─────  ESP32-S3
```

- 路由器与 ESP32 高度建议 0.8～1.5 m；
- 两者之间不要紧贴大型金属柜、冰箱或配电箱；
- 人体主要活动区域尽量经过它们之间或菲涅尔区；
- ESP32 天线一端不要贴墙或放进金属盒；
- 节点持续高负载运行，保持通风；
- 改变摆放后重新做基线观察。

## 四组基础实验

每组至少记录 2～5 分钟：

1. 房间无人且门窗、风扇保持不变；
2. 一个人在链路附近静坐；
3. 一个人在链路附近往返走动；
4. 无人但风扇、窗帘或空调摆风运行。

第四组用于识别环境运动造成的假阳性。

## 合理的首版验收标准

- ESP32 连续发送 30 分钟不重启；
- 服务端明确为 `esp32` 源；
- 断开 ESP32 后节点消失；
- 无人、有人走动两组 CSI/运动指标存在稳定差异；
- 重复三次进入/离开实验，趋势基本一致；
- 板子只是温热，不烫手；
- 不把 UI 骨架动画作为验收依据。

## 想提高效果时

优先顺序：

1. 优化路由器与节点位置；
2. 固定 Wi‑Fi 信道，减少自动换信道；
3. 排除风扇、窗帘和移动金属物体；
4. 延长无人/有人数据采集；
5. 增加第二、第三块 ESP32-S3，形成不同方向的链路；
6. 最后才考虑房间专用训练。
