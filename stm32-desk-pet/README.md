# STM32 OLED 表情桌宠

第一次遇到 Blue Pill、ST-Link、GPIO、I²C 等名称时，先看[工作区新手名词解释](../docs/00-新手名词解释.md)。

这是给第一次使用 PlatformIO 和 STM32 Blue Pill 的渐进式项目。最终效果是：OLED 显示会眨眼的表情，一个 SG90 舵机让桌宠摇头，开关切换心情，LED 显示状态，串口蓝牙发送字符控制表情和方向。

## 为什么先做这个

- 每一级都能独立运行，故障容易定位；
- 使用套装里型号相对明确的器件；
- 同时学习 GPIO、I2C、PWM、按键和 UART；
- 不需要一开始连接锂电池、扬声器或 5 个舵机。

## 五个学习阶段

| PlatformIO 环境 | 使用器件 | 成功现象 |
|---|---|---|
| `step1_blink` | 仅 STM32 板 | PC13 板载灯每 0.5 秒闪烁 |
| `step2_oled_face` | 加 OLED | 显示表情并每 3 秒眨眼 |
| `step3_servo_head` | 加 1 个 SG90 | 表情显示且舵机左右摇头 |
| `step4_button_led` | 加开关、LED、2kΩ | 按一次切换一种表情 |
| `step5_bluetooth` | 加串口蓝牙 | 手机发送字符控制摇头和表情 |

第一次必须从 `step1_blink` 开始。前一级没有通过，不要继续加器件。

## 接线表

### OLED（1.3 英寸 I2C）

| OLED | STM32 Blue Pill |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |

代码默认屏幕驱动为 SH1106、地址为 `0x3C`。如果屏幕背面明确写着 SSD1306，请把 `src/main.cpp` 中的 `U8G2_SH1106_128X64_NONAME_F_HW_I2C` 改成 `U8G2_SSD1306_128X64_NONAME_F_HW_I2C`。

### 单个 SG90 舵机

| SG90 | 连接 |
|---|---|
| 信号线（橙/黄） | PA0 |
| VCC（红） | 独立稳定 5V |
| GND（棕/黑） | 5V 电源 GND，并与 STM32 GND 共地 |

禁止从 STM32 的 3.3V 引脚给舵机供电。首次只接一个舵机。舵机抖动或 STM32 重启，通常是 5V 电源电流不足或没有共地。

### 开关和外接 LED

```text
PB13 ── 开关 ── GND

PB12 ── 2kΩ ── LED 正极
LED 负极 ── GND
```

LED 长脚通常是正极，但应以器件标记或万用表测试为准。

### 串口蓝牙模块

| 蓝牙模块 | STM32 |
|---|---|
| TX | PA3（STM32 RX） |
| RX | PA2（STM32 TX） |
| GND | GND |
| VCC | 按模块丝印/说明书确认，不能仅凭照片猜测 |

默认串口速率是 `9600`。手机串口工具可发送：

- `L`：向左；
- `R`：向右；
- `C`：回中；
- `H`：开心；
- `S`：难过；
- `N`：普通；
- `Z`：困倦。

## PlatformIO 第一次使用

打开 [PlatformIO 从零开始教程](docs/01-PlatformIO从零开始.md)，严格按步骤完成第一次编译和烧录。

## 暂时不要连接的器件

- 大圆扬声器不能直接连接 GPIO，需要语音/功放模块驱动；
- 语音模块必须先确认正反面型号和针脚；
- 锂电池与 5V 充放电模块必须先确认 `B+ / B- / OUT+ / OUT-` 等标识；
- 5 个舵机同时动作需要较大的 5V 电流，不能由开发板或 ST-Link 供电。

拍摄语音模块、蓝牙模块、充放电模块的正反面近照并能看清丝印后，才能安全加入后续版本。
