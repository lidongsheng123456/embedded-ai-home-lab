# 07 能否只靠路由器直接采集 CSI

理论上可以，但只适用于部分芯片和可刷机设备，不是“任意家庭路由器”。

常见研究路线包括：

- Broadcom 芯片 + Nexmon CSI；
- Qualcomm Atheros CSI Tool；
- 部分 MediaTek Filogic + OpenWrt/厂商 CSI 接口；
- Intel 5300 等老研究网卡；
- Linux 802.11bf/厂商专用驱动。

开始前必须知道路由器的准确品牌、型号、硬件版本、SoC、Flash/RAM 和 OpenWrt 支持情况。同一个商品名的不同硬件版本可能使用完全不同的芯片。

风险包括：

- 刷错固件导致路由器无法启动；
- 丢失宽带拨号、VLAN、IPTV 和 Mesh 配置；
- CSI 只在特定客户端发送流量时产生；
- 输出格式需要自己写桥接程序；
- 断网会影响整个家庭；
- RuView 对该物理来源可能只有“未校准启发式”支持。

因此新手不要在主路由器上实验。ESP32-S3 的价值是：

- 不改变家庭网络；
- 失败时拔掉开发板即可恢复；
- 成本低；
- 上游提供专门固件；
- 容易移动和调整 RF 链路。

如果以后确实想走路由器直采路线，应另买一台兼容 OpenWrt 的备用路由器，不能拿正在承担全屋上网的主路由器直接刷机。
