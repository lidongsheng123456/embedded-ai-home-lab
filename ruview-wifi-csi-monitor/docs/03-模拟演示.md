# 03 无硬件模拟演示

模拟演示只用于确认网页和 Docker 能运行，不代表监控到了房间。

## 配置代理（访问失败时）

CMD：

```bat
set http_proxy=http://127.0.0.1:7892
set https_proxy=http://127.0.0.1:7892
```

PowerShell：

```powershell
$env:HTTP_PROXY='http://127.0.0.1:7892'
$env:HTTPS_PROXY='http://127.0.0.1:7892'
```

## 启动模拟界面

PowerShell：

```powershell
$token = -join ((1..64) | ForEach-Object { '{0:x}' -f (Get-Random -Maximum 16) })
docker pull ruvnet/wifi-densepose:latest
docker run --rm --name ruview-demo `
  -p 127.0.0.1:3000:3000 `
  -e RUVIEW_API_TOKEN=$token `
  -e CSI_SOURCE=simulated `
  ruvnet/wifi-densepose:latest
```

打开 <http://127.0.0.1:3000>。

## 正确理解结果

此时：

- 页面有动作不等于检测到你；
- 遮挡路由器或在房间走动不会控制模拟人物；
- 数据源必须显示 simulated/synthetic；
- 这一步的成功标准只是 Docker 和 UI 正常。

按 `Ctrl+C` 停止容器。
