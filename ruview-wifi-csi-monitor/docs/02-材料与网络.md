# 02 材料和网络要求

可直接购买的表格版本见 [RuView专用采购清单](../bom.csv)。

## 最低真实配置

你已经有电脑、家庭路由器、可传数据的 USB-C 线和 USB 供电，因此本阶段只购买下面一件：

| 需要购买 | 数量 | 准确规格 |
|---|---:|---|
| ESP32-S3-DevKitC-1 开发板 | 1 | 全尺寸、N16R8、Type-C、已焊排针 |

下单入口和规格选择见[京东购买指南](09-京东购买指南.md)。价格以京东下单页面实时显示为准。

下面这些是运行时仍会用到的现有条件，但**不用再买**：Windows 电脑、支持 2.4 GHz 的家庭路由器、USB-C 数据线、USB 供电。USB 延长线和额外 USB 电源也不买。

不要购买：

- 普通 ESP32；
- ESP32-C3；
- N8R2 版本；
- 未焊排针版本；
- 带 IPEX 外置天线座版本（新手没有必要）；
- 只有 4 MB 且散热很差的 S3 SuperMini；
- 所谓“USB 超声波接收器”；
- 为了本实验更换主路由器。

官方固件会关闭 Wi‑Fi 省电并持续运行 DSP，小型廉价板可能明显发热。第一次运行时保持通风，每隔几分钟触摸检查；烫手就立即断电。

## 网络条件

- 路由器必须有 2.4 GHz SSID；
- ESP32 和电脑连接同一个局域网；
- 路由器不能开启 AP/客户端隔离；
- 电脑最好使用固定 DHCP 地址或路由器地址保留；
- Windows 防火墙允许 UDP 5005 入站；
- 公共、校园和公司 Wi‑Fi 通常不适合，因为客户端之间可能被隔离。

## 软件

- Git；
- Python 3.10+；
- Docker Desktop；
- Rust stable + MSVC Build Tools；
- Node.js 20+（用于 `npx` 数据检查，可选）；
- 官方 RuView 源码。

## 一块板能做到什么

把路由器和 ESP32 放在房间两侧，人体经过两者之间或附近时，CSI 会变化。单板适合验证：

- 无人/有人差异；
- 走动和静止的变化；
- 房间布局发生明显变化；
- 原始 CSI 包是否稳定到达。

它不适合承诺：

- 精确位置坐标；
- 多人可靠计数；
- 17 关键点人体姿态；
- 医疗级呼吸、心率或跌倒检测。
