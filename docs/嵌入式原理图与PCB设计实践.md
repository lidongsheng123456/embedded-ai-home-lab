# 从接线到PCB：为什么要这样设计

**先证明零件能配合工作，再把接线做成牢固、可维护的板子。** PCB不只是把杜邦线换成铜线，还要管供电、尺寸、发热、干扰和焊接。

这是通用方法。HomeGuard具体用料看[材料表](../projects/homeguard-mini/docs/02-材料清单.md)，具体针序看[接线](../projects/homeguard-mini/docs/03-接线教程.md)。当前固件**仅编译验证**，载板还未实物上电验收。

## 1. 原理图根据什么画

原理图回答“谁和谁连接”。四份证据必须一致：

| 依据 | 核对什么 |
| --- | --- |
| 实物照片、丝印、厂家答复 | 真正买到的模块版本和供电方式，不猜相似模块 |
| 原厂数据手册、尺寸图 | 每脚功能、电压/电流、焊脚间距、推荐电路 |
| [pins.h](../projects/homeguard-mini/firmware/include/pins.h)与[编译配置](../projects/homeguard-mini/firmware/platformio.ini) | 程序实际使用的引脚、屏幕和分压系数 |
| [当前原生工程](../projects/homeguard-mini/eda/README.md) | 原理图网络与PCB实际铜线是否一致 |

AI建议不能替代手册，编译成功不能证明线没接反。没有可靠规格的部分要列为待确认，不补猜测。

## 2. 先查供电，再接信号

把电源想成送水：电压像水压，电流像流量。标着3A表示电源的供给能力，不是强行灌入3A。

HomeGuard当前供电：

```text
专用5V/3A电源 → 板边USB-C → 保险丝/限流保护
                            ├→ MQ-2、雷达5V
                            ├→ 反向阻断/缓慢上电 → J7.21 → 开发板5V
                            └→ 降压 → 外围独立3.3V
各部分GND相连；外围3.3V与开发板自身3.3V不并联。
```

| 最容易误会的事 | 正确理解 |
| --- | --- |
| GPIO能接电机就能给它供电 | GPIO发控制信号，电机/舵机/灯带由合格电源和驱动承担电流 |
| 模块用5V，信号也能直接接ESP32 | 供电电压与信号电压分别查；MQ-2 AO须分压 |
| 共地就是所有电源输出都相连 | 连接GND是建立共同参考，不把两路3.3V稳压输出并联 |
| 有保护就不怕任意误接 | 保险丝、限流、反向阻断各管一部分，不能保证所有故障安全 |
| 3A电源还有很多余量 | 本载板设计分配1.60A，典型限流约2.04A，仍要测峰值、压降、温升 |

MQ-2载板上下各10kΩ，把5V降为2.5V，软件乘2还原。旧面包板10kΩ/20kΩ的软件系数1.5不能混用。

这款开发板按厂家图短接**IN/OUT**才采用当前排母供电方案，**不是短接5V/GND**。烧录：断载板电→取下→接电脑USB→拔USB→装回→上电，不能随意双路供电。

## 3. 布局：先摆大件，再放小件

| 先安排什么 | 为什么 |
| --- | --- |
| 板框、安装孔、开发板排母 | 先保证尺寸能套上；封装是焊盘外形、间距和脚号，不只是图标 |
| USB、对外插座、线束 | USB靠板边，给插头塑料头、锁扣、外壳壁厚留空间 |
| 输入保护、稳压器、电感、电容 | 大电流路径紧凑，芯片旁小电容靠近用电脚 |
| 模拟采集、相机等信号 | 避开开关电源、天线和大电流回路，缩短关键线路 |
| 模块在外壳里的位置 | MQ-2远离SHT40，雷达正面不遮金属，麦克风远离蜂鸣器 |

**XH 2.50mm与杜邦2.54mm不是同一种插头。** 排母摆得下，也要检查插上线束后是否挡住旁边器件。1:1打印后用实物套合，不能只看3D画面。

## 4. 布线：不仅要去得了，还要回得来

电流形成回路，信号也需要通过地返回。连续地层像返回道路；绕远、被切断可能增加干扰。

- 先处理电源和相机时钟等关键线，再安排普通控制线；不要求所有线都盲目等长。
- 电源线宽按电流、铜厚、长度、压降和温升计算。HomeGuard主5V为40mil、外围3.3V主干24mil，不能照搬到其他负载。1mil=0.0254mm。
- 过孔用于换层，也要核算电流。主干很粗，不代表细出口和过孔就一定足够。
- 摄像头数据成组、短线、少过孔，不跨地层缺口；实际线束和波形仍须测量。

### 在EDA重点看哪些层

| 层 | 检查重点 |
| --- | --- |
| 板框 | 尺寸、圆角、开槽、安装孔 |
| 顶/底铜层 | 焊盘、电源与信号实际连接，不能短路或漏连 |
| 两个内层 | 当前设计主要作为地层，注意完整性和过孔连接 |
| 顶/底丝印 | 元件编号、电压、第一脚和方向，别压在焊接位置 |
| 阻焊层 | 焊盘是否正确露铜，周围是否留足绿油间隔 |
| 锡膏层 | 贴片钢网上哪里开口，交装配厂复核 |
| 钻孔/机械层 | 孔径、金属化、USB槽孔与结构配合 |

丝印是字和图案，不导电；铜层才是实际电路。3D好看不代表这些都检查通过。

## 5. HomeGuard踩过的坑

| 问题 | 原因与处理 |
| --- | --- |
| 相机PCLK用GPIO44 | 板载CH343也驱动它，改到GPIO16 |
| 把35～37当空闲脚 | N16R8扩展内存占用，保留不用 |
| 18针相机想直插20针接口 | 定义不同，做[逐根转换线](../projects/homeguard-mini/eda/hardware/docs/camera-adapter.md) |
| 模块没供电，信号却已高电平 | 可能沿信号脚倒送电；用信号开关等待两路3.3V稳定 |
| 把信号开关当电平转换 | 只接通/断开，不能把5V变3.3V，也不叫电气隔离 |
| 分压改了不改固件 | 电压还原就错，必须匹配环境后重新学习 |

## 6. 怎样从“设计没报错”走到“真的正常”

1. 面包板逐个跑通，固定模块型号、接口和软件引脚。
2. 核对电源、封装、方向、尺寸，再布局布线。
3. 执行规则检查（ERC/DRC），保存重开核对；提交Git，避免堆“最终版”文件夹。
4. 首板先查焊接/短路，再限流空载测电压，逐件加模块。
5. 测全负载电流、压降、温升与关键波形，连续运行48小时，最后定外壳。

DRC类似代码静态检查，不替你验证实物尺寸、线束、温度和电源稳定性。当前原生DRC为0，辅助制造检查仍有提示，不能说全部通过：见[制造检查](../projects/homeguard-mini/eda/hardware/docs/fabrication-review.md)。设计计算见[电气依据](../projects/homeguard-mini/eda/hardware/docs/electrical-review.md)，操作见[首板验收](../projects/homeguard-mini/eda/hardware/docs/first-board-validation.md)，进度见[当前状态](../projects/homeguard-mini/docs/10-遗留问题与验收清单.md)。

HomeGuard只是学习和辅助提醒设备，不能替代经过认证的生命安全报警器。
