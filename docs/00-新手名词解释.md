# 嵌入式 AI 工作区新手名词解释

这份词典服务于三个案例：`stm32-desk-pet` STM32 桌宠、`homeguard-mini` ESP32-S3 安全管家、`ruview-wifi-csi-monitor` Wi-Fi CSI 实验。

你不需要一次背完。遇到陌生名称时回来查询即可。每个词都尽量说明“是什么、像什么、在项目里做什么”。

## 1. 一张图理解嵌入式项目

可以把整个项目想成一家小餐馆：

| 项目中的东西 | 餐馆比喻 | 实际作用 |
|---|---|---|
| 开发板 | 餐馆 | 承载整个系统 |
| 微控制器 | 店长兼厨师 | 读取输入、计算、控制输出 |
| 固件 | 菜谱和工作制度 | 告诉芯片每一步怎么做 |
| 传感器 | 眼睛、鼻子和耳朵 | 感知环境和人体 |
| 屏幕、LED | 告示牌 | 显示结果 |
| 舵机、蜂鸣器 | 手脚和嘴巴 | 产生动作或声音 |
| GPIO、通信接口 | 门和走廊 | 在器件之间传递信号 |
| 电源 | 水电供应 | 提供能量 |
| PlatformIO | 厨房管理工具 | 准备工具、编译和烧录 |

## 2. 板子和芯片

### MCU、微控制器

`MCU` 是 Microcontroller Unit。它像缩小到一颗芯片里的专用电脑，有处理器、内存和引脚，擅长稳定地控制硬件。

### 开发板

开发板是在 MCU 周围加上供电、时钟、USB、按钮和排针形成的整块板。MCU 像发动机，开发板像装好油箱、方向盘和仪表的练习车。

### 模块

模块把某种芯片和必要电路装在一块小板上，例如 OLED、蓝牙、SCD41 模块。它像已经装好插头的家电，比直接焊裸芯片适合新手。

### STM32、STM32F103C8T6、Blue Pill

- `STM32`：ST 公司的 MCU 家族，像汽车品牌；
- `STM32F103C8T6`：桌宠使用的具体芯片型号，像具体车型；
- `Blue Pill`：使用该芯片的一种蓝色开发板的外号，中文常叫“蓝色药丸板”。

```text
STM32 芯片家族
└─ STM32F103C8T6 具体芯片
   └─ Blue Pill 一种开发板
```

### ESP32、ESP32-S3

ESP32 是乐鑫的无线 MCU 家族，ESP32-S3 是其中一种芯片。工作区两个 ESP32 案例要求 S3，普通 ESP32、C3、S2 的引脚和能力不同，不能当成同一块板替换。

### ESP32-S3-DevKitC-1

工作区指定的全尺寸 ESP32-S3 开发板。`DevKit` 表示开发套件。它通常自带 USB 烧录能力，用数据线连接电脑即可，不需要 ST-Link。

### ESP32-S3-WROOM-1

开发板中央带金属罩的核心模组，里面组合了 ESP32-S3、Flash、PSRAM 和天线。WROOM 像发动机总成，DevKitC-1 像装好接口的整车。

### N8R8、N16R8

- `N8`：8 MB Flash；
- `N16`：16 MB Flash；
- `R8`：8 MB PSRAM。

N8R8 就是 8 MB Flash + 8 MB PSRAM。它们是容量规格，不是 Wi-Fi 型号。

### Flash、RAM、PSRAM

- Flash：断电后仍保存固件和资源，像书架；
- RAM：程序运行时的临时工作区，断电清空，像工作台；
- PSRAM：ESP32 外接的扩展运行内存，相当于加大工作台。

## 3. 代码、编译和烧录

### 源代码、固件

`.cpp`、`.h` 是人能读懂的源代码。固件是编译后给芯片执行的程序，例如 `firmware.bin`。源代码像中文菜谱，固件像翻译成厨师机器指令的菜谱。

### 编译（Build/Compile）

把源代码翻译成芯片能执行的机器代码。编译成功只表示固件做出来了，不表示已经写进开发板。

### 烧录、上传（Upload/Flash）

把固件写入开发板的 Flash。中文常说“烧录”，PlatformIO 按钮通常写 `Upload`。

### ST-Link V2

STM32 专用烧录和调试工具，通过 SWD 工作。它像维修人员的专用诊断插头，可以下载、暂停和单步运行 STM32 程序。ESP32-S3 通常不需要它。

### SWD、SWDIO、SWCLK

STM32 常用的调试接口：`SWDIO/DIO` 传数据，`SWCLK/CLK` 给节拍，另外要连接 GND。DIO 像说话内容，CLK 像统一口令的节拍器。

### USB-TTL

把电脑 USB 转成 UART 串口信号的模块，常见 TXD、RXD、GND、3V3/5V。它像串口翻译员，适合日志和通信；特定模式下也能给 STM32 烧录，但不能提供 ST-Link 的 SWD 调试。

### Bootloader

芯片上电后最先运行的一小段程序，决定进入正常应用还是下载模式。它像大楼门卫，决定把来访者送进办公室还是维修通道。

### BOOT、BOOT0、RESET

- STM32 `BOOT0`：选择启动方式，用 ST-Link 时通常保持 0；
- ESP32 `BOOT`：辅助进入下载模式；
- `RESET/RST/EN`：让芯片从头启动，类似重启键。

名称相似，但 STM32 跳线和 ESP32 按钮的操作不能照搬。

### USB 数据线、COM 口、驱动

- USB 数据线：同时传电和数据；只有充电功能的线无法烧录；
- COM 口：Windows 分配的串口房间号，例如 `COM7`；
- 驱动：让 Windows 认识 CH340、CP2102 等 USB 芯片的软件。

### 串口监视器（Serial Monitor）

显示开发板通过串口输出的文字，也能发送命令。它像开发板的聊天窗口，不等同于断点调试器。

## 4. VS Code 和 PlatformIO

### VS Code、PlatformIO

VS Code 是写代码的工作桌。PlatformIO 负责下载平台、管理库、编译、烧录和串口监视，像工具管理员、翻译员和搬运工的组合。

### `platformio.ini`

PlatformIO 项目的总配置，记录开发板、框架、库和烧录方式。它像项目施工说明书。

### environment、env

一套 PlatformIO 编译配置。桌宠的 `step1_blink` 到 `step5_bluetooth` 是五个环境，像同一产品的五个功能套餐。

### platform、board、framework

- `platform`：芯片工具支持包，例如 `ststm32`、`espressif32`；
- `board`：开发板编号，例如 `bluepill_f103c8`；
- `framework`：开发框架，例如 Arduino。

可以依次理解为“工具仓库、具体车型、编程规则”。

### Arduino 框架、`Arduino.h`

Arduino 框架提供 `setup()`、`loop()`、`digitalWrite()` 等统一接口。`Arduino.h` 是主要声明文件。这里的 Arduino 是软件框架，不代表必须使用 Arduino 品牌开发板。

### 库、`lib_deps`、工具链

- 库：别人写好的可复用代码，例如 U8g2；
- `lib_deps`：PlatformIO 的库依赖清单；
- 工具链：编译器等一整套构建工具。

STM32 与 ESP32 的处理器不同，使用的工具链也不同。

### IntelliSense、`compile_commands.json`

IntelliSense 是 VS Code 的补全和红线检查，像检查草稿的老师，并非真实编译器。编译数据库 `compile_commands.json` 记录真实编译参数，让它正确识别嵌入式头文件。若 PlatformIO 编译成功但编辑器报红，通常先检查索引配置。

### 头文件、宏、`PET_STAGE`

- `.h` 头文件：告诉代码有哪些类型、函数和常量可用；
- `#include`：把工具目录引入当前代码；
- 宏：编译前的文字或条件开关；
- `PET_STAGE`：控制桌宠本次包含第几阶段功能的总开关。

## 5. 电气基础

### 电压、电流、功率

- 电压 V 像水压；
- 电流 A 像每秒流过的水量；
- 功率 W 是消耗能量的速度，近似为电压乘电流。

电压必须匹配，电源最大电流要足够。5V 2A 表示最多可稳定提供约 2A，不会强迫设备吸收 2A。

### 3V3、5V、VCC、VIN、VBAT

- `3V3` 就是 3.3V；
- `VCC` 是模块工作电源端，具体电压必须查说明；
- `VIN` 是板子电源输入端，可能经过稳压；
- `VBAT` 是电池或备用电源端。

它们都与电源有关，但不能随意互换。

### GND、共地

GND 是电压共同参考的零点。两套电源传递信号时通常要共地，像两把尺子从同一零刻度开始量。共地只连接 GND，不是把不同电源正极并联。

### GPIO

通用输入输出引脚，像可配置的小门：输入时读取按键，输出时控制 LED。GPIO 只能处理小信号，不能直接给舵机、喇叭或大负载供电。

### PA0、PB6、PC13、GPIO8

芯片引脚门牌号。STM32 常写 `PA0`、`PB6`，ESP32 常写 `GPIO8`。不同板子必须看丝印和接线表，不能只数左边第几个孔。

### 高低电平、输入输出

输入是芯片听别人说，输出是芯片对外发命令；高/低电平近似数字 1/0。Blue Pill 板载 LED 常为“低电平点亮”，所以 LOW 反而亮。

### 上拉、下拉

悬空输入可能随机变化。上拉把默认状态轻轻拉高，下拉则拉低，像给无人推动的门加一根弱弹簧。

### 电阻、电容

- 电阻限制电流或设置默认电平，LED 的串联电阻像限流阀；
- 电容短时储存电荷、过滤波动，像设备旁的小水箱。

`2kΩ` 是 2000Ω，`10kΩ` 是 10000Ω。电解电容通常有正负极。

### LED

发光二极管，电流主要只能朝一个方向流动。通常长脚是正极，但拆机件应看标记或测量；使用时要串联限流电阻。

### 面包板、洞洞板、PCB

- 面包板：免焊、可反复修改，像草稿纸；
- 洞洞板：手工焊接，像手写定稿；
- PCB：工厂制作好铜线路，像正式道路网。

### 排针、排母、杜邦线

排针是成排金属针，排母是对应插座，杜邦线用于临时连接。公对公、公对母、母对母只表示两端形状，不表示信号方向。

## 6. 通信接口

### UART、TX、RX、波特率

UART 就是常说的串口。TX 发送、RX 接收，所以通常交叉连接：模块 TX → 开发板 RX。波特率是通信节拍，如 9600、115200，两端必须相同。

### I²C、SDA、SCL、地址

I²C 用两根信号线连接多个设备：SDA 传数据，SCL 给时钟，每个设备有地址，例如 OLED 常见 `0x3C`。它像一条公交线，每站有自己的门牌号。

### SPI、SCK、MOSI、MISO、CS、DC

SPI 速度较快，彩屏使用它：SCK 给节拍，MOSI 是主控发出，MISO 是设备返回，CS 选择设备，DC 让屏幕区分命令和图像数据。它像高速传送带，但需要更多控制线。

### I²S、WS、SCK、SD

I²S 是数字音频接口，INMP441 使用它。WS 标记采样帧/声道，SCK 给节拍，SD 传声音数据。I²S 与名字相近的 I²C 不是同一种接口。

### PWM

快速切换高低电平，通过每周期“开多久”控制平均效果。它像快速开关水龙头，桌宠用它控制 SG90 舵机角度。

### Wi-Fi、蓝牙

Wi-Fi 适合加入局域网并传输较多数据，蓝牙适合手机与近距离设备直接通信。它们像“社区道路”和“面对面对讲机”。

## 7. STM32 桌宠名词

### OLED、SH1106、SSD1306、U8g2

- OLED：自发光小屏幕；
- SH1106、SSD1306：两种常见屏幕驱动芯片，外观相同也可能“方言”不同；
- U8g2：负责字体和图形绘制的现成代码库，像绘画助手。

### SG90、舵机、180°

SG90 是按控制脉冲转到指定角度的小舵机。普通电机像持续转的风扇，舵机像能转到指定方向的脖子。它启动电流较大，要用独立稳定 5V 并与 STM32 共地，不能由 GPIO 供电。

### 板载 LED、自锁开关、轻触按键

- 板载 LED：已焊在开发板上的灯，第一阶段用它验证烧录；
- 自锁开关：按一次保持、再按一次释放，像房间灯开关；
- 轻触按键：松手即恢复，像门铃。

### 串口蓝牙模块

把 UART 数据通过蓝牙传给手机，像给串口加无线延长线。供电电压和逻辑电平必须看具体型号。

### 蜂鸣器、扬声器

有源蜂鸣器给控制信号就能发提示音；裸扬声器需要音频信号和功率放大。前者像电子门铃，后者像需要功放推动的嗓子，不能直接接 GPIO。

### 锂电池、充放电模块

锂电池提供便携能源，充放电模块负责充电、保护或升降压。`B+/B-/OUT+/OUT-` 必须按丝印确认。短路可能起火，先用合格 USB 电源完成验证。

## 8. HomeGuard Mini 名词

### SCD40、SCD41、CO₂、ppm

SCD40/41 是二氧化碳传感器。`ppm` 是百万分之一；1000 ppm 约表示一百万份空气中有一千份 CO₂。它像空气的 CO₂ 浓度计。

### MQ-2、MQ-135

都属于广谱气敏元件，对多种气体都会变化且容易漂移。它们像只知道“闻到味道”的鼻子，不能可靠给出 CO₂ ppm，因此不能替代 SCD40/41。当前HomeGuard使用MQ-2相对指数做实验，不再宣称测量CO₂。

### SHT40、BH1750、lux

- SHT40：数字温湿度传感器；
- BH1750：数字光照传感器；
- lux（勒克斯）：照度单位，表示环境有多亮。

### LD2410C、毫米波、PIR

LD2410C 用毫米波回声感知移动与细微动作，像用无线电观察房间；PIR（如 HC-SR501）只感知人体热辐射变化，像只注意“热影子有没有移动”的门卫，静坐时可能漏检。

### INMP441、数字麦克风

I²S 数字麦克风，把声音转换为数字采样。项目用它计算声音强弱特征，不等于持续录音上传云端。

### ST7789V、ILI9341

都是彩屏驱动芯片，像屏幕内部的显示管理员，不是尺寸名称。当前HomeGuard使用1.54英寸240×240的ST7789V；学习课程还保留2.4英寸240×320的ILI9341案例。

### OV2640、DVP

OV2640是200万像素摄像头传感器。DVP是它一次并行发送多位图像数据的接口，需要D0～D7、像素时钟和同步线，因此接线比I2C传感器多得多。

### 有源蜂鸣器模块

内部有振荡或驱动电路，GPIO 只给控制信号。`有源` 表示能自己发固定提示音，不表示能播放语音。

### 边缘 AI、本地推理

数据直接在 ESP32-S3 上处理，而不是全部上传云端。像把判断员放在家里，响应快、隐私好，但能力受芯片资源限制。

### 特征、基线、异常分数

- 特征：从原始数据提取的有用数字；
- 基线：一段时间内学到的正常范围；
- 异常分数：当前状态偏离正常的程度。

它像保安先熟悉日常作息，再标记不寻常的组合，不是无所不知的通用 AI。

### Web 服务器、AP、热点、STA

ESP32 能自己提供网页，此时“服务器”只是提供网页的一方，不必另买服务器。AP 是无线接入点；STA 是连接 AP 的客户端。ESP32 可作为 STA 连接家中路由器，失败时也可创建自己的热点 AP。

## 9. RuView Wi-Fi CSI 名词

### RuView、RF、CSI

- RuView：工作区使用的上游 Wi-Fi 感知软件项目；
- RF：射频，即无线电波；
- CSI：Channel State Information，信道状态信息，描述 Wi-Fi 不同频率成分经过房间后如何变化。

CSI 像“无线电波穿过房间后留下的一组细致回声记录”。它可观察有人/无人和运动变化，但单块板不能保证人体骨架、医疗级生命体征或可靠多人定位。

### 子载波、幅度、相位、RSSI

Wi-Fi 把数据分到许多窄小频率通道，这些叫子载波。幅度表示信号强弱，相位表示波形位置，RSSI 是总体接收强度。RSSI 像只看全班总音量，CSI 像分别分析许多音高和时间差。

### DSP

数字信号处理，对采样数据滤波、变换并提取特征，像从嘈杂录音中整理节奏和变化。

### 路由器、AP、SSID、2.4 GHz

路由器连接家庭网络，AP 是它提供无线接入的角色，SSID 是手机看到的 Wi-Fi 名称。2.4 GHz 是无线频段，不是传输速度或 CPU 主频。

### 局域网、IP 地址、DHCP

- 局域网 LAN：同一路由器下的本地网络，像同一小区；
- IP：设备地址，像楼栋房号；
- DHCP：路由器自动分配 IP，像前台发临时房卡；
- 地址保留：让同一设备尽量总拿到相同 IP。

### UDP、端口 5005

UDP 是快速、低开销的传输方式，不保证丢失数据重传，像连续寄明信片。端口 5005 像同一 IP 大楼里的具体房间号。

### 防火墙、客户端隔离

Windows 防火墙像门卫，必须允许 UDP 5005 入站。路由器的 AP/客户端隔离会阻止同一 Wi-Fi 下设备互访，导致 ESP32 无法把数据发给电脑。

### 校准

在实际房间采集无人、有人、运动状态作为参考。CSI 很受家具和摆放影响，校准像给秤归零，换房间或大幅移动设备后通常要重做。

### 模拟数据、真实数据

模拟数据由软件生成，用于验证页面；真实数据来自 ESP32-S3。页面动画好看不等于检测真实。拔掉 ESP32 后数据仍自然变化，通常说明仍在演示模式。

## 10. EasyEDA 和制板名词

### EasyEDA（嘉立创EDA）、EDA

EasyEDA 是绘制原理图和 PCB 的 EDA 软件。EDA 是 Electronic Design Automation，即电子设计自动化。

### 原理图、PCB 图

原理图表达“谁与谁电气相连”，像地铁线路图；PCB 图决定真实元件位置与铜线走法，像城市施工地图。原理图正确不代表 PCB 布局一定合格。

### 符号、封装、网络、BOM

- Symbol 符号：原理图里的抽象图标；
- Footprint 封装：PCB 上真实焊盘和尺寸；
- Net 网络：电气上应相连的一组点；
- BOM：要购买的物料清单。

它们分别像地图图标、实物占地、道路和采购单。

## 11. 电脑端软件名词

### Git、仓库、提交、GitHub、Gitea

Git 记录文件变化；仓库像项目档案室；提交像给一次完整修改拍照并写说明。GitHub 和 Gitea 是托管 Git 仓库的不同服务，像不同品牌的档案馆。

### 上游源码、vendor

上游源码是原作者维护的代码。`vendor` 用来存放下载的第三方项目副本，像供应商零件仓库，不应与自己的代码混在一起修改。

### Python、Docker

Python 是通用编程语言。Docker 把程序和运行环境装进标准容器，像把厨房和厨具一起装进集装箱。它们运行在电脑端，不是 STM32/ESP32 烧录器。

### Node.js、npm、npx

Node.js 在电脑上运行 JavaScript；npm 管理软件包；npx 临时执行包中命令。它们用于 RuView 的电脑端工具。

### Rust、MSVC Build Tools

Rust 是编程语言；MSVC Build Tools 提供 Windows 本地编译工具。RuView 部分电脑端组件需要它们，它们与 STM32 的 ARM 编译器不是同一套东西。

### localhost、`127.0.0.1`

表示“当前设备自己”。ESP32 向电脑发数据时不能把电脑地址填为 `127.0.0.1`，因为从 ESP32 看，这个地址指 ESP32 自己。

## 12. 最容易混淆的名称

| 容易混淆 | 正确区别 |
|---|---|
| STM32 vs Blue Pill | STM32 是芯片家族；Blue Pill 是一种开发板 |
| ESP32-S3 vs DevKitC-1 | S3 是 MCU；DevKitC-1 是装好外围的开发板 |
| ST-Link vs USB-TTL | ST-Link 走 SWD 调试 STM32；USB-TTL 走 UART |
| 编译 vs 烧录 | 编译生成固件；烧录把固件写进板子 |
| Arduino 框架 vs Arduino 板 | 前者是软件接口；STM32 也能使用它 |
| 3V3 vs VCC | 3V3 明确是 3.3V；VCC 必须查模块要求 |
| GPIO vs 电源脚 | GPIO 传小信号；不能给大负载供电 |
| I²C vs I²S | I²C 连传感器/屏幕；I²S 主要传数字音频 |
| OLED vs SH1106 | OLED 是屏幕类型；SH1106 是驱动芯片 |
| 蜂鸣器 vs 扬声器 | 蜂鸣器易发提示音；扬声器通常需要功放 |
| Flash vs RAM | Flash 断电保留；RAM 是临时工作区 |
| Wi-Fi CSI vs 摄像头 | CSI 分析无线信道变化，不拍摄人体图像 |
| AI 异常检测 vs 通用智能 | 当前项目识别统计偏离，不理解所有事件 |
| 原理图 vs PCB | 原理图讲连接关系；PCB 决定真实布局走线 |

## 13. 三个案例的工具链路

### STM32 桌宠

```text
电脑 + PlatformIO
  → ST-Link V2
  → Blue Pill
  → OLED
  → 1 个 SG90（独立 5V，和 STM32 共地）
  → 按键、LED、串口蓝牙
```

USB-TTL 可用于串口日志，但不是当前默认烧录方式。

### HomeGuard Mini

```text
电脑 + USB-C 数据线
  → ESP32-S3-DevKitC-1
  → MQ-2分压 + SHT40 + BH1750
  → LD2410C + INMP441 + OV2640
  → ST7789V + 有源蜂鸣器
```

开发板自身通过 USB 烧录，不需要 ST-Link。

### RuView Wi-Fi CSI

```text
家庭 2.4 GHz 路由器
        ↕ Wi-Fi
ESP32-S3-DevKitC-1  → UDP CSI 数据 → Windows 电脑
```

它需要正确的网络与软件配置，不需要摄像头或所谓“超声波接收器”。

## 14. 新手安全规则

1. 接线和改线前先断电。
2. 先确认电压，再连接 VCC、VIN、3V3、5V。
3. GPIO 只传控制信号，不直接驱动舵机、大扬声器等负载。
4. 使用独立电源时按接线要求共地，但不要把两个电源正极直接并联。
5. 第一遍只接开发板，烧录成功后每次只增加一个模块。
6. 锂电池最后再接；不清楚 `B+/B-/OUT+/OUT-` 时不要尝试。
7. 器件发烫、有焦味或反复重启时立即断电。
8. 接线以模块丝印和数据手册为准，不按外观或线色猜测。
