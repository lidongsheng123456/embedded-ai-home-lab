# 新手词典：遇到哪个查哪个

**先记住：传感器采集 → 程序判断 → 灯、屏幕或蜂鸣器输出。** 电源给它们供电，信号线让它们交换信息。

## 板子和存储

| 名称 | 一句话理解 |
| --- | --- |
| 单片机 / MCU | 能运行程序、读取引脚、控制硬件的一颗小电脑芯片。 |
| 开发板 | 给芯片配好供电、接口和排针的整块板，方便学习。 |
| 模块 | 已配好外围电路的小板，例如OLED或温湿度模块。 |
| 载板 | 连接开发板和多个模块的底板；本身也要装电源和接口元件。 |
| STM32F103C8T6 | 当前STM32学习板使用的芯片型号。 |
| Blue Pill | 常见的STM32F103蓝色最小系统板的外号。 |
| ESP32-S3 | 带Wi-Fi和BLE的单片机；不能和普通ESP32、C3、S2随意互换。 |
| DevKitC-1 | 一种ESP32-S3开发板；同名兼容板也要核对针脚图。 |
| WROOM | 带金属罩的核心模组；天线可能在模组上，也可能通过接头外接。 |
| N16R8 | 16MB Flash和8MB PSRAM；N8R8则是8MB Flash和8MB PSRAM。 |
| Flash | 存固件、网页等，断电仍保留。 |
| RAM | 程序临时工作区，断电清空。 |
| PSRAM | 扩大的临时工作区，适合放图片和音频缓存，不能代替Flash。 |

## 写代码到运行

| 名称 | 你实际要做的事 |
| --- | --- |
| 源代码 `.c` / `.cpp` | 人能读和修改的程序。C与C++是两种语言，C++还支持类等功能。 |
| 头文件 `.h` | 列出模块提供的函数、类型和常量；实现通常在`.c/.cpp`。 |
| 固件 | 编译后给芯片执行的程序，常见文件是`.bin`或`.elf`。 |
| Build：编译 | 生成固件；这一步不把程序写进板子。 |
| Upload：烧录 | 把固件写到板子的Flash中。 |
| Monitor：串口监视 | 查看日志、发命令；不是烧录，也不是断点调试。 |
| Clean | 清理编译缓存；不等于擦除板上程序。 |
| VS Code | 写代码、打开工程的编辑器。 |
| PlatformIO | 管理芯片工具、库、编译、烧录和串口的插件。 |
| `platformio.ini` | 记录板型、框架、依赖和烧录方式的工程配置。 |
| 环境 / env | 本次编译哪一套案例或功能；例如`01a_gpio_blink`。 |
| platform / board / framework | 分别选芯片支持包、开发板型号、编程框架。 |
| HAL库 | 厂家提供的硬件操作函数；STM32课程使用它。 |
| Arduino Core | 提供`pinMode()`等接口的软件框架；不要求Arduino品牌开发板。 |
| 库 / `lib_deps` | 已写好的功能代码，以及工程依赖它们的清单。 |
| 工具链 | 编译器、链接器等把源码变成固件的一套工具。 |
| `#include` | 引入头文件，让编译器知道有哪些接口。 |
| 宏 | 编译时的文字或条件开关；如桌宠的`PET_STAGE`选择功能阶段。 |
| IntelliSense / 红线 | 编辑器分析结果；是否真的编译失败，要看Build输出。 |
| `compile_commands.json` | 记录真实编译参数，帮助编辑器识别芯片和头文件。 |

**只复制一个`.c`文件到任意目录，不能代替打开完整工程。** 芯片头文件和编译参数来自工程配置。

## 电源和引脚

| 名称 | 一句话理解 |
| --- | --- |
| 电压 V | 两点之间的电位差；常用GND作为0V参考。 |
| 电流 A | 实际流过的电荷流量；5V/3A电源不代表一定输出3A。 |
| 功率 W | 消耗能量的快慢，直流情况下约等于电压×电流。 |
| 3V3 / 5V | 分别表示3.3V、5V；连接前要核对是输入还是输出。 |
| VCC / VIN / VBAT | 工作电源、输入电源、电池/备用电源的常见名称；允许电压必须查具体板子。 |
| GND / 共地 | 共用电压零点，通常把通信双方GND连接；不代表把正极也并联。 |
| GPIO | 可配置成输入或输出的信号脚，不是大功率供电口。 |
| PA9 / PB6 / GPIO8 | 引脚名称；按板上丝印找，不按排针从左数第几孔。 |
| 输入 | 读取外部电平，例如判断按钮是否按下。 |
| 输出 | 主动设置电平，例如给LED或驱动模块发控制信号。 |
| 高 / 低电平 | 3.3V系统中通常接近3.3V / 0V；表示数字1 / 0。 |
| 输入上拉 | 输入脚通过内部大电阻默认保持高，按钮接GND时变低；不是强力输出3.3V。 |
| 输入下拉 | 输入脚默认保持低，按钮接3.3V时变高。 |
| 推挽输出 | 引脚能主动拉高，也能主动拉低。 |
| 开漏输出 | 只能主动拉低；变高需要上拉电阻。 |
| 电阻 | 可用于限流、分压、设置默认电平；10kΩ=10000Ω。 |
| 电容 | 短时储存电荷、减小电源波动；电解电容通常有正负。 |
| LED | 发光二极管；普通灯要串限流电阻，正负接法决定哪种电平亮。 |
| 低电平点亮 | LED另一端接正电源，引脚拉低才有电流；低电平不等于整个电路“没电”。 |
| 面包板 / 洞洞板 / PCB | 分别适合免焊试验、手工焊接、工厂制作固定铜线路。 |
| 排针 / 排母 / 杜邦线 | 金属针、配套插座、临时连接线；公母指接头形状，不是信号方向。 |

GPIO模式和可用引脚的完整表见[两块开发板引脚速查](../learning/docs/两块开发板GPIO模式与引脚清单.md)。

## 通信和接口

| 名称 | 怎样理解、怎样用 |
| --- | --- |
| USB | 一套连接与通信规范；可以供电，也可以传数据。 |
| Type-C / USB-A | 插头外形；外形相同不保证支持相同速度、功率和功能。 |
| COM口 | Windows给串口设备的编号，如COM5；换接口、板子或模式后可能变。 |
| 驱动 | 让电脑认识CH340、CH343等设备的软件。 |
| UART串口 | 按约定速度逐位传数据，常用TX、RX、GND。 |
| USART | 既支持异步串口，也支持某些同步模式的硬件；只接TX/RX时通常用异步模式。 |
| TX / RX | 发送 / 接收；通常TX接对方RX，RX接对方TX。 |
| 波特率115200 | 普通UART中每秒约115200个信号位；常见8-N-1每字节占10位，约11520字节/秒。 |
| 起始位 / 停止位 | 告诉接收方一个字符在哪里开始、在哪里结束；不是等对方回信的时间。 |
| ASCII | 字符编码，例如字符`'1'`是0x31，与数值1不同。 |
| USB转串口 / USB-TTL | 把电脑USB转换成UART信号的模块；必须核对3.3V逻辑电平。 |
| ST-Link / SWD | 给STM32烧录和调试；SWDIO传数据，SWCLK传节拍。SWIM是STM8接口。 |
| I2C / SDA / SCL | 两根信号线：数据和时钟；同一总线上用设备地址选对象。 |
| I2C地址0x3C | OLED的常见设备地址；不是GPIO编号，也不是内存地址。 |
| SPI / SCK / MOSI / MISO / CS | 时钟、发出数据、返回数据、片选；适合屏幕和存储器。 |
| 屏幕DC脚 | 区分命令和画面数据；不是SPI所有设备都有的标准信号。 |
| I2S / BCLK / WS / SD | 数字音频的时钟、声道/帧标记和数据；不是I2C。 |
| ADC | 把输入电压变成数字，像电压尺；只有支持ADC的脚能用。 |
| PWM | 周期重复的高低电平；调灯常看高电平占比，舵机看高电平持续时间。 |
| 周期 / 频率 / 占空比 | 重复一遍多久 / 每秒重复几遍 / 高电平占整个周期多少。 |
| 舵机20ms周期 | 每秒重复50遍：1÷50秒=20ms=20000µs；具体脉宽对应角度要按舵机规格校准。 |
| 外设通道 | 同一个硬件内部的第几路；如TIM3通道1连接PA6，不是另一根额外的线。 |
| RCC / 时钟使能 | 给相应硬件模块打开工作节拍；没开时钟，模块通常不能正常工作。 |
| HSI / HSE / PLL | 芯片内部振荡器 / 板外晶振 / 把时钟倍频的电路。 |
| SysTick | 常用的系统滴答计时器，为HAL毫秒计时提供节拍。 |
| 中断 / EXTI | 事件到来时插入一小段处理；EXTI专门响应引脚等外部变化。 |
| DMA | 按配置在内存与外设之间搬数据，减少CPU逐字节搬运。 |
| 状态机 | 记录“现在到哪一步”，每次只执行当前步骤该做的事。 |
| FreeRTOS / 任务 / 队列 | 安排多个工作运行 / 一个工作循环 / 安全传递数据的容器。 |
| 低功耗 / 唤醒 | 空闲时让部分电路休息，发生指定事件后恢复工作；效果要测电流。 |

电脑的Monitor、VOFA都是打开COM口的工具，通常不能同时占用同一COM。**COM口不是ESP32上运行的网络服务端口。**

## 联网与网页

| 名称 | 一句话理解 |
| --- | --- |
| Wi-Fi / BLE | 家庭网络常用连接 / 手机近距离低功耗蓝牙连接。ESP32-S3不支持经典蓝牙SPP。 |
| STA / AP | 像手机一样连路由器 / 自己创建热点。 |
| SSID / 2.4GHz | Wi-Fi名称 / 无线频段，不是CPU速度。 |
| IP / 局域网 | 网络中的设备地址 / 本地互通的网络；同路由器设备一般可互访，但隔离设置可能阻止。 |
| DHCP | 路由器自动给设备分配IP。 |
| 网络端口 | 一个IP上的服务入口，如网页常用80；与COM编号是两回事。 |
| Web服务器 | 给浏览器提供网页的一方；ESP32自己就能承担这个角色。 |
| localhost / 127.0.0.1 | 当前设备自己；ESP32不能用它指代你的电脑。 |
| UDP / 5005 | 一种不保证重传的数据传输方式 / RuView项目使用的网络端口。 |
| 防火墙 / 客户端隔离 | 电脑或路由器阻止通信的规则；网页打不开时要检查。 |

## 项目里的模块和AI

| 名称 | 实际作用 |
| --- | --- |
| OLED / SH1106 / SSD1306 / U8g2 | 屏幕类型 / 两种屏幕控制器 / 常用绘图库；型号要配对。 |
| SG90 | 常见角度舵机；用合适5V电源供电，信号接GPIO，并共地。 |
| 轻触按键 / 自锁开关 | 松手复原 / 按一次保持、再按释放。 |
| 蜂鸣器 / 扬声器 | 提示音器件 / 需要功放和音频信号的喇叭；都不能用GPIO承担大电流。 |
| 锂电池 / 充放电模块 | 电能来源 / 充电、保护或升降压电路；不能只凭外观接线。 |
| MQ-2 / MQ-135 | 对多种气体有反应，容易受温湿度影响；当前HomeGuard用MQ-2相对指数。 |
| SCD40 / SCD41 / CO₂ ppm | 二氧化碳传感器 / 浓度单位；MQ-2不能代替它测CO₂。 |
| SHT40 / BH1750 / lux | 测温湿度 / 测光照 / 光照单位。 |
| LD2410C / PIR | 毫米波人体存在模块 / 感应热辐射变化的模块；能力不同。 |
| INMP441 | 数字麦克风；HomeGuard计算相对声音强弱，不是校准分贝。 |
| ST7789 / ILI9341 | 两种彩屏控制芯片，不是屏幕尺寸名称。 |
| OV2640 / DVP | 摄像头 / 并行图像接口，需要多根数据和同步线。 |
| 特征 / 基线 / 异常分数 | 从数据提取的数字 / 学到的平常范围 / 偏离平常的程度。 |
| 本地AI / 边缘推理 | 数据在设备上处理，不必每次发云端。 |
| DeepSeek API | 设备通过互联网请求官方模型；需要密钥，可能计费。 |
| RuView / RF / CSI | Wi-Fi感知软件 / 无线电 / 描述无线信道变化的数据，不是拍摄人体。 |
| 子载波 / 幅度 / 相位 / RSSI | 不同频率成分 / 强弱 / 波形位置 / 总体接收强度。 |
| DSP / 校准 | 处理采样信号 / 在实际环境建立参考；换摆放后可能要重做。 |
| 模拟数据 / 实物数据 | 软件编出来的演示 / 真实传感器测得的数据；动画不能证明检测有效。 |

## 画板与装配

| 名称 | 一句话理解 |
| --- | --- |
| EDA / 嘉立创EDA | 画原理图、电路板的软件。 |
| 原理图 | 规定谁和谁电气相连。 |
| PCB布局布线 | 决定元件放哪里、铜线怎么走、板子开哪些孔。 |
| 符号 / 封装 / 网络 | 图上的抽象元件 / 实物焊盘形状尺寸 / 应相连的一组电气点。 |
| 位号 | 板上元件的名字，如R13、U7，用来找位置。 |
| BOM / 元件坐标表 | 型号与用量清单 / 每个元件的板上位置与方向。 |
| 空板打样 | 做出没有装元件的PCB；3D预览中有芯片不代表购买时包含芯片。 |
| 贴片 / 插件焊接 | 把小元件焊在板面 / 把引脚穿过孔再焊。 |
| 包料 / 来料代焊 | 厂家买元件并焊 / 你提供元件，厂家负责焊。 |
| 丝印 / 阻焊 | 板上的文字图案 / 常见绿色保护层；露出的焊盘用于焊接。 |
| OSP / 沉金 | 焊盘表面防氧化的不同工艺；券是否适用与电路是否正确无关。 |
| DRC | 按规则检查短路、间距等；0项不等于插得上、供电稳或已经实测。 |

## 电脑端工具：用到再查

| 名称 | 一句话理解 |
| --- | --- |
| Git / 提交 / 仓库 | 记录文件变化的工具 / 一次有说明的版本记录 / 项目档案。 |
| GitHub / Gitea | 两种代码托管服务。 |
| 上游 / vendor | 原作者维护的代码 / 保存第三方代码的位置。 |
| Python / Docker | 编程语言 / 打包程序运行环境的工具，不是下载器。 |
| Node.js / npm / npx | 运行JavaScript / 安装依赖 / 执行软件包命令，HomeGuard打包网页会用到。 |
| Rust / MSVC Build Tools | 编程语言 / Windows本地编译工具，部分电脑端程序需要。 |
| Bootloader / BOOT / RESET | 启动或下载程序 / 选择下载模式的操作 / 重新启动。STM32的BOOT0与ESP32的BOOT不能照搬。 |

接线前只核对四件事：**供电几伏、信号几伏、GND是否相连、引脚是否被占用。** 电机、舵机、继电器、灯带和喇叭需要匹配的电源与驱动，不让GPIO承担它们的供电电流。
